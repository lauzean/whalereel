## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
- 观众要的是"我知道一点、我猜错一点"：悬念 = 信息差（让观众替角色捏汗，而不是猜"你藏了什么"）。
- 心理级爽点锁「秩序」：用逻辑推进还原真相（报告：复仇/宫斗/悬疑/重生/寻亲同属秩序型），不靠暴力、不靠金手指。
- 观众位置决定细分：焦急型（主角不知）→替主角担心；先知型（配角不知）→期待打脸；上帝型（只有观众知）→期待真相大白。
- 信息差三规则：①所有信息差都奔着情绪去（要么气到发抖、要么爽到剁手），没情绪的悬念一文不值；②悬念别拖，该爆就爆；③一个悬念结束立刻埋下一个，不留空隙。
- 反派必须有合理动机——最好的矛盾是"两个好人因不同选择走向不同命运"。

### 1.2 单集结构公式
- 黄金单集公式：本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连。
- 单集 = 1 核心情绪 + 1 辅助情绪 + 1 结尾钩子（核心情绪同集 ≤2 个）；每集永不解决问题、永不圆满收尾。
- 每集必须给新信息（新身份/新底牌/新阴谋/新破绽），看完等于没看 = 白写。

### 1.3 情绪配比（数字）
- 压抑 40% + 爽感 50% + 解气 10%（报告·复仇类）。
- 基调确定后不中途大幅更改（悬疑剧突然插甜宠撒糖＝严重问题）；情绪布局须呈波浪上升，禁止连续 3 集同一强度。
- 单集 500–800 字正文须覆盖爆点/虐点/爽点 ≥1 个；连续 3 集无情绪爆点 = 严重问题。

### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个信息点、15 秒一个剧情变化、45 秒一个强期待（并在其中留出主角做抉择的时空）。
- 情绪节点：前 3 秒把最强钩子甩到观众脸上（不做铺垫）；中段 30–40 秒第一次小爆发、每约 30 秒埋一个小钩子；结尾 10 秒拉满悬念卡断。
- 反转密度：全剧股价级反转 ≈3 个（骨架定死，预埋集必须早于揭晓集）；单集钩子级反转 ≤1 个且不可连续使用。
- 付费点：第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集五个卡点（秘密将曝光→遭陷害→重大反转→伏笔翻转→揭阴谋），必须卡在主线上；情绪按阶段走（报告·复仇类）——压抑+愤怒 → 紧张+小爽 → 震惊+焦虑 → 爽感+解气 → 温暖+圆满。
- 拉扯：压到谷底（压越狠反弹越猛）→ 来回晃 ≥3 次（先给"危机解除"的错误预期再致命一击）；约每分钟晃一次、每 3 分钟一次完整"压-弹"。

### 1.5 爽点配方（装→打脸→震惊→收获）
爽点 = 装 + 打脸 + 震惊 + 收获（报告四件套），本题材落地：
- **装**：藏起真实身份（假装懦弱、实则收集证据）——他把被撕碎的举报信一张张收好；**打脸**：落在**证据**上而非拳头上——他不辩解，只把账本推到桌中央翻到第 37 页；**震惊**：写具体身体动作（冷笑者把茶杯放回桌上、指尖在抖），不写"全场哗然"；**收获**：真相成立、罪责落地，并立刻抛出幕后更大的黑手。
- 桥段形态：被诬陷后反手投屏篡改记录；豪门认亲现场拿出信物揭穿假冒者（报告·身份差付费点）。
- 打脸必须有观众：付费点特征=场面宏大、事态紧急、围观群众多（宴会/认亲/发布会/婚礼）；卡点三步：先爽透（投屏证据+全行业通报+跪地求饶）→ 拉高预期（"欠我的账一笔笔讨回来"）→ 卡准核心钩子。

### 1.6 反转与钩子模板
- 股价级反转三式：①**预期误导**：不藏信息，用观众思维定式引导出"合理的错误结论"，反转后线索严丝合缝；②**人设颠覆**：只用于配角，绝不动主角核心底色；③**动机置换**：同一行为同时适配表层/深层两个动机。
- 单集钩子级反转三式：道具伏笔（保温杯→杯底录音笔录下篡改数据）、情绪回弹（被嘲笑→当场播放挪用公款认罪录音）、镜头错位（局部真画面误导+下集全景揭晓）。
- 两准则：给观众的画面必须 100% 真实，绝不造假骗人；同一招不能连续使用。铁规矩：空降硬凹反转 = 耍流氓，线索对不上、画面造假一律不采用。
- 钩子两套并用：关系内部（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观），避免全是同一类。
- 反模板纪律："不为检查表硬加秘密、反转或人物弧"；剧本长出输入没有要求的机关时撤掉机关，不替它找理由；桥段/反转市面 >10 次就别用；开篇避三天坑（铺背景、一群角色乱冒、慢悠悠写景）。

### 1.7 台词特征
- 潜台词要高效但不要晦涩：一句话同时推进剧情+塑造人物+传递冲突，意思一遍就懂。
- 单句 ≤20 字、单角色单次 ≤50 字，全口语化；遮住角色名仍能判断说话人；反派威胁不喊出口，用家常话完成："你女儿今天几点放学？"
- 称谓按短剧规范：「家主」代家族掌权人、「执法局/执法人」代公安，禁用真实官职；财富用"亿元""百亿订单"等夸张表达。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 信息差控制与线索三现法（悬疑的核心）
- 观众必须比角色多知道半步或少知道半步：每集至少一个"观众看见、角色没看见"的镜头（门后的手、桌下的录音笔）。
- 信息差靠画框分配：同一时刻给观众的比给角色的多——先给观众一个 2 秒物证特写，再切回毫不知情的对话。
- **线索三现法（保留并扩写）**：关键物证第一集给模糊特写、中段给对比特写、揭晓集给全景闪回——三帧同构图、同机位、同角度，只换清晰度与信息量（轮廓→磨损细节→关键刻字）。
- 闪回统一色调（偏灰/过曝）、时长 1–3 秒、只给一个新信息；每次给线索只推进"半步"——观众猜到方向、猜不到手法。

### 2.2 景别与运镜语言
- 跟踪与被跟踪：长焦偷窥感（前景虚化遮挡）、镜子/车窗/屏幕里的倒影构图。
- 审讯或对峙：越轴剪辑制造压迫，两人同框永远隔一个物件（桌子/审讯台/车）。
- 细节特写优先：指纹、账本、旧照片的折痕——悬疑的可信度在道具里。
- 复杂群戏先锁空间锚点与屏幕方向，再定景别变化；物证镜与集尾悬念镜用固定镜头；运镜克制（固定为默认），一段内 ≤2 种。

### 2.3 节奏与单镜复杂度（数字）
- 报告三层结构：段（一次生成）≤15 秒 → 段内切 2–5 秒 → 平均 3 秒一切。本平台一镜=报告一次"段"（一次生成 ≤15 秒，单镜档位 5–12 秒为平台既有约定）——段内 3–5 切的信息量由"相邻镜景别跳档 + 反应镜"承担。
- **反转节奏规范（保留并扩写）**：反转前 30 秒必须"让观众以为猜对了"——给一个强化错误判断的假线索，假线索本身必须真实可拍（不造假骗人）；反转镜用慢镜+静音，人物反应比事件本身多给 2 秒。
- 长台词/长 VO >20 字强制拆镜，每镜换景别、按语义停顿点切、不平均切；台词按 4 字/秒折算；含台词镜 ≥ 字数÷语速+停顿+1 秒余量；无台词镜 ≤6 秒。
- 同框 ≤3 人；切镜必须带来信息/权力/情绪/空间/节奏变化之一，相邻镜景别错开、禁连续 3 镜同景别；群演只给微动作（遮、瞥、垂、攥）。

### 2.4 情绪可视化与氛围语言
- 不写情绪写身体：隐忍=指节压白、呼吸变浅；崩溃=肩膀塌下去；恐惧=后退半步、手摸到身后墙面。
- 冷色调+顶光/底光审讯感；雨夜、监控雪花、时钟滴答声放大；环境替人说话——真相将揭在空旷冷清的走廊/惨白灯光，和解在雨停后的自然光。
- 暴力克制：出拳瞬间切反应，落点用音效补，比直给更狠。
- 声音只写环境音+音效、禁 BGM；关键证据用声画错位——画面拍反派得意的脸，声音先出录音里的认罪句。

### 2.5 常见钩子的镜头落法
- 集尾钩子三选一（保留）：新证据特写（只给局部）/ 反派出现在不该出现的地方（背影入画）/ 主角做危险决定前的深呼吸。
- 镜头错位：本集只给局部真实画面（他单手撑墙把人圈在墙角），下集全景揭晓（其实是在拦住要动手的人）；断在开口前一帧，下集首镜接"结果态"。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表（可拍 vs 必崩 + 替代拍法）
- 可拍：静态对峙（同框、隔一张桌、视线不交汇）；递放物件（已完成态）；单次推搡的定格姿态；跪/扶/按住；逆光轮廓剪影。
- 必崩 → 替代：打斗连招 → 只拍"起手定格+对方倒地"两镜跳切，中间用反应镜与音效跳过；泼洒/流血 → 只拍已完成的静态结果（血渍在袖口）；撞车/坠楼/火灾 → 拍旁观者反应+结果空镜；镜面同框（镜中看见凶手）→ 只拍背影与镜中局部物件；人群围堵 → 人群只作前景虚化遮挡；开锁/拆信/验指纹 → 改"动作已完成"的静态特写（锁已开、信纸已摊开）。
- 报告原则：保留内容必须能被 AI 稳定生成、避免生成端执行不了的动作；主动规避 AI 跳脸、画面不连贯、重复场景视觉疲劳。平台机制：以上类别在分镜 risks 标 motion/fluid/collision/mirror/hands/crowd。

### 3.2 参考图策略
- 必带：嫌疑人与反一号定妆三视图（正/侧/全身，脸与半身像一致）+ 常同框角色服装主色差异（防串脸）+ 场景主图。
- 优先级与上限：角色 > 场景 > 道具；首帧参考图预算 8 张（报告 @Image 上限 9，本项目按 8 执行），超预算先裁尾部道具/场景——角色必在预算内，杜绝悬空标注串脸。
- 犯罪现场/审讯室/豪宅宴会厅按场景主图参考，同场景多镜共用同一张环境参考图（报告·生成批次单）。
- 关键物证（账本、录音笔、旧照片、信物）出白底无手道具图——拿着道具的手是最常见污染；跨镜不变的外观写进正文；服装/伤势/湿污按"变体"处理（先写什么不变使它仍是同一资产，再写本集变化）。

### 3.3 易崩点与规避
- 文字类画面（账本、屏幕文字、新闻标题）高危：改为只拍纸张/屏幕边缘+手部动作，关键信息交给台词与 OS；必须呈现时逐行点亮+关键数值高亮一拍。
- 人物漂移：图生/文生由"有没有可读参考图"分流；文生镜必须写非空静态视觉锚点，**禁止只写"保持已有外观/preserve/keep"**。
- 服装/发型/长相不进画面描述（交参考图），只写动作、姿态、表情与状态变化（汗湿、泪痕、衣衫凌乱）。
- 同缺陷 ≥2 次停止盲摇（重摇硬上限 2–3 次）改提示词；重拍单变量，一次只改一个子句；同一招不连续用，重复镜头与重复场景的视觉疲劳会把观众划走。
