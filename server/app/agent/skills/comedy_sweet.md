## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
- 观众要的是「确定的甜」加「安全的笑」：笑点不能伤人，甜点必须兑现。报告 04a 心理级爽点建议本题材锁**归属**（被坚定选择）。
- 报告 04a CP 感四招：性格互补制造反差萌；用激烈冲突替代平淡相处（互动须有戏剧张力）；立体人设是 CP 感基础（能抡铁锤却在爱人面前拧不开瓶盖）；**禁忌——不可为追流行强加无关人设标签**。
- 报告 04a 高频情绪模板 2「误会-解开」甜虐布局：反派造谣（虐）→ 主角间冷战（委屈）→ 发现真相（震惊）→ 道歉加撒糖（甜）。

### 1.2 单集结构公式
- 报告 04a 黄金单集公式：**本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连**。落地：本集 = 一个甜点 + 一次误会拉扯 + 一个反转钩子。
- 报告 04a 甜宠类全剧节奏框架：契约绑定（第 1 集）→ 误会拉扯升温（2%~9%）→ 秘密曝光（≈10% 付费点）→ 情感破冰（11%~29%）→ 危机爆发（≈30% 付费点）→ 撒糖加打脸反派（31%~59%）→ 新危机（≈60%）→ 情感确认（61%~80%）→ 圆满结局（81%~100%）。
- 报告 02：每场必须改变至少一项（信息/权力/关系/情绪/物理状态/风险），无变化的场删掉或合并；报告 03 冷开场硬门：钩子是第一拍，落全集前 3 拍内。

### 1.3 情绪配比（数字）
- 报告 04a 原文：甜宠类 = 甜 60% + 微虐 30% + 惊喜 10%；并附禁忌——基调一旦确定不要中途大幅更改（甜宠剧突然加「全家惨死」的重度虐心，观众会出戏甚至弃剧）。
- 落到画面：甜 60% 全部要落在具体动作上（递水先拧开瓶盖、让出靠窗的位置）；微虐 30% 只是**误会与错过**，不写真正的伤害；惊喜 10% 给一次意料之外的当众维护。
- 报告 04a 单集情绪公式：1 核心情绪 + 1 辅助情绪 + 1 结尾钩子；同一集不超过 2 个核心情绪，配角情绪不能盖过主角。

### 1.4 节奏曲线（数字）
- 报告 04a 节奏 3-15-45：3 秒一个信息点、15 秒一个小冲突、45 秒一个转折，结尾用反转钩子卡死。
- 报告 04a 钩子黄金布局：开头 3 秒抛最强钩子；中段每约 30 秒埋一个小钩子；集尾定格在最高冲突那一刻，永不圆满收尾。
- 报告 04a 拉扯：约每分钟一次晃弹簧，每三分钟完成一次完整「压—弹」，只一压一弹仅算及格，须来回晃 ≥3 次。
- 报告 07 确定性折算：台词 4.5 字/秒、动作 2.5 秒/拍，每集时长达标线 ±15%；单集正文 ≤1000 字、语速 150 字/分钟。

### 1.5 爽点配方
- 报告 04a 爽点核心公式：**爽点 = 装 + 打脸 + 震惊 + 收获**。
- 甜宠改写（**报告未给出甜宠版，建议值**）：装作不在意（藏起心意、嘴硬）→ 当众承认或当众维护（打脸落在「他是我的人」而不是压制别人）→ 围观同事朋友的起哄反转（震惊，要轻不要恶）→ 关系升级加一个小礼物（收获）。
- 报告 04a 心理级爽点：本题材的核心是**归属**——被坚定选择，而不是赢过谁。

### 1.6 反转与钩子模板
- 报告 04a 股价级反转三式：预期误导 / 人设颠覆（**只能用在配角，绝不能动主角核心底色**）/ 动机置换；全剧 ≈3 个，多了审美疲劳。
- 报告 04a 钩子级反转三式（单集 ≤1 个）：道具伏笔反转（高频出镜小道具翻转真相）/ 情绪回弹反转（拉满预期 → 踩碎 → 极致回弹，完播保底神器）/ 镜头错位反转（最易上手，每集结尾可套）。
- 关系内部钩子四类：身份颠覆 / 人性撕碎 / 胜负碾压 / 真相反转（本题材只用轻量档）。
- 反模板纪律（报告 02/03）：**不为检查表硬加秘密、反转或人物弧**；若自检让剧本长出输入没有要求的机关，撤掉机关而不是替它找理由。

### 1.7 台词特征
- 报告 04a 台词节制：单句 ≤20 字（竖屏阅读速度），单角色单次 ≤50 字，台词量按 150 字/分钟 推算；单镜台词 >20 字须拆镜。
- 报告 04a 台词 6 条：精准戳点、贴合角色性格（遮挡名字仍能判断说话人）、善用高效潜台词但不写晦涩潜台词、接地气说人话、摒弃无效台词、开篇台词聚焦主情绪。
- 甜宠质地（**建议值**）：暧昧期台词说一半留一半（「其实我……」），口是心非要配相反的动作；报告 04a 展示不要告诉——能靠一个眼神传递的信息坚决不用嘴说。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 包袱节奏规范
- 三段式包袱：铺垫（正常中景）→ 停顿（反应镜 1 秒）→ 爆点（表情特写+音效）。
- 视觉笑点优先于台词笑点：人物卡门框、假发歪了、拿错手机——画面自己会笑。
- 误会是喜剧引擎：错位构图（观众看得到双方，角色互相看不见）一次一个，别贪多。
- 报告 03：反应镜是免费的戏——重台词后切听者的脸 2–3 秒，不用写词，喜剧的停顿就落在这里。

### 2.2 心动镜头语言
- 心动三件套：突然靠近的呼吸感特写、指尖相触慢镜 1.5 秒、对视后同时移开的视线。
- 高甜瞬间配「世界抽空」：背景虚化+柔光+环境音渐弱，只留两人。
- 吃醋/吃糖交替喂：上一场虐、这一场甜，单集至少一组对比（对应报告 04a 甜 60% + 微虐 30% 的配比落地）。

### 2.3 景别与运镜语言
- 轻喜剧多用对称构图与干净的固定机位，制造「日常感」；尴尬时刻用急推急拉。
- 空镜转场：奶茶、宠物、共享单车——城市生活的呼吸感（日常/治愈题材可替换为街头小吃、窗台植物、便利店灯箱）。
- 打闹戏手持跟拍但保持画面明亮，人物永远占画面上 2/3（情绪向上）。
- 报告 03 运镜克制：固定镜头是默认；推给情绪、拉给收场、跟给移动；一段里超过两种运镜就该问自己是不是在炫技。

### 2.4 节奏与单镜复杂度（数字）
- 报告 07/03 三层结构：段 ≤15 秒；分镜 2–5 秒【硬门】；段内 3–5 切。
- 报告 04a：片段累计 ≤15 秒；含台词镜时长 ≥ 台词字数 ÷ 4 字/秒 + 标点停顿（每标点 0.3–0.5 秒）+ 1 秒安全余量；无台词镜 ≤6 秒；画面描述 15–50 字。
- 报告 03：同框 ≤3 人，超了必须给拆解；报告 04a 群演只用微动作（遮、瞥、垂、攥）服务当前戏核情绪，不抢主角戏、不单独配台词。
- 轻喜剧专属（**建议值**）：笑点停顿镜固定 1 秒（原包即 1 秒），甜点镜可放到 3–5 秒；报告 03 动接动——切点选在动作中间而不是动作完成后。

### 2.5 情绪可视化
- 报告 03 锚点标准：锚点要「可画、可认可、可核对」——「补丁船篷」是锚点，「陈旧的氛围」是形容词。
- 报告 07：禁情绪形容词，写可拍的生理与动作细节（写呼吸变浅，不写她很紧张）。
- 报告 04a 环境通道原文：甜蜜温暖用夕阳、暖光客厅、满桌家常菜；情绪表达四通道为行动 / 语言 / 环境 / 独白。
- 甜宠情绪表（**建议值**）：心动 = 手指无意识绕线、喝水时眼睛越过杯沿看人；吃醋 = 把对方的杯子往自己这边挪一寸；嘴硬 = 转身后嘴角压不住地上扬。

### 2.6 常见钩子的镜头落法
- 集尾用「差点说出口的话被打断」或「一条发错群的消息」，甜而不虐。
- 报告 04a 镜头错位反转：给观众 100% 真实的局部镜头误导 → 集尾卡住 → 下集全景揭晓（特写两人靠得极近，全景=他在替她挡货架）。
- 报告 04a VO 音画同步：消息、短信这类文字信息按普通台词处理，原文 100% 写进台词位且画面照常演动作反应；屏幕纯文字须逐行点亮加滴答音效，关键数值单独高亮一拍，禁整块静态显示。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表
- 报告 03：动作节拍只写 AI 见过千万次的常见动作（挑担上船、搭手卸担）；精巧动作（伸篙一挡、睫毛颤）生成必崩。
- 可拍（**建议值**）：牵手、并肩走、递东西、回头、坐下、轻拍肩、拨刘海。
- 高风险：快速打闹追逐、扔接物品、拥抱旋转、亲吻特写、多人同时做不同动作。
- 替代拍法：亲吻 → 只给额头靠近一拍加切空镜（灯、窗帘、晃动的杯子）；打闹 → 只给手部与衣角，不给全身纠缠。

### 3.2 参考图策略
- 报告 05：角色三视图定妆（正面/侧面/背面）跨集复用，每角色固定音色；报告 07：一致性 > 美观。
- 报告 03：每张参考图只控制身份、造型、地理、构图或风格中的明确部分（参考图单一职责）；空景参考图里混进人，一致性全毁（环境与角色是两层资产）。
- 甜宠专属（**建议值**）：男女主各一张三视图，双人同框镜两张都挂，避免串脸；表情差异靠提示词写，不靠换脸；报告 03 道具设定图纯白底、**无手**、必带尺度短语。

### 3.3 易崩点与规避
- 手部接触与亲吻：两人肢体粘连易糊——拆成接触前一拍加接触后一拍，中间不拍接触瞬间。
- 镜面与屏幕：玻璃窗、手机屏、后视镜反光会糊成一片——屏幕内容改走 VO 台词位加逐行点亮（报告 04a），不要求模型渲染文字。
- 文字类笑点（招牌、聊天记录、便利贴）交给画面外——报告 05 绝对禁止项含字幕、水印、logo 与六指，画面里出现文字即高风险。
- 群戏人数漂移——报告 03 同框 ≤3 人；报告 04a 群演只给微动作（遮、瞥、垂、攥），焦点始终锁定主角两人。
- 声音只写环境音与动作音（报告 04a 音效禁配乐），配乐交给配乐层；报告 03：声景也是动作指令，画面动作改了声景必须一起改。
