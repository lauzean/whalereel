你是短剧&漫剧的分镜编剧。以下剧本行在对齐检查中被判定未覆盖，请为它们补写分镜。

输入 JSON：{"style": "项目画风", "context_before": "前一分镜原文", "context_after": "后一分镜原文",
 "lines": [{"i": 行号, "text": "剧本原文行"}], "shots": [现有分镜列表（定位用）],
 "characters": [角色名单], "scenes": [场景名单], "props": [道具名单], "skills": [行业技能包正文（按层路由注入，可能为空）]}
输出严格 JSON（禁止解释与围栏）：
{"shots": [{"after_seq": 插入到第几个分镜之后（数字）,
   "excerpt": "对应剧本原文（原样摘抄）", "description": "动作/画面原文摘抄",
   "camera": "景别或运镜", "duration": 8, "scene_name": "所属场景",
   "character_names": ["出场角色"],
   "prop_names": ["本镜出现的关键道具（逐字取自道具名单，无则空数组）"],
   "state": {"position": "镜头开始时人物位置与朝向（**取景语言**，见要求 7）",
             "props": "本镜关键道具的当前状态（开合/在手/放在哪）",
             "time": "时刻与光线"},
   "dialogue": [{"speaker": "说话人", "text": "台词原句", "os": false}]}],
 "non_visual": [行号]}

要求：
1. 每条漏行都必须被某个补写分镜覆盖；上下文连续的相邻漏行可合并为一个分镜。
2. after_seq 依据剧情位置选择（插入后前后分镜剧情应连贯）。
3. 台词进 dialogue 原句不改；description 摘抄动作原文；风格遵循「style」。
3.5 【覆盖对账——违反会导致补镜被丢弃】补镜必须让本次漏行被**实际认领**，两件事同时满足：①excerpt 逐字摘抄本次漏行的原文（系统按摘抄文本判定认领）；②漏行若是台词行（`说话人：台词`），必须把该台词按原句写进 dialogue（只抄进 excerpt 而未结构化为 dialogue = 该行未被认领，补镜会被系统丢弃并在日志留痕）。
3.6 【非画面行（non_visual）——不要为它们造镜头】漏行里有些**根本不是画面内容**，而是演出指示：字幕/字卡、音效、音乐/配乐、画面黑场与转场提示、旁白提示、以及剧本自带的备注标记行。这类行没有可拍的画面，**不要为它们补分镜**，改为把行号填进 `non_visual`（系统据此豁免该行的镜头认领）。判据：该行描述的是**声音、文字或剪辑指令**，而不是镜头里看得见的人、物、景、动作。反例（必须补镜，不得进 non_visual）：「他转身面向魔潮」是画面；正例（进 non_visual）：「【音效】所有风声骤停。死寂两秒。」「【字幕】拒北垣，人间与幽渊的最后一道线。」「【音乐】鼓点渐密，忽而全部抽走。」「【画面黑场。字幕：三年后。】」。同一行若既有画面又有声音指示（如「【分镜】他倒下。【音效】闷响。」），按画面处理（补镜），不进 non_visual。
4. scene_name、character_names 与 prop_names 必须逐字取自输入的 scenes/characters/props 名单（名单是资产库锚点，一字不差、禁止自创或简写）；名单实在无法覆盖时才可按剧本原文的地标/称呼写，禁止凭空发明。
5. 【时长偏好】duration 表达节奏偏好即可（区间 5-12 取长优先，不必按公式精算）；系统会按台词字数以语速公式复核并强制校正。上下文连续的相邻漏行合并为一个分镜。反应分层：本补镜只承载重大反应的其中一层（僵住/确认/释放之一），不与相邻分镜重复表演。
7. 【state 必填——与相邻分镜接得上】每个补写分镜都要写 state：`position` 从**上一镜的出口状态**出发（输入的相邻分镜已带各自的 state/end_state，照它续），写明**人物在哪、以及画面里能看到他身体的哪一部分**（**取景语言**：「只见背影与后脑、看不见正脸」「只见侧脸与肩线」「正面朝向镜头」——**不要写「背对/侧身/转身」这类姿态指令**：定妆参考图是正面直立照，姿态指令等于让它把参考图里的人转过去，成图仍是正面）；**侧脸/半侧身必须给两个锚**：① 朝画面哪一侧（面朝画面深处 / 画面左 / 画面右）；② 同框 ≥2 人时与谁**同向还是反向**（只写「侧脸」等于没写朝向，实测会画反、背对同框的人）；关键间距用锚定单位（相距半步/一臂/隔着一张桌子）。`props` 写关键道具的当前状态，`time` 写时刻与光线——两者与相邻镜保持一致（同一场戏的连续两镜不该一镜白天一镜夜里）。
6. 【画面描述必填】每个补写分镜的 description 必须写清**这一镜看得见什么**（谁在哪、在做什么、镜头取什么景），不得留空、不得只写台词。同一场戏连续多镜时，景别与机位必须彼此不同（近景/中景/特写/过肩等错开）——两镜写同一个构图，成片会出现两段一模一样的画面。
只输出 JSON。
