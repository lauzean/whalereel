## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
观众要的是「弹簧」：先被甜到心跳，再被虐到心疼，最后必须兑现。甜宠的爽点是「被唯一选择」，虐恋（追妻火葬场）的爽点是「他终于知道错了」。
- 情绪基调：甜 60% + 微虐 30% + 惊喜 10%（报告类型情绪基调表）；不中途大改基调（甜宠突然插入重度虐心＝严重）。
- 爽点锁一种：归属（被唯一选中）或秩序（误会逐条还原真相）。
- 落地：甜由同一件小事反复兑现（他总在楼下买同一款糖），虐就是它被打破（便利店拆了），反转再补回来（他学会了做糖）——同一物件承载甜与虐才形成对照。
- 双向题材要让两边各有一次「主动选择」的画面，不能只有一方在追。

### 1.2 单集结构公式
本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（黄金单集公式）。
- 每场必须改变至少一项：信息/权力/关系/情绪/物理状态/风险，无变化就删或并场。
- 每场至少一个动作节拍（纯对白场是广播剧，AI 没有画面可写）；单集三栏齐全：钩子 + 悬念 + 甜点（或虐点）认领。
- 整集可套「误会-解开」甜虐布局（报告情绪模板 2）：反派造谣（虐）→ 冷战（委屈）→ 发现真相（震惊）→ 道歉 + 撒糖（甜）。

### 1.3 情绪配比（数字）
- 甜 60% + 微虐 30% + 惊喜 10%。
- 虐恋阶段配比：前期误会伤害 1%–20% → 男主悔悟 21%–40% → 追妻受阻 41%–70% → 真诚悔改+和解 71%–100%（报告类型节奏框架）。
- 单集 = 1 核心情绪 + 1 辅助情绪 + 1 结尾钩子；核心情绪 ≤2 个；配角情绪不能盖过主角。
- 每集正文 500–800 字须覆盖爆点/虐点/甜点至少一个（硬性）；连续 3 集无爆点＝严重。
- 虐点逻辑：关系越紧密虐感越强；先给极致幸福再夺走；经典虐点＝牢记的人忘了自己 / 说不出口的爱意 / 无人知晓的牺牲 / 至死未解的误会。

### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个情绪冲击、15 秒一个剧情变化、45 秒一个强期待（雨中告白 → 转身撞见合照 → 没发出的那条消息）；强期待里必须留出主角做抉择的时空。
- 开场 3 秒抛最强钩子、2 秒防划走、5 秒勾住人；第 1 集前 10 秒交代主角是谁/什么危机/核心冲突。
- 开头 3 秒最强钩子 + 中段每约 30 秒一个小钩子 + 集尾定格最高冲突；永不解决问题、永不圆满收尾。
- 甜宠节奏框架：契约绑定（第 1 集）→ 误会拉扯升温（2%–9%）→ 秘密曝光（≈10%）→ 情感破冰（11%–29%）→ 危机爆发（≈30%）→ 撒糖+打脸反派（31%–59%）→ 新危机（≈60%）→ 情感确认（61%–80%）→ 圆满结局（81%–100%）。
- 付费卡点在第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集（±2 集内）；感情流卡点必须绑定情感阶段转变（无感→好感→醒悟→确认心意→表白），每卡点 ≥1 个可剪 30 秒投流点。
- 拉扯：约每分钟晃一次弹簧、每 3 分钟一次完整「压—弹」；全剧来回晃 ≥3 次，只一压一弹仅算及格。

### 1.5 爽点配方（装 → 打脸 → 震惊 → 收获）
- 装：他把在意藏起来——公司都知道他刻薄，只有观众看见他深夜替她改完方案。
- 打脸：当众被质疑「她配不上」时，他把从第 1 集留到现在的证据摆出来（为她买下的老宅、她随手画的图被裱在客厅）。
- 震惊：围观者态度 180° 反转——嘲笑过她的亲戚集体噤声、随后改口；收获：关系从「合约」升格到「公开」（戒指从抽屉里拿出来、户口本被放在桌上）。
- 三段拍法：①围观现场全景（她被围在中间）②证据特写（旧照片、签了字的合同）③态度反转（同一批脸从讥笑到僵住，逐个给 2–3 秒反应镜）。
- 先压后爆：从第 1 集压到第一个付费点前才给反击信号；压得越狠反弹越爽。

### 1.6 反转与钩子模板
- 股价级反转全剧 ≈3 个（>4 或 0 均为问题），骨架阶段定死，预埋集必须早于揭晓集。
- 甜宠常用预期误导（她以为他在办离婚、其实在办婚礼，线索从第 10 集就在画面里）；人设颠覆只用在配角（男二/女二），不动主角核心底色；动机置换＝他的冷漠其实是保护；不藏信息、画面 100% 真实，空降硬凹＝烂尾。
- 单集钩子级反转 ≤1 个：道具伏笔（信物颠覆用途）/ 情绪回弹（拉满→踩碎→回弹卡结尾）/ 镜头错位（真局部误导，下集全景揭晓）。
- 集末钩子两套并用、不可全是悬念：关系内部钩子（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）。
- 高频形态：差点说出口的话被打断 / 发错群的消息 / 只看到一半的短信 / 门缝里听见半句。

### 1.7 台词特征
- 单句 ≤20 字（竖屏阅读速度），一口气上限 ≤35 字、单角色单次 ≤50 字。
- 要展示不要告诉：禁自爆家门式台词；动作 > 台词——他把外套披上去，不说「我怕你冷」。
- 对白必须在争取/回避/试探/逼迫/重新定义关系；潜台词高效不晦涩，一遍就懂。
- 谁的话像谁：句式偏好 + 2–3 个全剧口头禅——他的口头禅越冷，反转时说出口才越重。
- CP 感四招：性格互补反差萌（玲珑鬼精灵 × 天然呆）/ 用激烈冲突替代平淡相处 / 立体人设（能抡铁锤却在爱人面前拧不开瓶盖）/ 不为追流行强加人设标签。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 双人对话正反打：说话人中近景（肩上过），反应镜给听者微表情；谁的台词信息量大，谁的脸给得近。
- 心动三件套：突然靠近的呼吸感特写 → 指尖相触的慢镜 1.5 秒 → 对视后同时移开的视线。
- 高甜瞬间配「世界抽空」：背景虚化、环境音渐弱只留两人（虚化靠浅景深构图，提示词不写光影词）。
- 吃醋 / 吃糖交替喂：上一场虐、这一场甜，单集至少一组对比。
- 关系升温用距离镜头语言：隔桌全景 → 并肩中景 → 同框特写；疏远反着走（物理距离即心理距离）。
- 运镜语义：手持轻晃＝不安，缓推＝告白前奏，固定长镜＝对峙；固定是默认，一段超两种运镜就是炫技。
- 进场三件套：第一切必须有主体运动（静物特写开场是死画面）→ 大远景定场 → 关键局部特写；重台词后切听者脸 2–3 秒。

### 2.2 节奏与单镜复杂度（数字）
- 段（一次生成）≤15 秒、不跨场次；段内分镜 2–5 秒（硬门），3 秒一切是短剧的呼吸。
- 甜戏取 3–5 秒慢一点；争吵 / 吃醋戏压到 2–3 秒；单镜同框 ≤3 人，超限必须拆镜。
- 台词装得下：镜头秒数 ≥ 认领台词字数 ÷ 4.5 + 2 秒余量；无台词镜 ≤6 秒。
- 一镜画面描述 15–50 字；超 8 秒或含场景切换＝过度合并；整集时长落在目标 ±15% 内。
- 每集给一个 5 秒安静镜头（心动或心碎瞬间，环境音抽走只留呼吸）；欲言又止配视线镜：看 → 躲 → 再看。

### 2.3 情绪可视化（可拍细节）
禁情绪形容词，只写能拍到的动作与状态：
- 心动＝呼吸变浅 + 耳尖泛红 + 拿杯子的手停半秒 + 视线看→躲→再看。
- 吃醋＝表面微笑但把杯子推远 + 视线从对方脸上移到旁人身上 + 手指敲桌面。
- 委屈＝眼眶先红 + 下唇咬出白痕 + 笑一下才落泪；心碎＝听见关门声后肩膀塌下来，维持微笑 3 秒才落泪（先给极致幸福再夺走）。
- 决绝（追妻）＝雨里站定不追 + 把伞收起来 + 转身时手插兜攥紧。
- 四通道择一或叠加：行动（撕扯、握拳、颤抖的手）/ 语言（痛斥、语塞、泣不成声）/ 环境（阴雨、空街、满桌家常菜）/ 独白（难言之隐用 OS 或 VO）。
- 光照不写光影词，走场景衍生资产（「客厅·傍晚版」）；转场用生活动势（关门、挂电话、电梯门合拢），不硬切。

### 2.4 常见钩子的镜头落法
- 差点说出口：说话人近景说到一半 → 切打断源（手机震动特写 / 第三人进画）→ 定格在张着嘴的脸。
- 发错群的消息：手机屏幕逐行点亮 + 滴答音效（关键行单独高亮一拍）→ 切看手机人的脸 → 群里逐条「撤回」提示。
- 只看到一半的短信：屏幕特写，关键行入画即卡 → 切主角表情。
- 撞见：给 100% 真实的局部镜头（特写他单手撑墙把人圈住）→ 定格 → 下集全景揭晓（他在拦要搞事的人）。
- 段尾留钩：悬念必须是具象物（信物、没关的门、亮着的手机），不是抽象情绪。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表（可拍 vs 必崩 + 替代拍法）
可拍：靠近、后退半步、轻拉手腕、递伞、披外套、擦眼泪、拥抱、背对背坐着、并肩走路、放下杯子、把戒指推回桌上、关门。
必崩 → 替代：
- 接吻 / 贴脸拥抱 → 用头靠肩的侧影、手部特写、听者反应镜三镜替代，不拍对面部贴合。
- 扇耳光 / 推倒 / 摔东西 → 拆两镜：抬手定格 → 结果镜（脸偏过去、杯子碎在地上）。
- 雨里长跑追车 → 拆三个 2–5 秒分镜（起步背影 → 雨中中景 → 停下喘息特写）。
- 精细手部（戴戒指、系扣、拆信）→ 物件特写 + 手入画即止；慢镜升格 → 用动作起始态 + 结果态两镜替代。
依据：只写 AI 见过千万次的常见动作，精巧动作生成必崩。

### 3.2 参考图策略
- 先锚后变：人物三视图（正 / 侧 / 全身）＋半身近景；三视图的脸必须与半身像一致、全身比例协调。
- 服装变体不是新身份：居家 / 礼服 / 职场是同一角色的变体；参考图单一职责（身份 / 造型 / 地理 / 构图 / 风格只控制明确一部分）。
- 信物类道具必须有独立的白底无手参考图（戒指、信、照片、保温杯），否则每帧长得不一样；尺度短语必写，防把手持道具画成家具尺寸。
- 优先级（报告未给出，建议值）：①男女主定妆 ②对手 / 关键配角 ③主场景空景 ④信物道具（含开合等状态变体）⑤光照变体场景；图与文冲突时模型听图的。

### 3.3 易崩点与规避
- 禁光影色调词（光 / 影 / 逆光 / 色温 / 色调 / 暖色 / 冷色），光照走场景衍生；音效只写环境音 + 动作音，禁 BGM / 配乐 / 乐器烘托（画面动作改了，声景必须一起改）。
- 外观（服装 / 发型 / 长相 / 妆）不进画面描述，只写动作、姿态、表情与当下状态变化（汗湿、泪痕、妆花了）。
- 在场人物不能消失：未离场角色每镜要有视觉落点（背景 / 局部 / 反应镜 / 虚焦剪影 / 前景遮挡）；群演只做微动作（遮、瞥、垂、攥），不配台词。
- 冻结关键帧只投影镜头起点，删掉终点才出现的动作、姿态、道具状态；同义重复镜头删掉，同一动作不跨镜重复，终点能成为下一镜可信起点。
- 八病自查：舞台剧病 / 均匀病 / 秒数漂移 / 台词爆仓 / 声景漏改 / 换景不换段 / 改切不读邻切。
- 反模板条款：不为检查表硬加秘密、反转或人物弧；若自检让剧本长出输入没有要求的机关，撤掉机关而不是替它找理由；审片意见须带位置 / 引文 / 影响 / 修订结果，不能只说「AI 味」「不够电影感」。
