> 依据：火山方舟《Seedream 4.0-5.0 提示词指南》（12 页）+ 本系统实测。

## 一、提示词结构（四要素公式）

```
主体 + 行为/状态 + 环境/背景 + 风格/美学
```

一段连贯中文，**不用英文 tag 堆砌**；负面词由节点参数单独传，不写进正向提示词。

**官方口径与我们的实测一致**：本系列「对文本提示的理解能力更强，能在较少描述下
生成符合预期的画面」，**简洁精确的提示通常优于重复堆叠华丽复杂的词汇**。反面示例
（官方原文）：`一个女孩，撑伞，林荫街道，油画般的细腻笔触`——**碎片化堆砌会被逐词
注意力分散**，正确写法是 `一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈
油画风格`。

## 二、长度红线（本模型最敏感的一项）

**建议 ≤300 汉字——过长会分散模型注意力，主体被稀释。**

这是**实测踩过的坑**：我们的首帧提示词曾达 1171 字（约束样板占 63%，主体描述仅 17%），
远超本模型建议——结果是**约束句人人遵守、主体细节反而变弱**。

**收敛优先级**（超长时按此砍）：
1. 删除重复的约束声明（同一件事只写一次）；
2. 合并同类约束成一段（如把「人物仅限/严禁复制参考图/每人只出现一次」合成一句）；
3. 压缩解释性文字（"必须"、"严禁"之外的解释语气全部删掉）；
4. **最后才砍画面内容**——主体与关键物件是模型最需要的。

参照图场景可略增（参考图本身承担了部分外观描述），但仍应宁短勿长。

## 三、文字渲染（本模型强项，善用）

- **要生成的文字内容放在双引号中**（官方明确要求）：`生成一张海报，标题为 "Seedream 4.5"`
  ——不写引号时模型容易把文字画错或漏画；
- 明确写**文字内容、字体风格与位置**；这是少数能渲染中文的模型，不要浪费；
- 官方建议**优先使用常用字**，避免生僻字与特殊符号。

## 四、参考图生图（两部分必须都写）

官方要求提示词中明确两部分内容：

1. **指明参考对象**——清晰描述希望从参考图中提取并保留的元素（「参考图中的人物
   形象」「参考图中产品材质」）；
2. **描述生成画面**——具体说明希望生成的画面内容与场景细节。

- **改写类要有"保持不变"声明**：`改变 X，保持人物面部特征与服装不变`——只说改什么、
  不说保持什么，模型会连不该动的一起改；
- **多图输入必须逐图指明用途**（官方示例：「用图一的人物替换图二的人物，并参考图三
  的风格进行生成」「让图一人物穿上图二的服装」）——不逐图指定时，模型会把每张参考
  图的内容都画进画面；
- 有明确需保持的特征（角色形象/视觉风格/产品设计）时，用参考图比用文字描述更可靠。

## 五、美学增强词（四类，置句尾）

| 类 | 可选词 |
| --- | --- |
| 风格 | 写实 / 插画风 / 国风 / 赛博朋克 |
| 光影 | 工作室灯光 / 侧逆光 / 柔和散射光 / 冷色调 |
| 构图 | 特写 / 中全景 / 广角 / 俯视角 / 浅景深 |
| 质感 | 电影级 / 超清晰 / 细节丰富 / 金属质感 |

**描述要具体**：「侧逆光勾勒发丝轮廓」优于「高级感光影」（后者零信息量）。有明确
风格需求时，**精准的风格词或参考图**都能显著提升风格渲染效果。

## 六、易崩点与规避

| 风险 | 规避 |
| --- | --- |
| 主体被稀释 | 严守 ≤300 字红线（见 §2） |
| 姿势与正面冲突 | 定妆图禁写姿态词（侧身/背对/转身）与机位词（仰拍/俯拍） |
| 多人参考图混淆 | 参考图 ≤4 张；**逐张明确职责**（见 §4） |
| 空镜出现人脸 | 场景提示词**不得出现任何含「人」的字样**（含否定句） |
| 半身截断 | 服装从上到下写全（上装/下装/鞋履） |
| 多余肢体 | 正向声明「两条手臂、两只手（每只手五根手指）」+ 末尾复锚一次 |
| 人物 ID 漂移 | **人脸特写 + 全身照组合**（`面部特征参考图片1（大头照），妆造参考图片2`），**避免多视图**——同一人物多角度会被识别成多个主体 |
| 画面泛白/塑料感 | 本系列已改善泛白问题；仍出现时优先**减少堆砌**而非加词，检查是否超长 |

## 七、参数与端点

- **参考图上限 4 张**（端点能力，超出由系统按预算裁剪并在生成参数中外露）；
- **seed 不支持**：方舟端点静默忽略（同 seed 两次出图不同，实测确认），系统不下发；
  需要多样选择时用「数量 >1」而非固定种子。

## 操作纪律（对 LLM 的硬约束，违反即不可用）

- **不得降级或替换模型**：用户配置了哪个模型就用哪个（含档位与端点）；不可用时报错并说明原因，**禁止自行改投其它模型或档位**——这与项目「禁止静默回退本地推理」同源：失败要看得见，不要悄悄换个差一点的。
- **组装之后不再改写**：系统组装完成的提示词（@引用解析、参考图预算裁剪均属**组装环节**，允许）到端点之间**零改写**——不追加标题/前缀/后缀/风格词/质量词，不改标点与换行。参数（画幅/时长/参考图）一律走独立字段，不写进提示词正文。
- **不使用 `--` 符号**：该符号之后的内容可能被模型截断，不会被解析或响应。

**本模型专属**：

- **I2I 输入图引用用 `[img0]`、`[img1]`**：生图阶段**不得**用 `@图片`／`图1`／`参考图1` 这类格式（`@图片N` 只用于视频生成的 I2V）。
- **保留项不得只写「保持不变」**：必须逐项列明主体身份、结构、构图关系、位置比例、透视角度、光影方向、材质细节、文字样式、层级关系。
