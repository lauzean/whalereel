## 一、剧作层（注入：审读 / 创作 / 拆解）

### 1.1 台词必须适配镜头时长（硬约束）
- 单句台词**3 秒内只能说一两句短语**；写长台词等于让模型赶节奏或吞字。
- 一场戏的台词总量按 **3.5 字/秒**折算（口语基准），超出的部分拆到相邻镜头。
- 长篇旁白是红线：设定要落成**可拍物**（门派等级→牌匾与服色、内功深浅→呼吸长短与脚印深浅）。

### 1.2 每场戏至少一个明确节拍
- 节拍类型：亮相 / 破冰 / 打脸 / 反转 / 转变 / 情感闭环——写不出节拍的场次应合并或删。
- 情绪必须外化（见 §3.4），**禁止用解释性台词替代节拍**（「不要说他坏，让他踩碎主角的救命药」）。

### 1.3 符号系统（跨阶段一致的硬契约）
| 信息 | 符号 | 示例 |
| --- | --- | --- |
| 音乐 | `()` | `(背景中播放着快节奏的摇滚乐)` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}`（小语种须标语种） |
| 旁白 | `『』` | `『旁白：三年前的那个雨夜……』` |
| 字幕 | `【】` | `【第一章：启程】` |
| 镜头头 | `[ ]` | `[景别｜视角类型｜机位状态｜角度与朝向]` |

**两条禁令**：① 提示词中**不使用 `--`**（该符号之后内容可能被模型截断）；② 画面描述里**不得用 `{}` 包台词**（台词只进声音字段）。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别（7 级，按情绪目的选）
大特写（面部局部，放大极致情绪）→ 特写（头肩，聚焦表情）→ 近景（胸部以上，表情+肢体）→ 中景（膝/腰以上，对话常用）→ 全景（全身+小环境）→ 远景（人物占比极小，环境为主体）→ 大远景（人物成一个点，史诗开场/收尾）。

### 2.2 视角与 POV 规则
- 三类：第三人称客观视角 / POV 第一人称视角 / POV 与第三视角切换。
- **POV 三要件**：① 从该角色**眼睛高度**出发；② 写清视线方向、被看对象位置、可见的**手部/道具/衣袖/伤痕**等前景元素；③ **POV 镜头中不能出现该角色完整正脸**。
- **禁止**把 POV 写成自拍、监控、无人机或过肩镜头；需要过肩就写「过肩镜头」。
- 切回第三人称必须写清机位、主体朝向与动作承接；**视角切换时服装/发型/道具持有状态/光影方向/场景锚点必须连续**。

### 2.3 运镜（三组；一次只主导一种）
- **基础**：推镜（聚焦、拉近心理距离）、拉镜（揭示环境、疏离感）、摇镜、移镜（轨道平移，空间感）、升降镜。
- **情绪**：环绕（对峙/展示关键物）、手持感（纪实、紧迫）、希区柯克变焦（得知惊天秘密的震惊）、呼吸感（长凝视）。
- **冲击**：甩镜转场、格挡震动、子弹时间、冲刺跟拍（后三类**属高危**，见 §3.3）。

### 2.4 拍摄角度与主体朝向（AI 生成一致性的关键字段）
正面（面部表情、情绪爆发）/ 侧面（轮廓、对话交锋）/ 半侧面 3/4（最常用）/ 背面（神秘、疏离）/ 仰拍（威严压迫、主角觉醒）/ 俯拍（渺小受挫、全局）/ 平视（客观常规）。

### 2.5 光影与色调（三轴）
- 质感：硬光（轮廓分明、冲突感）/ 柔光（干净治愈）/ 伦勃朗光（三角光斑）。
- 方向：侧光（强烈明暗对比）/ 逆光（金边轮廓、剪影）/ 底光（恐怖悬疑）。
- 色调：低饱和（内敛忧郁）/ 冷色调（悬疑/赛博）/ 复古胶片（怀旧）。

### 2.6 连续性规则（可确定性核对）
- **角色与道具命名强一致**：同一角色/道具全程使用**完全一致的称呼**——**不得中途改用「他/那个男人/少年」等代词或别称**。
- **禁止群体量词概括角色**：不写「三个人面面相觑」「众人大惊失色」「反派们冲了上来」；必须**完整写出当前镜头内所有具体角色名**（如「黄衣小哥，粉裙少女，灰头发老太 面面相觑」）。
- **因果衔接**：每个镜头末尾写清转场（`[硬切]`/`[叠化]`），前后镜必须因果相扣（上镜扔出文件 → 下镜必须有人低头看）。
- **道具落点**：上镜抛出道具，下镜必须交代落点或反应。
- **多主体标签法**：同镜多主体时，**在描述开头用稳定标签定义**（如「前景的高个男人是警察」），后续每次提到该主体都**不省略主语**。

## 三、模型适配层（注入：画面描述 / 首帧）

### 3.1 单镜只用一种运动（本链路最高频的稳定性来源）
「每个镜头尽量只指定 **1 种**主要运镜方式；**不要在同一镜头同时堆叠推、拉、摇、移、环绕**，避免画面不稳定。」
- 复合运镜需求 → **拆成相邻两镜**，各自一种运动。
- 运镜与人物动作**分开表述**，避免混写导致模型把运镜和动作搅在一起。

### 3.2 首帧取「稳定态」，避开高动态瞬间
- 首帧应取该镜头**动作/状态到位后的稳定态**，**避免高动态模糊瞬间**。
- **不适合作为首帧**：纯转场/黑场/空白帧；**极高动态模糊镜头**（甩镜转场中段、冲刺跟拍中段）。
- 起手即高速运动的镜头，首帧要落到可静止描述的状态（起势前的静止/落地后的定格）。

### 3.3 高危动作禁用清单（除非剧情必须）
**优先低缓连续小动作**：缓慢行走、轻轻抬手、顺势坐下。
**避免**：狂奔、大跳、翻滚、复杂打斗等大动态不稳定动作。
**必须写明惯性与承接**（「借着转身惯性顺势抬手」「从停顿状态自然过渡到举手」）。
高风险镜（fluid/mirror/collision/transform）**只呈现结果状态**，过程靠声音与反应镜头暗示。

### 3.4 情绪外化对照表（禁情绪形容词）
| 情绪 | 可拍的身体细节 |
| --- | --- |
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识攥紧衣角、泪水在眼眶里打转 |
| 喜悦 | 嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快 |
| 紧张/焦虑 | 频繁看手表、手指不停敲击桌面、呼吸急促、无意识啃咬指甲 |
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀、从牙缝里挤出话语 |
| 释然 | 长长舒一口气、紧绷的肩膀完全放松、脸上露出淡淡微笑 |

### 3.5 方向性物体空间关系公式（一类高频翻车）
**适用**：手机屏幕、平板、显示器、画纸、镜子、书本、车门、武器、杯子把手。

**公式**：`人物朝向 + 视线方向 + 物体朝向 + 手部动作 + 画面可见的物体面 + 物体与人物距离`

- 容易翻车：`一个人在医院用 iPad 看剧。`
- 稳定写法：`医院病房里，年轻人靠坐在病床上，双手拿着一台平板电脑。平板屏幕朝向人物，屏幕背面朝向画面外侧，人物低头注视屏幕，中景侧面拍摄。`

> 此类画面**不必强行展示屏幕/画纸/镜中内容**，优先确保方向、视线、手部接触与可见面正确。

### 3.6 构图规则（按画幅分档）
- **竖屏 9:16（短剧）**：人脸与上半身必须在安全区内；**关键道具放画面中部或下三分之一安全区**；双人对话保持左右空间关系。
- **横屏 16:9**：三分法；人物视线前方留呼吸空间；前景/中景/远景建立纵深；**对话与对峙保持 180 度轴线**；重要元素不贴边。
- 两者共同：**不出现文字、水印、Logo 与无意义符号**。
