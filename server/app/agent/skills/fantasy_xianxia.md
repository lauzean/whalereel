## 一、剧作层
### 1.1 题材定位与观众期待
爽点本质：主角拿到一条别人没有的路，并把这条路走成实力。报告的心理级爽点里，「优势/金手指」（主角独有能力，让观众歪歪或崇拜）是核心；报告另指出 AI 男频常用「金手指成长 + 世界观探索」路线，提供养成爽感——两者可并为主线。金手指原创性 = 能否卖出：市面已出现 >10 次的设定别用，且**必须有约束**（有限次数的预知、每日一次、以寿命兑换），避免无敌外挂。报告最易落地的类型创新是元素创新（年龄/性别/背景/视角反转）与类型融合（团宠+鉴宝、萌宝+重生+寻亲）——融合须选关联度高的类型。
### 1.2 单集结构公式
本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（报告黄金单集公式）；AI 剧靠剧情推进留人——**每集必须有可视的进展**（打怪/升级/解锁/得宝），两集没进展观众就划走；每集 500-800 字覆盖爆点/虐点/爽点至少一个，单集正文 ≤1000 字、按 150 字/分钟折算。
### 1.3 情绪配比
爽感 50% + 期待 30% + 温暖 20%（报告「重生逆袭类」配比；玄幻奇幻未单列，沿用该近亲模板）。
### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个情绪冲击、15 秒一次剧情变化、45 秒一个强期待（并给主角留出做抉择的时空）；
- 钩子黄金布局：开头 3 秒最强钩 / 中段每约 30 秒一个小钩 / 集尾定格最高冲突，永远不解决问题；
- 拉扯：约每分钟晃一次弹簧、每三分钟完成一次完整「压-弹」，全剧晃 ≥3 次；
- 付费卡点在第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集五档；每卡点对应 ≥1 个可剪 30 秒的投流素材点，前 10 集凑 ≈10 个爆点。
### 1.5 爽点配方
装（扮猪吃虎：藏境界、藏身份）→ 打脸（越级取胜、当场兑现）→ 震惊（群像三连：瞠目、后退、交头接耳）→ 收获（突破/法宝/地位），四件套缺一件不成立；越级挑战走「受挫→濒死→觉醒→逆转」四拍，逆转给慢镜。
### 1.6 反转与钩子模板
全剧股价级反转 ≈3 个、骨架阶段定死：预期误导、人设颠覆（只能用在配角）、动机置换。单集钩子级反转 ≤1 个且不连续同招：道具伏笔（储物袋里的旧物）、情绪回弹、镜头错位。本题材独占**世界观钩子**（那扇门后面是什么、系统为何选中我），与关系内部钩子（身份颠覆/胜负碾压/真相反转）两套并用。
### 1.7 世界观与设定可视化的剧作要求
世界观呈现策略四问：关键设定的出场节奏 / 解释度（完全模糊-暗示-明确交代）/ 谁作世界观锚点（通过谁的态度建立世界）/ 观众对齐谁（和主角一起发现，或上帝视角）。降低理解成本：观众听台词就掌握核心设定；**大段旁白讲世界观是红线**。金手指规则必须当集讲清"能做什么 + 绝对不能做什么 + 代价"，边界不清观众就不等回报。设定必须可拍：境界差→呼吸、脚印深度、器物震颤；灵气浓度→粒子密度与流向；法则→一个惩罚镜头立规矩（有人违规→瞬间灰飞）。
### 1.8 台词特征
- 报告语言适配红线：全口语化、禁半文不白与生词冷词——仙侠修仙题材尤其容易写成半文言，禁止；
- 称谓架空化：报告要求掌权人称「家主」、执法者称「执法局/执法人」，**禁「市长」「县长」类现实官职**；仙侠称谓报告未给出（建议值：用「宗主/长老/道友/前辈」类架空称谓，不混用真实宗教与历史官职）；
- 系统播报、面板文字、弹幕按 VO 处理：内容原样进台词字段、逐行点亮 + 滴答音效，关键数值（等级/数量/时间）单独高亮放大一拍；
- 单句 ≤20 字（超 20 字拆镜）、单角色单次 ≤50 字、硬门 ≤35 字；遮名测试通过才算合格。

## 二、分镜层
### 2.1 设定可视化（玄幻的第一镜头法则）
- 金手指/系统面板首次展示必须给全屏 UI 特写 2-3 秒（观众要看得清规则）；
- 等级压制用光影语言：强者出场自带压暗四周、弱者镜头发虚——实力差距不用台词解释；
- 境界突破是每集最大奇观：冲击波扩散 + 时间静止 + 众人反应三连，给足 5 秒；
- 新场景首次出现用"揭示运镜"：从细节（一枚符文/一块牌匾）拉出到全景；
- 法则镜头：这个世界"什么不能做"用一个惩罚镜头立规矩（有人违规→瞬间灰飞）；
- 道具有戏：丹炉、传送阵、储物袋每次使用都给手部 + 发光特写，建立一致性；
- 「不可拍摄的内容」必须转译成可见物象：气血逆流→喷血、灵纹暗淡→裂痕、威压→器物震颤与衣摆下沉。
### 2.2 节奏与单镜复杂度（数字）
- 报告硬门：段（一次生成调用）≤15 秒不跨场次；段内每切 2-5 秒并认领剧本节拍；3 秒一切是呼吸节奏；
- 段落分层：过渡段 8-10 秒 / 叙事段 10-15 秒 / 爆点段（突破、觉醒、打脸）12-15 秒，爆点子镜可放慢到 4-6 秒；
- **同框 ≤3 人**：群像震惊三连要拆成三个人的分开反应镜，不给一张大合影；
- 台词装得下：段时长 ≥ 台词字数 ÷ 4.5 字/秒 + 2 秒；单镜台词 >20 字拆成连续多镜、按语义停顿点切；
- 每场至少一个动作节拍（纯对白场是广播剧）；反应镜 2-3 秒免费放大爽感。
### 2.3 打斗与升级节奏
- 越级挑战是核心爽点：受挫→濒死→觉醒→逆转四拍，逆转镜头用慢镜；
- 群像震惊三连：瞠目、后退、交头接耳——爽感靠配角的反应放大；
- 每集结尾必留"更强者登场"的影子或声音，压力层层递进；
- 对话切正反打，**谁的台词信息量大谁的脸给得近**；重台词后给听者 2-3 秒反应镜；动接动——切点选在动作中间而非完成后。
### 2.4 特效与氛围语言
- 灵气/魔力用粒子流 + 色温区分阵营；禁用写实血腥，用光效表达伤害；
- 穿越/传送用"抽帧 + 白闪 + 失重漂浮"三件套；
- 声音只写环境音与动作拟音（丹炉沸腾、灵石嗡鸣、法阵低鸣），**禁 BGM/配乐式的氛围描述**；
- 情绪写可见物理事实：呼吸变浅、指节发白、瞳孔收缩、下颌绷紧；危机用环境表达（风向突变、鸟群惊飞、烛火同时压低）。
### 2.5 常见钩子的镜头落法
- 集尾最后 30 秒给"更强者"的剪影或一句传音；
- 道具即伏笔：灵石裂痕、半块令牌、储物袋里的旧物每集至少一次特写；
- 段末留钩：把悬念具象成一件物（发光却看不懂的纹路），不靠人物表情收尾；
- 冻结关键帧只投影镜头起点——终点才出现的文字、动作、道具状态一律删除。

## 三、模型适配层
### 3.1 动作幅度表（法术与特效是本题材最大高危区）
可拍（单镜 ≤3 秒）：单手抬起、掌心朝上聚气（粒子自掌心升起）；原地跃起落地；单人挥剑半圈；掌心射出的直线光柱；缓慢漂浮与下坠；施法手势定格 1 秒；护盾在身前成型一格。
必崩：十指交错的复杂结印（手指立刻崩）；双手同时做不同动作；多人同时施法；快速多段连击；变身或合体全过程；多把法器环绕身体飞行；长距离飞行穿越；巨龙/巨兽全貌与骑乘；符文、咒文、阵法文字；粒子大面积遮脸。
替代拍法：法术用"光效 + 对手反应 + 环境反馈"三镜——施法只给手部或剪影（剪影是低成本拍高级感的办法），威力交给被打飞的道具与地面裂纹；变身用白闪/光斑遮断（抽帧 + 白闪 + 失重漂浮三件套）；群攻用"一次攻击 + 多个反应镜"；大型生物优先给局部（爪、鳞、声压下的碎石）与远景剪影，不给全貌长镜；打斗/追逐先出俯视调度图与红蓝双线轨迹图（红=人物、蓝=镜头），写明"沿轨迹运动，轨迹线不显示"。报告实测边界：动作迁移在编排、手势时序、运镜节奏上效果好，**手部细节、多人同步、面部表演差**——难度放在编排上，别放在手上。
### 3.2 参考图策略
- 角色三视图定妆：左正脸特写 + 右侧正面/90° 侧面/背面三张等高全身视图，同一张脸/发型/服装，中性 A 字站姿、柔和棚拍光、纯白背景；一致性 > 美观；禁动态姿势、夸张表情、手持道具、同框；
- 仙侠特化：发冠/发带/门派服色/佩剑作身份锚点；服装层数与纹样交给定妆图，不靠文字描述；
- **形态变体先锚后变**：觉醒态/魔化态/战损态是变体而非新身份——先写"什么不变使它仍是同一角色"，再写本集变化，每张变体单独出参考图；
- 法器、丹药、灵石、令牌走白底无手单品图 + 尺度短语（否则常被画成家具尺寸）；道具有状态弧：合上与打开是两张参考图；
- 场景空镜建立镜头（无人、三层构图、出入口明确、陈设固定相对位置），特殊时段另出母场景变体；
- 面板/系统界面：文字必崩——面板文字留给后期字幕与音效（逐行点亮 + 滴答），生成图只给"发光面板"的形制；图生视频声明首帧锁 `at 0.00 seconds, <Picture 1> is fully referenced`；正文里角色用 `@图N` 替代、标签必须带职能。
### 3.3 易崩点与规避
- **特效遮主体**：粒子、光柱、冲击波只走画面边缘或背景，主体面部与手部保持清晰；
- **形态漂移**（觉醒态每镜光色/纹路不同）：锁面写成最小名词短语、原样出现在每条提示词；只错一层时用编辑模式换那一层，不整条重生成；
- **双手与结印**：单手持物、单手施法，另一只手垂放或握拳（可拍）——避开生成端执行不了的动作；
- **文字**：符文、卷轴、面板、招牌文字一律禁止或交后期（可见文字须明确允许或禁止）；
- **宏大远景脏感**：人群与建筑会被补噪点，用焦点、景深、空气透视分层，重点留前景；
- **画风混搭**（角色日式、场景西幻）：风格预设整块取用不混搭，"画风必须同档"；
- **时代错位**（穿越题材必查）：现代物件、现代服饰穿越即出戏，禁止项写死；同一角色的名字与拼写全集一致。
