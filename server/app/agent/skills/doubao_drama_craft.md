## 一、四段产物法（先对齐后动笔，防剧情/人设漂移）

剧本创作按四段推进，缺任何一段都会导致下游失锚：

1. **剧情梗概（约 1500 字）**：3-5 个自然段对应起承转合。必须包含：主角核心动机、对立面的具体阻挠手段、主角的关键抉择、结局形态（爽感释放/情感和解/反转揭示）。长篇另配分集大纲表（每集一句话核心事件）。
2. **人物小传**：主角/配角/反派各一段，颗粒度固定——一句话定位（年龄+身份+标签）；性格（3-5 个**行为倾向**，禁抽象形容词）；动机（核心动机+底层驱动力：欲望/恐惧/执念）；成长弧线（开场状态→中段受挫→结局蜕变，写清转折触发事件）；视觉方向；关键道具/记忆点。**反派必须写"合理性动机"（避免脸谱化）与"惩罚落点"（如何得到实质惩罚）**。
3. **主要故事场景清单**：动笔前一次性锁定。短篇 2-4 个、长篇 4-8 个。每行登记：场景名称（2-6 字）、类型（主场景/次场景/回忆梦境）、空间概念方向（材质/体量/光源/时代感，只写大方向）、情绪氛围基调、**叙事性关键陈设**（与道具/伏笔/反转直接相关的物件）、常见时间/内外景。
4. **完整剧本**：每场戏的场景名**必须一字不差取自场景清单**；确需新增场景 → 先回填清单再继续。这条"场景来源约束"是防漂移的根。

长篇（>10 集）主动声明漂移风险（伏笔遗忘/动机不一/道具失守），完整剧本按**每批 3-5 集 → 确认 → 下一批**输出。

## 二、单集章节结构

单集切 **3-5 个叙事章节**，每章一个明确叙事功能：

- **短剧钩子驱动**：3 秒钩子+铺垫（15-20%）→ 加剧压迫、主角蓄力（30%）→ 身份/能力暴露、首波打脸（30%）→ 终局清算、爽点释放（20-30%）。
- **微电影三幕式**：铺陈（20-25%，世界观+开场钩子）→ 事件与冲突（40-50%）→ 高潮与落点（25-30%）；4-5 章节时把冲突拆成"展开+危机加剧"。

## 三、短剧向法则（钩子驱动/爽感释放）

- **黄金开局定律**：前 15-30 秒抛出核心矛盾或强悬念，让主角陷入危机或揭示极端处境。
- **高频反转**：每章节至少一次反转；不建议超过 15 秒没有信息增量或情绪推进。
- **收束优先**：结尾给明确落点（惩罚/反转/情感闭环），不用"待续"收尾。
- **压迫要具体，释放要痛快**：对手的阻挠必须有具体恶劣行径，主角的反击是降维打击。
- **反差原则**：人设反差（弱小外壳+强大内核）、情节反差（打破预期）、台词反差（不说"该说的"，说"最解气的"）。
- **用动作外化情绪，不靠解释性台词**：不要说反派多坏，直接让他踩碎主角的救命药。
- **台词千人千面**：匹配角色身份、教育背景与社会地位。
- **反派惩罚铁律**：本集内得到实质惩罚或明确失败，不跨集收拾。

## 四、微电影向法则（三幕式/情感沉淀）

- **单一核心事件定律**：一部微电影只承载一个核心事件/一次情绪转变/一个价值追问。
- **允许留白与呼吸**：2-3 秒静态凝视、无对白空镜是情绪沉淀的必需成本；判断某场戏是否"平"的标准——删掉它，主角的情感转变链会不会断。
- **落点优先情感闭环**：和解、释怀、觉悟、无声的目光对视；对立面可象征化（沉默/距离/时间），不必人格化为坏人。
- **情绪靠"物件+光影+留白"承载**：一封信、一块怀表、傍晚的斜光——优先给锚物件镜头，而非塞解释性对白。
- **台词克制、去戏剧化**：接近生活对白，允许沉默与答非所问；禁总结陈词式台词（"我终于明白了……"）。VO 只出现在开场与结尾。
- **主角内驱大于外驱**：写清"未和解的情绪/长期回避的问题/心里的一块石头"；配角 2-4 位，少即是多。

## 五、对白与动作红线（两类通用）

- 动作提示（△）只写可拍摄的客观动作与画面，不写心理剖析；
- 台词单句宜短（口语化，超过 20 字考虑拆分）；禁半文半白与生词冷词；
- 每场戏至少一个明确节拍（亮相/破冰/打脸/反转/转变）；
- 大段旁白讲世界观是红线——设定落成可拍物（门派等级→牌匾与服色，内功高低→呼吸长短与脚印深浅）。

## 六、风格锚点（先定锚，再动笔）

剧本头 `风格` 字段必须落到**具体锚点**，分两步判定：

**第一步 · 判形式（真人 / 非真人）**

**非真人仅两条强信号**（命中任一即可）：
1. 用户**直接指定画面制作形式**（3D 动画 / 2D 动画 / 水墨 / 国漫 / 日漫赛璐璐 / 绘本 / MG 动画 / 皮克斯 / 毛毡定格 / 粘土动画等）；
2. 内容本身**无法用真人拍摄**（非人形主角、极端抽象、低龄童话绘本形态）。

> **题材本身（仙侠/玄幻/修真/科幻/末世/赛博朋克/古风）不构成非真人信号**——《仙剑奇侠传》《三体》《长安十二时辰》《银翼杀手》皆为真人。**仅凭题材切成 3D/2D 是错误判断。**

**第二步 · 选锚点**

- 真人路径：从下表六大流派中**主动挑 1 位大师**，风格字段直接写「**某某风格的电影**」（一位大师有多个明显风格阶段时，可加代表作限定，如「王家卫《花样年华》风格的电影」）；
- 非真人路径：写「3D 玄幻风格」「2D 水墨风格」「2D 日漫赛璐璐风格」等类型词，可在其后追加更细画风（如「2D 日漫赛璐璐 · 京都动画风格」）；
- **禁止留白写法**：「影视级布光」「电影风格」「高级质感」这类模糊表述会让下游资产与关键帧阶段风格漂移；
- 题材/形式都推不出时**主动澄清**；实在无法推断（如「随便写个都市短剧」）取 `是枝裕和风格的电影` 作为**最保守锚点**。

**真人电影六大流派参考库**：

| 流派 | 大师 | 视觉特征 | 适配题材 |
| --- | --- | --- | --- |
| 一、东方生活流 / 家庭治愈 | 是枝裕和、李安（早期华语）、侯孝贤、岩井俊二 | 柔和自然光、餐桌戏、长镜头生活流、逆光空气感 | 都市治愈、亲情和解、青春成长 |
| 二、港风霓虹 / 怀旧胶片 | 王家卫、杜可风、贾樟柯 | 手持慢速快门拖影、高饱和红绿蓝、暗调霓虹、失焦前景 | 怀旧、年代、人物记忆 |
| 三、极简对称 / 高饱和作者美学 | 韦斯·安德森、保罗·托马斯·安德森、昆汀 | 绝对对称构图、马卡龙高饱和色板、章节化标题卡 | 喜剧甜宠、亮相戏、广告剧情、品牌微电影 |
| 四、极简冷冽 / 精密构图 | 大卫·芬奇、库布里克、罗杰·迪金斯、诺兰 | 低调冷灰、精密对称、长焦压缩空间、逆光剪影/顶光 | 悬疑、复仇、商战、独立文艺 |
| 五、诗性自然 / 影展作者 | 泰伦斯·马利克、阿彼察邦、河濑直美 | 广角低机位、麦浪金黄、诗性 VO、自然光 | 影展参赛短片、意境类微电影 |
| 六、社会现实主义 / 纪实感 | 达内兄弟、肯·洛奇、贾樟柯（纪实向） | 手持贴身跟拍、原生光、几乎无配乐、素人质感 | 社会议题型微电影、现实题材 |

## 七、题材与受众心理库

### 7.1 短剧向：两种爽感机制

**个人主义爽感**（打破规则、掌控命运、极致自我）—— 海外受众更吃这套
- 机制：主角拥有**绝对的信息差或宿命般的羁绊**，能改写命运或体验极致纯粹的情感；
- 题材：重生/预知/无限流、穿越/异世界、末世囤货/生存基建、狼人天选伴侣、吸血鬼/黑帮大佬、禁忌之恋/离婚觉醒、系统/修仙升级流。

**集体主义爽感**（阶层跃迁、打脸围观、重塑秩序）—— 国内受众占绝对主流
- 机制：主角隐忍不发，随后**突然暴露极其显赫的身份或惊人财富**，让所有轻视者付出代价；
- 题材：掉马甲/隐世大佬（战神/龙王/首富）、真假千金/豪门上位、年代/四合院/知青、婆媳伦理/手撕极品亲戚、萌宝/天才儿童、衣锦还乡/家族正名；
- 写法：**安排「围观群众」与「势利眼配角」衬托主角**。

### 7.2 微电影向：四类价值取向

| 类型 | 共鸣机制 | 常见方向 |
| --- | --- | --- |
| **情感共鸣型** | 让观众看见自己的影子：未说出口的遗憾、迟到的道歉 | 亲情和解（父亲遗物/母亲的病历/错过的葬礼）、异地离别、老友重逢、临终告别/阿尔茨海默、离婚后的独处 |
| **治愈自愈型** | 在平凡日常里重新找回小确幸 | 深夜食堂/便利店哲学、辞职返乡/GAP 一年、一日限定关系、独居美学、宠物告别 |
| **社会议题型** | 替观众「说出来」某种熟悉又无力的现象 | 打工人（外卖员/网约车/35 岁裁员）、教育焦虑、老龄化/空巢、性别议题、原生家庭/代际创伤、AI 与人性 |
| **品牌商业型** | 品牌作为「**情感转折的助手**」出现（一杯咖啡/一次快递/一个提醒） | 春节回家、母亲节/父亲节、独立女性、公益纪录短片 |

> 品牌商业型红线：**不让品牌直接出面说教**，**不在结尾加广告 slogan**。

## 八、专业剧本格式（分集分场）

**剧本头**（每部剧本开头一次）：`《标题》` / 类型（短篇短剧·微电影·剧情短片·长篇短剧，长篇注明总集数）/ 风格（见 §六）/ 标签（题材+情感关键词）/ 人设（一句话高浓缩对撞，如「年轻洒脱活泼女×年成熟稳重古板男」）/ 单集时长 + 剧作基调。

**正文格式**：

| 元素 | 规范 | 示例 |
| --- | --- | --- |
| 分集标题 | `第X集` 独占一行，**不带集名** | `第一集` |
| 场次编号 | `X-Y`（X=集号，Y=集内场次序号，从 1 起） | `1-2` |
| 场景表头 | `场次编号 场景名 [日/夜] [内/外景]`；**场景名必须取自场景清单** | `1-1 茶室 日 内` |
| 人物 | 单独一行；画外音用「角色名+VO」 | `白父VO` |
| 动作提示 | 以 `△` 起首，**只写可拍摄的客观动作与画面**，不写心理活动、不写情绪形容词 | `△（特写）指尖在相框上停留三秒后缓慢滑落` |
| 对白 | `角色名: 台词`；括号内可加简短情绪/动作提示 | `白清枞:（失笑）盲婚哑嫁，你也能接受？` |
| 特殊呈现 | `（特写）` 或 `（内心）` 前置 | |
| 旁白/画外音 | `角色名VO: 内容` | |
| 情绪节拍 | 关键台词或动作提示末尾用 `【节拍：XXX】` | `【节拍：破冰】`、`【节拍：反转】`、`【节拍：爽点释放】`、`【节拍：情感闭环】` |

**不建议**再用「章节 + 100 字梗概」这类概要式写法当完整剧本——概要式内容归在剧情梗概产物里。

## 九、风格一致性（一条硬铁律）

剧本头 `风格` 字段是**全链路唯一真源**：资产图 / 关键帧 / 视频提示词的全局风格限定词必须与它**一字不差**，且置于提示词最前。

- 不得简化为「电影风格」「港风」「高级质感」等模糊写法；
- 不得中途替换为其它大师；
- 允许在锚点后追加更细的美学词组（如「结合复古胶片美学：轻微颗粒感、暗调霓虹、漏光效果」），但**主锚点表述不得替换**；
- 本链路已由系统在提示词开头自动注入画风前缀（含风格锚点全称）——**剧本正文与分镜描述里不要重复写画风与质量词**。
