> 协议」接入）+ 本仓通用画面描述规范。标注「**官方能力**」的条目出自接口文档的

## 一、生成模式（图生视频，与其它端点不同）

本端点**只接图生视频**（`images` 必填且只收 1 张）：传入的图就是**本镜起点画面**。

- 描述写首帧之后的**动态延续**，**勿重复描写首帧的静态外观**（首帧已由画面决定，
  重写一遍只会与画面打架）；
- **没有参考图通道**：角色长相/服装、场景陈设的一致性**全部压在首帧 + 文字描述**上。
  提示词里不得出现「参考图N」式指代——系统组装时会自动脱去编号与「角色@」类型
  前缀，并把「与参考图一致」改指首帧画面（改动随「查看参数」外露）；
- 该端点**不支持纯文生视频**：没有首帧图时提交会被明确拒绝（不静默降级、不自动
  改用别的端点）——这正是「失败要看得见」的纪律。

## 二、画面描述结构（六要素顺序）

①主体与场景 → ②动作与变化 → ③镜头语言 → ④视觉风格 → ⑤声音与节奏 → ⑥一致性要求

- **单镜头只写一个连贯动作**（在本镜时长内可完成），不要在一句话里塞多个镜头切换；
- **运镜用具体动词**：推近/拉远/环绕/跟拍/手持晃动/平移；单镜头只指定 **一种** 主运镜；
- **动作与运镜分开表述**，**时序敏感**：动作先后顺序即播放顺序，避免倒装句。

## 三、长度预算

| 段 | 预算 |
| --- | --- |
| 前四段（全局定义/视频画面/画面要求/安全合规） | **250-450 字**（10 秒以上长镜 ≥350 字） |
| 声音设计 | 20-60 字 |
| **合计上限** | **≤900 字** |

密度不足 → 画面空洞；超长 → 关键约束被稀释。

## 四、音画同出（官方能力）

本端点是**音画同出**模型（提交时 `audio=true`）：台词与音效随画面同步生成，
声音描述直接决定成片听感，且**台词会与口型同步**——写进提示词的台词原句就是
要被念出来的那句话，**不得写成描述性转述**（如「他冷冷拒绝」），必须给原句。

- 环境声写**层次与变化**（雨声密度 / 灶台蒸汽声 / 街道远近声），不写「有环境音」；
- 台词**只补语气**（哭腔/冷笑/低吼），**不重复原句**（原句已在画面小节里）；
- 角色**背对镜头**、背对另一角色或处在远景里时，补一句「**台词清晰可闻，音量不因
  背对或距离而衰减**」——原生音频按画面空间关系摆放声源，不写清楚会被处理成远场；
- 无配乐需求**不写配乐**（成片 BGM 由合成环节统一叠加）；仅在剧情明确需要
  （收音机/现场演奏/铃声）时写明。

## 五、自动切镜（官方能力）

本模型**支持自动切镜**（一个生成任务内可能自动分成多个镜头），且提交参数里
**没有关闭开关**。本仓按「一镜一生成」组织提示词，据此规避：

- 描述保持**单一场景内的一个连贯节拍**，不写跨场景/跨地点的跳跃——自动切镜若
  发生，应落在同一场景的景别变化之内，而不是把两个地点硬接在一起；
- 不被切散的写法：把「必须出现在同一画面里的元素」（两人同框、手部与道具接触）
  写在**同一个小节**里；需要换景别的信息放后一个小节。

## 六、易崩点与规避

| 风险 | 表现 | 规避 |
| --- | --- | --- |
| 首帧被跳过 | 视频不从首帧起像 | 首帧由接口语义保证（`images` 即起点画面）；描述里不要出现与首帧矛盾的静态外观 |
| 流体动作 | 倒水/洒落演成喷涌 | 只拍**结果态**（液体已在杯中、碎片已散落），过程靠声音与反应镜暗示 |
| 手部精细交互 | 多指/穿模 | 降级为「手部入画局部」或切反应镜 |
| 大幅动作 | 狂奔/大跳变形 | 优先**低缓连贯的小动作**（缓慢抬手/微微低头），写明动作承接 |
| 多事件塞一镜 | 画面混乱（自动切镜把跳跃放大） | 一个片段只承载**一个可见节拍 + 一个摄影机想法 + 一个终点** |
| 台词听不清 | 背对/远景说话音量衰减 | 见第四节：补「台词清晰可闻」句 |

## 七、跨镜一致性

- 同场景连续镜：上一镜的**尾帧状态 = 本镜首帧状态**（站位/持物/朝向不得跳变）；
- 人物外观全程以首帧画面为准，**服装/发型不得无端变化**；
- 台词与画面同镜（避免「只有声音没有画面」的广播剧形态）。

## 操作纪律（对 LLM 的硬约束，违反即不可用）

- **不得降级或替换模型**：用户配置了哪个模型就用哪个（含档位与端点）；不可用时报错
  并说明原因，**禁止自行改投其它模型或档位**——与项目「禁止静默回退本地推理」同源；
- **组装之后不再改写**：系统组装完成的提示词到端点之间**零改写**（本端点的提示词
  扩写开关 `is_rec` 已按本仓纪律**关闭**）——不追加标题/前缀/后缀/风格词/质量词，
  不改标点与换行。参数（时长/分辨率）一律走独立字段，不写进提示词正文；
- **负向控制仅限音频与字幕**：画面内容一律正向描述。

**本模型专属**：

- **台词必须是原句**（音画同出会照念）：不要替角色改台词，也不要省略台词；
- **时长按镜头实际秒数写**：本端点支持 3-16 秒，描述的动作量应与时长匹配。
