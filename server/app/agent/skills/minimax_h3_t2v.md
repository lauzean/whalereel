## 一、画面描述结构

按「**镜头运动 → 主体动作 → 环境反应 → 氛围收尾**」推进：

- H3 对**时序敏感**：动作先后顺序即播放顺序，**避免倒装句**（"在他抬手之前，碗已经放下" 这类写法会乱序）；
- **单镜头只写一个连贯动作**（在本镜时长内可完成），不要在一句话里塞多个镜头切换；
- 篇幅遵循画面描述总规范（前四段 250-450 字 + 声音 20-60 字）。

## 二、运镜写法

**用具体动词**：推近、拉远、环绕、跟拍、手持晃动、平移、升降、固定。

- 禁「高级感运镜」「电影级调度」等抽象词——H3 不解析这类描述；
- **单镜头只主导一种运镜**，与人物动作分开表述。

## 三、原生音频（本模型强项）

H3 原生生成音频，声音描述直接决定成片：

- 环境音/音效写入【声音设计】段（如「雨声渐起」「衣料摩擦声」）；
- **无描述则按静音处理**——需要环境声就一定要写；
- 台词只补语气（哭腔/冷笑/低吼），不重复原句。

## 四、图生视频（i2v）写法

- 描述首帧的**自然动态延续**：「人物从首帧姿态自然转身走向窗边，衣物和头发运动真实，镜头缓慢推进」；
- **勿重复描写首帧的静态外观**（模型已看到图，重复描述会诱发画面跳变）；
- 首帧与尾帧同时提供时（fl2v），写明中间过程的**动作路径**，而不是只写头尾。

## 五、参考图与引用

- `@角色名` / `@场景名` 引用**保持原样写出**，由系统在提交时转换为参考图绑定——**不要自行改写成「参考图1」**（会打断系统的编号对账）；
- 参考图张数与对齐规则由提交侧统一处理。

## 六、易崩点与规避

| 风险 | 表现 | 规避 |
| --- | --- | --- |
| 时序倒装 | 动作顺序错乱 | 严格按发生顺序书写，禁用「之前/之后」倒叙 |
| 多事件塞一镜 | 画面混乱 | 一个片段一个可见节拍 |
| 大幅动作 | 变形 | 优先低缓连贯的小动作（缓慢抬手/微微低头） |
| 首帧被忽略 | 视频不从首帧起像 | i2v 模式描述动态延续而非重写静态外观 |
| 无环境声 | 成片发干 | 需要声音就写进【声音设计】段（不写 = 静音） |

## 操作纪律（对 LLM 的硬约束，违反即不可用）

- **不得降级或替换模型**：用户配置了哪个模型就用哪个（含档位与端点）；不可用时报错并说明原因，**禁止自行改投其它模型或档位**——这与项目「禁止静默回退本地推理」同源：失败要看得见，不要悄悄换个差一点的。
- **组装之后不再改写**：系统组装完成的提示词（@引用解析、参考图预算裁剪均属**组装环节**，允许）到端点之间**零改写**——不追加标题/前缀/后缀/风格词/质量词，不改标点与换行。参数（画幅/时长/参考图）一律走独立字段，不写进提示词正文。
- **不使用 `--` 符号**：该符号之后的内容可能被模型截断，不会被解析或响应。

**本模型专属**：

- **五段式结构保留**：`【全局定义】【视频画面】【画面要求】【声音设计】【安全合规】` 段名一字不差。
- **负向控制仅限字幕与音频**：画面内容一律正向描述。
