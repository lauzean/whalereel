## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
- 观众要的是"用专业和证据赢"：主角在被压制的组织里靠能力、证据与人心翻盘，不靠拳头。
- 心理级爽点锁「优势/金手指」：主角独有能力（一眼看穿账目、谈判节奏、技术判断）让观众崇拜，且必须有约束（如只能用一次、不能暴露来源），无边界即贬值。
- 商战必须看得懂：每个商业动作都用一句台词讲明利害（谁欠谁、这单丢了对谁致命），降低理解成本。
- 严格单线（报告：多线并行＝严重问题）：商战是唯一主线，感情/家庭线只作情绪助攻，不推动主线的支线全砍。
- 反派必须有合理动机——最好的矛盾是"两个好人因不同选择走向不同命运"（师徒理念之争、为救公司而站错队）。

### 1.2 单集结构公式
- 黄金单集公式：本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连。
- 每场必须改变信息/权力/关系/情绪/风险中至少一项；每集一个"可视的进展"（丢单、签约、上位、被夺权、融资到账）——AI 短剧靠剧情推进留人，两集没进展就被划走。
- 一卡三招：第 1 集写清性格/困境/目标/动机 + 敲定类型 + 对手登场；2–3 集解决一个与对手相关的重大危机；第 10 集结尾强钩子卡主线。

### 1.3 情绪配比（数字）
- 爽感 45% + 期待 35% + 温暖 20%（报告未给出职场商战类配比，建议值；可比照报告"重生逆袭类"爽感 50%+期待 30%+温暖 20%）。
- 单集 = 1 核心情绪（憋屈或爽）+ 1 辅助情绪（小冲突）+ 1 结尾钩子；核心情绪同集 ≤2 个，配角情绪不能盖过主角。
- 单集 500–800 字正文须覆盖爆点/虐点/爽点 ≥1 个；连续 3 集无情绪爆点 = 严重问题。

### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个信息点（合同被撕/被踢出群/账户冻结）、15 秒一个剧情变化、45 秒一个强期待（并在这段里完成人物抉择）。
- 情绪节点：前 3 秒抛最强钩子；中段 30–40 秒第一次反击；结尾 10 秒拉满悬念卡断。
- 压-弹：压到谷底（先被架空、被抢功、被踢出局）→ 来回晃 ≥3 次（先给"危机解除"的错误预期再致命一击）；约每分钟晃一次、每 3 分钟一次完整"压-弹"。
- 付费点：第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集五个卡点，必须卡在主线上；每集永不圆满收尾；前 10 集凑 ≈10 个可剪 30 秒爆点（每集 ≥1 个），付费冲动前置到前 3 集。
- 单集体量：正文 ≤1000 字、台词按 150 字/分钟（单句字数见 1.7）。

### 1.5 爽点配方（装→打脸→震惊→收获）
爽点 = 装 + 打脸 + 震惊 + 收获（报告四件套），本题材落地：
- **装**：以最低职位在场（实习生/被架空的副总/供货小老板）被指派杂活、被抢功——他把工牌翻过去扣在桌上；**打脸**：不看拳头看**专业与证据**——当场指出合同漏洞、投屏篡改记录、一句话点破对方底价；**震惊**：写具体身体动作（董事长把笔放下、对手的助手手一抖、沉默三秒后先有人鼓掌），不写"全场哗然"；**收获**：签约/上位/对手出局，并立刻抛出更大的局。
- 打脸必须有观众：付费点特征 = 场面宏大、事态紧急、围观群众多（股东大会、竞标现场、签约仪式、产品发布会）。

### 1.6 反转与钩子模板
- 全剧股价级反转 ≈3 个、骨架定死：常用预期误导（观众以为这单要丢，反转=他故意把单让给对手的子公司）与动机置换（对手的每一步其实在逼他上位）。
- 人设颠覆只用于配角（温和的合伙人其实是内鬼），绝不动主角核心底色。
- 单集钩子级反转 ≤1 个且不可连续用：道具伏笔（保温杯/录音笔/合同副本）、情绪回弹（净身出户被嘲笑→当场播放挪用公款认罪录音）、镜头错位（局部真画面误导+下集全景揭晓）。
- 两准则：给观众的画面必须 100% 真实，绝不造假骗人（局部真画面误导可以，造假不行）；同一招不能连续使用。
- 付费点素材（报告）：关系类（反目、断绝关系）、冲突类（好友陷害、产业被占、揭发）、真相变故类（被控入狱）、行动类（请君入瓮、调虎离山、忍辱负重）。
- 钩子两套并用：关系内部（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）；铁律——卡点必须卡在主线上。
- 反模板纪律：三条死路不碰（换汤不换药的模仿、照搬公共桥段、换皮洗稿）；"不为检查表硬加秘密、反转或人物弧"，长出输入没有要求的机关时撤掉机关；开篇避三天坑（铺背景讲世界观、一群角色乱冒、慢悠悠写景）。

### 1.7 台词特征
- 商战台词=利害句：每句都能折成"钱/权/风险"——"这单丢了，你我的保证金都归对方"，禁空洞喊话。
- 单句 ≤20 字、单角色单次 ≤50 字，全口语化，禁半文半白与生词冷词；财富用"亿元""百亿订单"等夸张表达以突破现实货币体系。
- 称谓按短剧规范：以「家主」代家族掌权人、「执法局/执法人」代公安/警察，禁用真实官职（"市长""县长"改"市首""总督"）。
- 要展示不要告诉：把工牌推到桌上、把合同合上、把笔帽扣紧，比十句"我要走了"更狠；遮住角色名仍能判断说话人。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 会议室=权力空间语言：主位用微俯仰差（谁被俯拍谁弱势）；谈判对峙用正反打+越轴制造压迫；两人同框永远隔一个物件（长桌/车门）。
- 关键信息落特写：合同条款、笔尖停顿、指节敲桌——观众靠道具读懂输赢。
- 上位/翻盘用"空间打开"一镜完成：从被隔在玻璃门外（前景门框遮挡）走到会议桌主位，位移即地位变化。
- 时间与规模用叠化（工地搬砖叠化到十年后写字楼签合同）；反派用逆光轮廓剪影。
- 只在四个节点标特殊镜头：开场钩子/爽点瞬间/情绪爆发/悬念揭晓；运镜克制（固定为默认，推给情绪、拉给收场），一段内 ≤2 种。

### 2.2 节奏与单镜复杂度（数字）
- 报告三层结构：段（一次生成）≤15 秒 → 段内切 2–5 秒 → 平均 3 秒一切。本平台一镜=报告一次"段"（一次生成 ≤15 秒，单镜档位 5–12 秒为平台既有约定）——段内 3–5 切的信息量由"相邻镜景别跳档 + 反应镜"承担。
- 长台词 >20 字（谈判长句、合同宣读、发布会发言）强制拆镜，每镜换景别、按语义停顿点切、不平均切；台词按 4 字/秒折算；含台词镜 ≥ 字数÷语速+停顿+1 秒余量；无台词镜 ≤6 秒。
- 同框 ≤3 人：谈判桌/董事会只给 3 人清晰，其余虚焦或只给手与背影；群演只给微动作、不配台词。
- 切镜必须带来信息/权力/情绪/空间/节奏变化之一；同一动作不跨镜重复；本镜终点=下一镜可信起点。
- 画面描述 15–50 字，只写动作/姿态/表情/状态变化；相邻镜景别错开，禁连续 3 镜同景别。

### 2.3 情绪可视化
- 不写情绪写身体：隐忍=笔尖压出墨点、领带松开一扣；决断=把文件夹合上、起身；被架空=站在会议室门外听里面的笑声（门缝一线光）。
- 权力变化用可见物：桌上的名牌被换掉、椅子被拉开、门禁卡刷不开——每个转折给一个可拍的物件动作。
- 环境替人说话：受压制在狭窄工位/电梯间/地下车库（冷光），翻盘在开阔落地窗前（自然光）。
- 数据与金钱不靠台词堆：报表上被划掉的名字、红绿数字跳动，用"物的表演"承担（文字画面高危，写法见 3.3）。

### 2.4 常见钩子的镜头落法
- 集尾三选一：一份文件被翻到关键一页（只给局部不留全文）/ 对手出现在不该出现的地方（背影入画）/ 主角做危险决定前的深呼吸（侧脸+手部动作）。
- 镜头错位：本集只给局部真实画面（他把一份文件塞给对手的助手），下集全景揭晓（其实是在把证据递给对方内部的人）。
- 断在动作前一帧，黑场；下集首镜接"结果态"，过程交给声音与反应镜。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表（可拍 vs 必崩 + 替代拍法）
- 可拍：递/放/推文件（已完成态）；签字、握手、起身离席；正反打对峙；单人在长桌一端站定；点钞/翻页的静态结果；逆光剪影。
- 必崩 → 替代：掀桌、砸电脑、摔手机 → 撞前/撞后两镜跳切，碎片只拍"已散落"的结果；泼咖啡/泼酒 → 液体只拍已完成的结果（衣襟渍痕）+ 声音与反应镜；多人推搡、抢文件、围堵 → 只拍被围的静态构图（人群前景遮挡、主角清晰）；动手/斗殴 → 起手定格+对方倒地结果，落点永不给画面；开保险箱/拆信封/键盘特写 → 改静态完成态（箱门已开、信纸已摊开、屏幕已显示）；快速转身走人+长距离移动 → 一镜只给"新位置已站定"，走动并入邻镜。
- 报告原则：保留内容必须能被 AI 稳定生成、避免生成端执行不了的动作；主动规避 AI 跳脸、画面不连贯、重复场景视觉疲劳。
- 平台机制：以上类别在分镜 risks 标 motion/fluid/collision/hands/crowd，供审片核对与降级路线。

### 3.2 参考图策略
- 必带：主角、对手、常同框搭档的定妆三视图（正/侧/全身，脸与半身像一致）+ 同框角色服装主色差异（防串脸）+ 场景主图。
- 优先级与上限：角色 > 场景 > 道具；首帧参考图预算 8 张（报告 @Image 上限 9，本项目按 8 执行），超预算先裁尾部道具/场景——角色必在预算内，杜绝串脸。
- 办公室/会议室/发布会场按场景主图参考，同场景多镜共用一张环境参考图（报告·生成批次单）。
- 关键道具（合同、录音笔、工牌、股权书）出白底无手道具图（拿着道具的手是最常见污染）；跨镜不变的外观写进正文（不靠模型记忆）。

### 3.3 易崩点与规避
- 文字类画面是本题材最大高危（合同条款、PPT、报表、股价屏、手机消息）：只拍纸张/屏幕边缘+手部动作，关键信息交给台词与 OS；必须呈现时逐行点亮+关键数值高亮一拍。
- 人物漂移：图生/文生由"有没有可读参考图"分流；文生镜必须写非空静态视觉锚点，**禁止只写"保持已有外观/preserve/keep"**。
- 服装/发型/长相不进画面描述（交参考图），只写动作、姿态、表情与状态变化。
- 同缺陷 ≥2 次停止盲摇（重摇硬上限 2–3 次）改提示词；重拍单变量，一次只改一个子句。
- 场景复用疲劳：本题材场景集中（办公室/会议室/宴会厅），靠光线与画面元素区分转场，禁同一构图连续复用。
