## 一、剧作层
### 1.1 题材定位与观众期待
爽点本质：规矩被践踏 → 主角以武力与道理讨回。报告的心理级爽点里，「归属」点名「帮派、修仙、大女主、女战神」，「秩序」（用逻辑还原真相）点名「复仇」——锁定其一为核心。金手指属「优势」类：市面出现 >10 次的设定别用，且**必须有约束**，避免无敌外挂。反派必须有合理动机；矛盾沿四级阶梯抬到 3-4 级——最好的矛盾是"两个好人因不同选择走向不同命运"。
### 1.2 单集结构公式
本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（报告黄金单集公式）；每集 500-800 字须覆盖爆点/虐点/爽点至少一个，单集正文 ≤1000 字、按 150 字/分钟折算。
### 1.3 情绪配比
压抑 40% + 爽感 50% + 解气 10%（报告「复仇类」配比；武侠仙侠未单列，沿用该近亲模板）。
### 1.4 节奏曲线
- 3-15-45：3 秒一个情绪冲击、15 秒一次剧情变化、45 秒一个强期待（并给主角留抉择的时空）；
- 钩子布局：开头 3 秒最强钩 / 中段每约 30 秒一个小钩 / 集尾定格最高冲突，永远不解决问题；
- 拉扯：约每分钟晃一次、每三分钟一次完整「压-弹」，全剧晃 ≥3 次；
- 付费卡点在第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集五档；前 10 集凑 ≈10 个可剪 30 秒爆点。
### 1.5 爽点配方
装（藏功不露、被小辈轻视）→ 打脸（一招制敌、当场兑现）→ 震惊（围观者态度 180° 反转：瞠目、后退、交头接耳）→ 收获（名声/秘籍/地位），四件套缺一件不成立。
### 1.6 反转与钩子模板
全剧股价级反转 ≈3 个、骨架阶段定死：预期误导、人设颠覆（只能用在配角）、动机置换。单集钩子级反转 ≤1 个且不连续同招：道具伏笔（断剑/玉佩颠覆真相）、情绪回弹、镜头错位。钩子两套并用：关系内部（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）。
### 1.7 世界观与设定可视化的剧作要求
世界观呈现策略四问：关键设定何时出场 / 解释度（模糊-暗示-明确）/ 谁作锚点 / 观众对齐谁。降低理解成本：观众听台词就懂核心设定；**大段旁白讲世界观是红线**。设定落成可拍物：门派等级→山门牌匾与弟子服色，内功高低→呼吸长短与脚印深浅。
### 1.8 台词特征（古装称谓与语体）
- 报告语言适配红线：全口语化、**禁半文半白与生词冷词**——古装同样适用，古味靠称谓与语体节奏，不靠文言句式；
- 称谓用架空词建等级：掌权人称「家主」、执法者称「执法局/执法人」，**禁「市长」「县长」类现实官职**（报告改「市首」「总督」）；古装官职报告未单列——建议值：用「家主/大人/公子」类架空称谓，避真实朝代官职与历史人物；
- 单句 ≤20 字（超 20 字必须拆镜）、单角色单次 ≤50 字、硬门 ≤35 字；遮名测试通过才算合格。

## 二、分镜层
### 2.1 景别与运镜语言
- 大远景横移长卷：开篇立世界观（城池/山门/江湖全貌），如展开一幅长卷；
- 景别五层递进：远景交代世界 → 全景交代动作 → 中景建立关系 → 近景传递情绪 → 特写放大回应；
- 特写三件套：兵器纹理（剑穗/断口）、眼神变化、指节与手部动作——武侠的情绪全在手上；
- 运镜语义：推镜=情绪聚焦（拔剑前），拉镜=孤独感揭示（战后），环绕=对决仪式感，跟拍轻晃=逃亡紧迫；
- 对决套路：出招前大面积留白或静默 2 秒（越安静越致命），决胜一击 1-2 秒定格，再轰然散开；
- 对话切正反打，**谁的台词信息量大谁的脸给得近**；重台词后给听者 2-3 秒反应镜；动接动——切点选在动作中间而非完成后。
### 2.2 节奏与单镜复杂度（数字）
- 文戏长段 6-10 秒、打斗快切 2-4 秒（现包经验值；报告硬门为段 ≤15 秒、段内每切 2-5 秒——"文戏长镜"即长**段**，段内仍切 2-4 个子镜）；
- 报告硬门：段（一次生成调用）≤15 秒不跨场次；段内每切 2-5 秒并认领剧本节拍；3 秒一切是呼吸节奏；同框 ≤3 人，超出必须带拆解说明；
- 段落分层：过渡段 8-10 秒 / 叙事段 10-15 秒 / 爆点段 12-15 秒（破局镜给足 5 秒）；
- 台词装得下：段时长 ≥ 台词字数 ÷ 4.5 字/秒 + 2 秒；单镜台词 >20 字拆成连续多镜，按语义停顿点切、不平均切。
### 2.3 情绪可视化
- 每场至少一个动作节拍——纯对白的场是广播剧，AI 生成没有画面可写；
- 表演写可见物理事实：不写"他很愤怒"，写呼吸变浅、指节抵住剑柄、下颌绷紧、视线停留时长；
- 环境互动四件套至少取二：衣袍发丝逆风、雪粒悬停、烛火压低、水面倒影碎裂；
- 剑气以笔墨/光痕表现：心境越纯剑气越清（细而亮的直线光痕，掠过处竹叶缓落）；入魔者剑气浓稠吞光（墨色浊流、光被吸走）——同一角色的剑气写法全集统一，不逐镜换效果；
- 血与色彩克制：全片点睛色（血红/鎏金）每集不超过三处，出现即高潮；受伤镜头必接反应镜（对手的瞳孔/后退半步），打斗才有重量。
### 2.4 常见钩子的镜头落法
- 认知反转（仇人实为恩人/死人未死/内鬼是最亲之人）放集尾最后 30 秒；
- 道具即伏笔：断剑/玉佩/半枚印每集至少给一次特写存在感；
- 段末留钩：把悬念具象成一件物（剑鞘缺口、桌上多出的杯），不靠表情收尾；
- 冻结关键帧只投影镜头起点——终点才出现的动作、文字、道具状态一律删除（起始帧提前出现动作结果是最常见缺陷）。

## 三、模型适配层
### 3.1 动作幅度表（打斗与法术是本题材高危区）
可拍（单镜 ≤3 秒）：单人起手/收势慢动作；"格挡 → 错身 → 刀锋擦过"三段式；兵器相击一瞬与火星；袖袍翻卷、发丝甩动；掌心聚气（光效自掌心升起）；倒地、后退半步。
必崩：两人以上贴身缠斗超过 2 秒（手臂归属错乱、多指）；快速多招式连打（只剩糊状残影）；兵器持续互砍对峙；飞剑绕人飞行；数十人远景群战；马战；抛接兵器；十指交错结印。
替代拍法：整段打斗拆成"攻击方特写 → 兵器相击瞬间定格 1-2 秒 → 被击方反应镜"；报告实测动作迁移在编排、手势时序、运镜节奏上效果好，**手部细节、多人同步、面部表演差**——价值给编排与节奏，不给手；"三次攻防转换"（试探→受挫→破局）用三个独立 2-3 秒镜头；用环境替身承担动作（剑气削断竹、水袖扫落烛）；打斗前先出两人全景定站位，再按俯视调度图与红蓝轨迹（红=人物）生成，写明"轨迹线不显示"。
### 3.2 参考图策略
- 角色三视图定妆：左正脸特写 + 右侧正面/90° 侧面/背面三张等高全身视图，同一张脸/发型/服装，中性 A 字站姿、柔和棚拍光、纯白背景；一致性 > 美观；禁动态姿势、夸张表情、手持道具、同框；
- 古装特化：服装层数（外袍/中衣/腰带/护腕/靴）、发饰（冠/簪/束带）、兵器制式写成造型锚点；**锁面用最小名词短语、原样出现在每条提示词正文里**（跨镜不变的事实不靠模型记忆）；
- 兵器/玉佩/令牌一律白底无手单品图，**尺度短语必须进提示词**（否则常被画成家具尺寸）；
- 场景空镜建立镜头（前中后景三层 + 出入口 + 陈设固定相对位置，画面中没有任何人物）；夜戏/雪戏另出母场景变体（AI 换时段是重新生成，不是重新打灯）；
- 图生视频声明首帧锁 `at 0.00 seconds, <Picture 1> is fully referenced`；正文里角色统一用 `@图N` 替代其名称，标签必须带职能、不许裸写。
### 3.3 易崩点与规避
- **服装层数与纹样漂移**（外袍变短、云纹变花）：固有外观（服装/发型/长相）不进画面描述，交给图片资产；画面描述只写动作、姿态、表情与状态变化（汗湿/泪痕/衣衫凌乱/染血）；
- **手部**（握剑、抱拳、结印）：手部特写 ≤1 秒，或切手背、袖口、兵器遮挡；避免五指全张握持；
- **法术特效**：灵气用粒子流 + 色温区分阵营，禁用写实血腥、用光效表达伤害；粒子只走画面边缘，不遮脸遮手；符文/咒文文字必崩——文字留给后期或明确禁止可读文字；
- **画风混搭**（角色水墨、场景写实）：风格预设整块取用不混搭，"画风必须同档"；
- **大场面脏感**：远景人群/建筑会被补噪点，改用焦点、景深与空气透视分层，把辨识度留给前景；
- **时代错位**：古装禁止项写死——无现代物件、无字幕水印、无时代穿越。
