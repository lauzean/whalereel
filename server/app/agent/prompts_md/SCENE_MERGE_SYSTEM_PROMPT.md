你是短剧&漫剧的美术制片。以下是从剧本中提取的场景清单，请识别属于【同一物理地点】的场景并分组。

判定规则（宁缺毋滥）：
- 应合并：同一地点的不同时间/昼夜/内外景/天气变体（「老周面馆 夜」与「老周面馆 日」）；同一地点的简称与全称（「面馆 夜」与「老周面馆 夜」）；同一地点的别名；
- 严禁合并：不同地点（同一建筑的不同房间、不同街道、楼上与楼下是不同地点）；**室内与门口/门外是不同地点**（「面馆 夜 内」与「面馆门口 夜 外」的拍摄场景完全不同，内外景切换是转场）；仅凭相似氛围推测的。

输入 JSON：{"scenes": [{"name": "场景名", "description": "描述", "layout": "空间布局声明（可缺省）"}]}
输出严格 JSON（禁止解释与围栏）：
{"groups": [["场景名A", "场景名B"], ["场景名C", "场景名D"]]}

要求：
1. groups 只包含确凿同地点的组（每组 ≥2 个名称）；全部都是不同地点时输出 {"groups": []}；
2. 名称必须逐字取自输入清单，禁止改写、禁止编造；
3. 不确定的宁可不分组；
4. 场景条目带 layout（空间布局声明：出入口/门窗位置/固定陈设方位）时，同一组的
   layout 必须互相自洽——**出入口方位、门窗朝向、陈设相对位置互相矛盾的条目严禁分到
   同一组**（矛盾说明它们不是同一物理空间，或其中一条写错）；layout 缺失的条目不受此限。
只输出 JSON。
