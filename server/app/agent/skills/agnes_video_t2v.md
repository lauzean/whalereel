## 一、生成模式（决定提示词写法）

| 模式 | 触发条件 | 提示词要点 |
| --- | --- | --- |
| **text** | 无图像输入 | 需完整描述主体与场景；无首帧锚点，一致性全靠文字 |
| **keyframe** | 仅首帧 | 官方语义：输入图即**实际首帧**。描述首帧之后的**动态延续**，**勿重复描写首帧静态外观** |
| **reference** | 带参考图 | 首帧并入 images 末位；提示词中「（参考图N）」对应 `<Picture N>`，**编号必须严格对齐** |

**关键纪律**：`first_frame` 与 `reference_image` 是**互斥模式**——不要在同一请求里既当首帧又当参考图（端点会 400）。有首帧时系统走 keyframe/reference，参考图的资产信息已体现在首帧里。

## 二、画面描述结构（六要素顺序）

①主体与场景 → ②动作与变化 → ③镜头语言 → ④视觉风格 → ⑤声音与节奏 → ⑥一致性要求

- **单镜头只写一个连贯动作**（在本镜时长内可完成），不要在一句话里塞多个镜头切换。
- **运镜用具体动词**：推近/拉远/环绕/跟拍/手持晃动/平移；禁「高级感运镜」等抽象词。单镜头只指定 **一种** 主导演镜。
- **动作与运镜分开表述**，避免混写导致模型把运镜和动作搅在一起。
- **时序敏感**：动作先后顺序即播放顺序，避免倒装句。

## 三、长度预算

| 段 | 预算 |
| --- | --- |
| 前四段（全局定义/视频画面/画面要求/安全合规） | **250-450 字**（10 秒以上长镜 ≥350 字） |
| 声音设计 | 20-60 字 |
| **合计上限** | **≤900 字**（含参考图用途声明可略增） |

密度不足 → 画面空洞；超长 → 关键约束被稀释（实测均值 1027 字，偏长）。

## 四、原生音频（重要特性）

Agnes Video **原生生成音频**，声音描述直接决定成片听感：

- 环境声写**层次与变化**（雨声密度 / 灶台蒸汽声 / 街道远近声），不写"有环境音"这类空话；
- 台词**只补语气**（哭腔/冷笑/低吼），**不重复原句**（原句已在画面小节里）；
- **台词必须清晰可闻**——原生音频会**按画面的空间关系摆放声源**：角色**背对镜头**、背对另一角色、或处在远景里时，不额外写清楚就会被处理成远场，成片里台词小到听不见（实测「背影 + 背对 + 不回头」的镜，说话人音量几乎不可闻）。这类镜必须补一句「**台词清晰可闻，音量不因背对或距离而衰减**」；
- 无配乐需求**不写配乐**（成片 BGM 由合成环节统一叠加）；镜头内音乐仅在剧情明确需要（收音机/现场演奏/铃声）时写明。

## 五、参考图对齐（reference 模式）

- 编号规则：「（参考图N）」↔ `<Picture N>`，**顺序即 images 数组顺序**（首帧在末位）。
- **首帧必须写明用途**：`<Picture N> 是本镜头的起始画面，视频必须从该画面开始并保持人物与场景连贯`——不写时模型可能把首帧误当"主角定义图"。
- 参考图张数上限约 5 张（含首帧）；**超限时尾部先裁**（道具/场景先掉），故按「角色 > 场景 > 道具」排优先级。

## 六、易崩点与规避

| 风险 | 表现 | 规避 |
| --- | --- | --- |
| 流体动作 | 倒水/洒落演成喷涌 | 只拍**结果态**（液体已在杯中、碎片已散落），过程靠声音与反应镜暗示 |
| 镜面反射 | 镜中同框人物错乱 | 只拍背影或局部，严禁镜中人物同框 |
| 复杂碰撞 | 摔倒/撞击穿模 | 拆「撞前/撞后」两镜，过程留白 |
| 手部精细交互 | 多指/穿模 | 降级为「手部入画局部」或切反应镜 |
| 大幅动作 | 狂奔/大跳变形 | 优先**低缓连贯的小动作**（缓慢抬手/微微低头），写明动作承接（借转身惯性顺势抬手） |
| 多事件塞一镜 | 画面混乱 | 一个片段只承载**一个可见节拍 + 一个摄影机想法 + 一个终点** |
| 首帧被跳过 | 视频不从首帧起像 | keyframe 模式已保证；reference 模式必须写 `<Picture N> 是起始画面` 句 |

## 七、跨镜一致性

- 同场景连续镜：上一镜的**尾帧状态 = 本镜首帧状态**（站位/持物/朝向不得跳变）；
- 人物外观全程以角色参考图为准，**服装/发型不得无端变化**；
- 台词与画面同镜（避免"只有声音没有画面"的广播剧形态）。

## 操作纪律（对 LLM 的硬约束，违反即不可用）

- **不得降级或替换模型**：用户配置了哪个模型就用哪个（含档位与端点）；不可用时报错并说明原因，**禁止自行改投其它模型或档位**——这与项目「禁止静默回退本地推理」同源：失败要看得见，不要悄悄换个差一点的。
- **组装之后不再改写**：系统组装完成的提示词（@引用解析、参考图预算裁剪均属**组装环节**，允许）到端点之间**零改写**——不追加标题/前缀/后缀/风格词/质量词，不改标点与换行。参数（画幅/时长/参考图）一律走独立字段，不写进提示词正文。
- **不使用 `--` 符号**：该符号之后的内容可能被模型截断，不会被解析或响应。

**本模型专属**：

- **参考图编号严格对齐**：提示词里的「参考图 N」必须与传入的图片顺序一一对应，不传入的图不得提及。
- **负向控制仅限字幕与音频**：画面内容一律正向描述。
