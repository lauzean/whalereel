## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
观众要的是「孩子不受委屈 + 亲人终相认」。委屈必须来自外部（孩子无错），父母责任越小共情越强——开场就让观众想护住他。
- 情绪基调：共情 40% + 委屈 30% + 和解 30%（报告家庭伦理类），不中途大改基调。
- 爽点锁一种：归属（一家人重新在同一张桌上吃饭）或秩序（被藏起来的身世逐条还原真相）。
- 落地：全剧要有一个孩子始终攥着的小物件（半张照片、一枚纽扣、手腕上的胎记），它是认亲的唯一凭证，也是每一集「他还不知道」的钩子。
- 信息差用「观众上帝型」：观众知道孩子的身世、主角配角都不知道——观众一边期待相认、一边替孩子着急。

### 1.2 单集结构公式
本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（黄金单集公式）。
- 每场必须改变至少一项：信息/权力/关系/情绪/物理状态/风险，无变化就删或并场。
- 每场至少一个动作节拍（纯对白场是广播剧，AI 没有画面可写）；带娃戏天然有动作源：喂饭、系鞋带、擦嘴、背书包、牵手过马路。
- 单集三栏齐全：钩子 + 悬念 + 爽点（或虐点）认领；可整集套「危机-救赎」共情布局（报告情绪模板 3）：遇难题（共情）→ 求助无门（绝望）→ 贵人出现（惊喜）→ 亲情升温（温暖）。

### 1.3 情绪配比（数字）
- 共情 40% + 委屈 30% + 和解 30%。
- 萌宝阶段配比：带娃回归逆袭 1%–20% → 男主发现孩子 + 解开心结 21%–50% → 联手反击反派 51%–80% → 家庭团圆 81%–100%（报告类型节奏框架）。
- 单集 = 1 核心情绪 + 1 辅助情绪 + 1 结尾钩子；核心情绪 ≤2 个；孩子的情绪是放大器不是主线——配角情绪不能盖过主角。
- 每集正文 500–800 字须覆盖爆点/虐点/爽点至少一个（硬性）；连续 3 集无爆点＝严重；不允许连续 3 集同一情绪强度。
- 虐点逻辑：关系越紧密虐感越强——亲子之间的伤害最催泪（被叫「没爸的孩子」比挨打更疼）。

### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个情绪冲击、15 秒一个剧情变化、45 秒一个强期待（孩子被推出门 → 母亲当众蹲下把他护在身后 → 一辆车停在门口）；强期待里必须留出主角做抉择的时空。
- 开场 3 秒抛最强钩子、2 秒防划走、5 秒勾住人；第 1 集前 10 秒交代主角是谁/什么危机/核心冲突。
- 开头 3 秒最强钩子 + 中段每约 30 秒一个小钩子 + 集尾定格最高冲突；永不解决问题、永不圆满收尾（团圆必须留到 81%–100%）。
- 付费卡点在第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集（±2 集内），必须卡在主线上，每卡点 ≥1 个可剪 30 秒投流点；前 3 集就要有付费冲动，前 10 集凑 ≈10 个可剪爆点。
- 拉扯：约每分钟晃一次弹簧、每 3 分钟一次完整「压—弹」；只一压一弹仅算及格。

### 1.5 爽点配方（装 → 打脸 → 震惊 → 收获）
- 装：孩子的身份被藏着——穿旧衣服、没有爸爸来接，被当成「拖油瓶」。
- 打脸：当众认亲——家长会上那句没敢说的话被孩子自己念出来，父亲第一次从家长席站起来。
- 震惊：围观家长态度 180° 反转——从「没爸的孩子」到窃窃私语「原来是他家的」。
- 收获：户口本上写上名字、搬进新家、第一次有人在校门口等他。
- 三段拍法：①孩子在门外（低机位平孩子视线，门里是热闹的大人）②凭证出现（特写照片 / 鉴定书 / 手腕胎记）③相认（愣住 → 东西掉落 → 跑起来，拥抱用背影 + 手部特写，不拍贴脸大特写）。

### 1.6 反转与钩子模板
- 股价级反转全剧 ≈3 个（>4 或 0 均为问题），骨架阶段定死，预埋集必须早于揭晓集。
- 萌宝常用预期误导（观众以为孩子是女主亲生，反转是另一种血缘真相）；人设颠覆只用在配角（假千金 / 恶婆婆 / 势利亲戚），不动主角核心底色；动机置换＝当年的抛弃其实是被设计；不藏信息、画面 100% 真实，空降硬凹＝烂尾。
- 单集钩子级反转 ≤1 个：道具伏笔（小物件颠覆用途）/ 情绪回弹（拉满→踩碎→回弹卡结尾）/ 镜头错位（真局部误导，下集全景揭晓）。
- 集末钩子两套并用、不可全是悬念：关系内部钩子（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）。
- 高频形态：认亲被中断（车来了 / 电话响）/ 孩子喊了一声却没人应 / 只看到一半的短信 / 门缝里听见半句。

### 1.7 台词特征
- 单句 ≤20 字（竖屏阅读速度），一口气上限 ≤35 字、单角色单次 ≤50 字——孩子台词再短一档。
- 童言直击：孩子不解释、只下判断（「你不是我爸爸，因为你不认识我妈妈的眼睛」）。
- 要展示不要告诉：禁自爆家门式台词；动作 > 台词——把孩子护到身后，比十句「我会保护你」都重。
- 称谓是本题材的武器：叫不叫「爸 / 妈」、什么时候改口本身就是戏——改口是一个可拍的停顿（张嘴 → 没出声 → 低头），不是一句台词。
- 孩子要有 2–3 个全剧复用口头禅；大人说人话，禁半文半白。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 孩子视角用低机位（蹲下来拍他的眼睛高度）：孩子仰头看大人用低机位仰拍，大人低头看孩子用高机位俯拍——身高差就是权力差。
- 带娃走路用跟移中景，主体保持在画面上 2/3；牵手、递东西、擦嘴优先给手部特写。
- 重逢 / 相认用距离镜头语言：隔着人群远景 → 跑过来的全景 → 蹲下同框中景 → 手部特写（握住）。
- 亲情升温给 5 秒安静镜头（环境音抽走，只留呼吸和孩子的鼻音）。
- 反应镜头是免费的戏：孩子的脸给 2–3 秒，比任何台词都值；进场三件套：第一切必须有主体运动 → 大远景定场 → 关键局部特写。
- 运镜语义：手持轻晃＝不安，缓推＝靠近与心软，固定长镜＝对峙；固定是默认，一段超两种运镜就是炫技。

### 2.2 节奏与单镜复杂度（数字）
- 段（一次生成）≤15 秒、不跨场次；段内分镜 2–5 秒（硬门），3 秒一切是短剧的呼吸。
- 儿童动作必须拆小：「跑过去抱住」拆成起步背影 / 跑动跟移 / 抱住三个 2–3 秒分镜。
- 单镜同框 ≤3 人，超限必须拆镜并给拆解思路——家长会、幼儿园、家庭聚餐是高发场景。
- 台词装得下：镜头秒数 ≥ 认领台词字数 ÷ 4.5 + 2 秒余量；无台词镜 ≤6 秒。
- 一镜画面描述 15–50 字；超 8 秒或含场景切换＝过度合并；整集时长落在目标 ±15% 内。

### 2.3 情绪可视化（可拍细节）
禁情绪形容词，只写能拍到的动作与状态：
- 委屈（孩子）＝吸鼻子 + 用袖子擦脸 + 攥着衣角不松手。
- 强撑（单亲父母）＝把眼泪憋回去，蹲下来对孩子笑，再替他整理一次衣领。
- 期待（等亲人）＝趴在窗台往外看 + 听到脚步就起身 + 又坐下；害怕＝躲在大人腿后只露出半张脸 + 抓住裤腿。
- 团圆＝先愣住 → 手里的东西掉落 → 跑起来 → 抱住时手在对方背上收紧。
- 亲人受伤不拍嚎哭，拍「手抖着给他擦脸，越擦越脏」（写动作不写形容词）。
- 情绪四通道择一或叠加：行动（撕扯、狂奔、攥手）/ 语言（哭喊、语塞、结巴）/ 环境（阴雨、空街、满桌家常菜）/ 独白（难言之隐用 OS 或 VO）；光照不写光影词，走场景衍生资产（「家·傍晚版」）；转场用生活动势（关门、挂电话、电梯门合拢）。

### 2.4 常见钩子的镜头落法
- 认亲被中断：凭证特写入画（照片 / 鉴定书）→ 画外一声刹车或电话铃 → 定格在凭证被合上 / 被夺走。
- 只看到一半的短信：屏幕特写关键行入画即卡 → 切孩子抬头。
- 孩子走失：空镜（还在转的玩具 / 晃动的门）→ 摇到空荡的街 → 定格在一双小鞋。
- 门缝里听见半句：门缝的窄构图（只看见大人的半张脸）→ 孩子的手停在门上 → 定格。
- 情绪回弹：拉满预期的全景 → 踩碎预期的特写 → 回弹动作卡住；段尾留钩必须是具象物（照片、纽扣、没关的门）。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表（可拍 vs 必崩 + 替代拍法）
可拍：牵手、蹲下、递东西、摸头、擦嘴、背书包、把孩子护到身后、拍背、并排坐着、一起吃饭、系鞋带（俯拍特写）、按电梯。
必崩 → 替代：
- 孩子奔跑大笑的长跟拍 → 拆三镜：起步背影 2 秒 → 跟移中景 2 秒 → 站定笑 2 秒。
- 抱起旋转 / 抛起 → 只拍「蹲下张开手」+「扑过来的背面」两镜。
- 抱住大哭（面部贴脸）→ 改用背影 + 手部特写，面部贴合最易崩。
- 精细手部（系鞋带、拉拉链、喂饭）→ 俯拍特写 + 手入画即止；哭到抽搐 → 单镜 2–3 秒「眼眶红 → 一滴落下来」。
依据：只写 AI 见过千万次的常见动作，精巧动作生成必崩。

### 3.2 参考图策略
- 孩子定妆三视图（正 / 侧 / 全身）＋半身近景；三视图的脸必须与半身像一致、三个全身像比例必须协调（模型会为塞细节把人压扁）。
- 年龄感靠身高与面部比例的锚点写进参考图（报告未给出，建议值）；校服 / 睡衣 / 礼服是同一角色的变体，不是新身份。
- 凭证道具必须有独立白底无手参考图（照片、纽扣、长命锁）+ 尺度短语（防画成家具尺寸）；胎记类特征写进角色定妆，不写进每镜描述。
- 优先级（报告未给出，建议值）：①孩子定妆 ②男女主定妆 ③关键配角（奶奶 / 老师）④主场景空景（家 / 幼儿园 / 公园）⑤凭证道具；图与文冲突时模型听图的。

### 3.3 易崩点与规避
- 多人同框必然超限：家长会、幼儿园、家宴要拆镜，群演只做微动作（遮、瞥、垂、攥），不给群演单独配台词，焦点锁主角。
- 孩子与成人体型差 → 用低机位、俯拍、手部特写回避全身同框；跨镜孩子换脸 → 每镜都挂孩子定妆图，提示词不写长相。
- 禁光影色调词（光 / 影 / 逆光 / 色温 / 色调 / 暖色 / 冷色），光照走场景衍生；音效只写环境音 + 动作音（每场给 1–2 个可感知的核心环境音，如蜡芯噼啪、远处风声），禁 BGM / 配乐。
- 人物外观（服装 / 发型 / 长相）不进画面描述，只写动作、姿态、表情与当下状态变化（汗湿、泪痕、衣衫凌乱）。
- 在场人物不能消失：带娃戏人物多、最容易漏——未离场角色每镜要有视觉落点（背景 / 局部 / 反应镜 / 虚焦剪影 / 前景遮挡）；冻结关键帧只投影镜头起点。
- 八病自查：舞台剧病 / 均匀病 / 秒数漂移 / 台词爆仓 / 声景漏改 / 换景不换段 / 改切不读邻切。
- 反模板条款：不为检查表硬加秘密、反转或人物弧；若自检让剧本长出输入没有要求的机关，撤掉机关而不是替它找理由；审片意见须带位置 / 引文 / 影响 / 修订结果，不能只说「AI 味」「不够电影感」。
