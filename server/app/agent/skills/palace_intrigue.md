## 一、剧作层
### 1.1 题材定位与观众期待
爽点本质：主角在一套压死人的规矩里，用脑子把规矩变成武器。报告的心理级爽点里，「秩序」（用逻辑推进还原真相）点名「宫斗」，「归属」（家族/母族/同盟）可作辅线——锁定其一为核心。桥段原创性红线：报告点名"宫斗避开「下毒、推水」，改用「心理操控」式陷害"——陷害要落在信息与人心上（挑拨、借刀、改口供），不靠毒药道具。反派必须有合理动机（纯嫉妒害人是低级写法）；矛盾沿四级阶梯抬到 3-4 级——两个好人因不同选择走向不同命运。
### 1.2 单集结构公式
本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（报告黄金单集公式）；每集 500-800 字须覆盖爆点/虐点/爽点至少一个，单集正文 ≤1000 字、按 150 字/分钟折算，单集钩子级反转 ≤1 个。
### 1.3 情绪配比
报告未单列宫廷配比；沿用其近亲「复仇类＝压抑 40% + 爽感 50% + 解气 10%」。宫廷细化配比（报告未给出，建议值）：憋屈 40% + 反制 45% + 揭秘 15%，可作项目级参数覆盖。
### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个情绪冲击、15 秒一次剧情变化、45 秒一个强期待，强期待里给主角留出做抉择的时空（人物刻画在此完成）；
- 钩子黄金布局：开头 3 秒最强钩 / 中段每约 30 秒一个小钩 / 集尾定格最高冲突——永远不解决问题、永远不圆满收尾；
- 拉扯：约每分钟晃一次弹簧、每三分钟完成一次完整「压-弹」，全剧晃 ≥3 次（先给"危机解除"的错误预期，再致命一击）；
- 付费卡点在第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集；宫廷卡点天然落在宫宴/朝会/册封/审案这类"场面宏大、事态紧急、围观群众多"的场合（报告付费点核心特征）；
- 爽点间隔 ≤3 集无真空（报告阈值），每卡点对应 ≥1 个可剪 30 秒的投流素材点。
### 1.5 爽点配方
装（称病避锋、示弱让位）→ 打脸（当众亮出物证或口供）→ 震惊（满堂宾客态度 180° 反转：瞠目、后退、交头接耳）→ 收获（掌家权/掌印/圣心），四件套缺一件不成立。
### 1.6 反转与钩子模板
全剧股价级反转 ≈3 个、骨架阶段定死：预期误导（引观众得出"合理的错误结论"）、人设颠覆（只能用在配角，绝不动主角底色）、动机置换（同一行为适配表层/深层双动机）。单集钩子级反转 ≤1 个且不连续同招：道具伏笔（一封被调换的信）、情绪回弹、镜头错位（局部画面误导，下集全景揭晓）。钩子两套并用：关系内部（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）。
### 1.7 世界观与设定可视化的剧作要求
世界观呈现策略四问：关键设定何时出场 / 解释度（模糊-暗示-明确）/ 谁作锚点角色 / 观众视角对齐谁。宫廷的设定就是规矩，靠人物态度锚定而非解说——**大段旁白讲世界观是红线**。等级必须可视化：能坐还是能站、用金器还是瓷器、袖口纹样与冠制，等级差异全部落到可拍物件。法则镜头：这世界的"什么不能做"用一个惩罚镜头立规矩（越礼→当众夺簪/罚跪），比十句台词有效。观众视角与主角对齐，和主角一起发现。
### 1.8 台词特征（古装称谓与语体）
- 报告语言适配红线：**所有台词口语化，禁半文不白、禁生词冷词**——古装同样适用，古味靠称谓、礼数与语体节奏，不靠文言；
- 称谓与官职：报告要求避开现实官职（原例：禁「市长」「县长」，改「市首」「总督」；家族掌权人称「家主」，执法者称「执法局/执法人」）；架空朝代与架空官制（报告未给出，建议值）——用「家主/掌印/中宫/娘娘/老奴」类称谓，不写真实朝代、真实历史人物、真实官制；
- 禁"自爆家门式台词"（别让人物一出场就喊身份喊目的），能靠一个眼神/动作传递的信息不用嘴说；
- 单句 ≤20 字（超 20 字必须拆镜）、单角色单次 ≤50 字、硬门 ≤35 字；遮名测试：遮住人名仍能凭语气认出说话人。

## 二、分镜层
### 2.1 景别与运镜语言
- 等级靠机位：上位者给平视或微仰，下位者给俯视；同一场里镜头角度随权力关系翻转而翻转；
- 正反打派规矩：对话切正反打，**谁的台词信息量大谁的脸给得近**；冲突顶点切对方沉默的特写，比吵架更狠；
- 器物即台词：茶盏的捧法、袖口的攥紧、账册翻页、指尖虚点桌面——权谋的暗流全在手上；
- 前景遮挡造窥视感：屏风、珠帘、门缝、廊柱后——宫斗一半的戏发生在"有人偷看"里；
- 进场三件套：第一切必须有主体运动（静物特写开场是死画面）→ 运动主体 → 大远景定场 → 关键局部特写；
- 复杂群戏先锁空间锚点与屏幕方向，再决定景别变化（报告镜头边界规则）。
### 2.2 节奏与单镜复杂度（数字）
- 报告硬门：段（一次生成调用）≤15 秒不跨场次；段内每切 2-5 秒并认领剧本节拍；3 秒一切是呼吸节奏；
- 段落分层：过渡段 8-10 秒 / 叙事段 10-15 秒 / 爆点段 12-15 秒（审案、揭穿、册封这类爆点段子镜可放慢到 4-6 秒）；
- **同框 ≤3 人**：宫宴、朝会、排班必须拆——多人同景是 AI 串脸与配角乱跑的第一高发区，超出必须带拆解说明；
- 台词装得下：段时长 ≥ 台词字数 ÷ 4.5 字/秒 + 2 秒表演余量；单镜台词 >20 字拆成连续多镜，按语义停顿点切、不平均切；
- 每场至少一个动作节拍——纯对白的场是广播剧，AI 生成时没有画面可写（报告反广播剧门）。
### 2.3 情绪可视化
- 禁情绪形容词，写可见物理事实：呼吸变浅、指节抵住桌沿、下颌绷紧、肩颈下沉、视线停留时长、步态快慢；
- 反应有层级：重大信息的反应按「僵住 → 确认（回看、靠近、再读一遍）→ 释放（行动、崩溃或压下去）」推进，每个镜头只承载一层，不许一步到位大哭大叫；
- 潜台词 = 身体与台词的反差：嘴上说"臣妾不敢"，手指在袖口收紧——反差只能建立在剧本已有的情绪事实上；
- 环境情绪通道：压抑=空殿、香灰落地；紧张=更漏声放大、烛火压低、脚步回声变长。
### 2.4 常见钩子的镜头落法
- 集尾最后 30 秒：一份被调换的礼单、一句没说完的称呼、屏风后退出的一角裙摆；
- 道具即伏笔：账册/密信/玉佩/香囊/药碗每集至少给一次特写存在感；
- 音画跨片段同步：前一段末尾的台词或撞击声延续到后一段首镜，由画面承接（前段末一声"咚"，后段首镜是还在打转的茶盏）；
- 冻结关键帧只投影镜头起点——终点才出现的文字、动作、道具状态一律删除。

## 三、模型适配层
### 3.1 动作幅度表（多人礼制场面是本题材高危区）
可拍（单镜 ≤3 秒）：行礼与起身的一拍；拂袖转身；端茶递物；拍案；抬手直指；掀帘入殿；单人缓步上阶；耳光（出手瞬间切反应镜）。
必崩：几十人整齐朝拜的全景（人数、朝向、服色全乱）；宫女队列行走（同款服装=串人）；两人以上拉拽撕扯超过 2 秒；杖责、刑具、缢死等写实刑伤；两人抬人拖人；下毒、换药、洒酒这类精细手部操作；多人依次跪拜的长镜。
替代拍法：朝拜用局部组接——跪下的膝、一片衣摆、殿顶、香炉烟，配环境声（报告：声景也是动作指令）；多人场景按报告原文处理：前景 1-2 个具象人物做微动作（遮、瞥、垂、攥），后方人影失焦、人头攒动，焦点锁前排，**禁给群演单独配台词**；刑杖用声音 + 旁观者反应镜；下毒改为"看到药碗被换手"的结果镜。
### 3.2 参考图策略
- 角色三视图定妆：左正脸特写 + 右侧正面/90° 侧面/背面三张等高全身视图，同一张脸/发型/服装，中性 A 字站姿、柔和棚拍光、纯白背景；一致性 > 美观；禁动态姿势、夸张表情、手持道具、同框；
- **造型变体不是新身份**：朝服/常服/寝衣是三张变体参考图——先写"什么不变使它仍是同一资产"，再写本集变化（服装、伤势、湿污、持物通常是变体）；
- 佩饰作身份锚点逐张锁住：冠、簪、腰牌、护甲、披风纹样；**锁面写成最小名词短语，原样出现在每条提示词正文里**（跨镜不变的事实不靠模型记忆）；
- 场景空镜建立镜头（大殿/寝殿/廊下：前中后景三层 + 出入口 + 陈设固定相对位置，画面中没有任何人物）；日戏与夜宴各出母场景变体（AI 换时段是重新生成，不是重新打灯）；
- 账册、密信、玉玺、药碗、灯烛走白底无手单品图，**尺度短语必须进提示词**；审案/宫宴这类走位复杂的戏先喂俯视调度图或红蓝双色轨迹（红=人物、蓝=镜头）。
### 3.3 易崩点与规避
- **文字必崩**：圣旨、账册、密信、匾额上的字交后期或明确禁止——可见文字、logo、水印、界面和字幕必须明确允许或禁止；确需文字时只给部件局部并声明"上面是手写的中文"；
- **手部**（行礼手势、递茶、写字、拈香）：手部动作 ≤1 秒，或切手背、袖口遮挡；
- **刺绣、珠串、点翠细节漂移**：不靠文字描述纹样，交给定妆图；远景与群像弱化细节；
- **多人同款服装串人**：同框 ≤3 人，用发冠/披风/纹样区分身份，前景遮挡分段；
- **长横移穿过人群**：改固定机位 + 局部组接，移动交给下一镜；
- **时代错位与画风混搭**：禁止项写死（无现代物件、无真实朝代官职、无字幕水印）；风格预设整块取用不混搭，"画风必须同档"；
- **大场面脏感**：远景人群与建筑会被补噪点，用焦点、景深、空气透视分层，把辨识度留给前景。
