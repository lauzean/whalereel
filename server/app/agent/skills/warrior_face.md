## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
- 观众要的不是"强者赢"，是**强者被当成废物之后再赢**：满级能力前置，当众受辱→隐忍→亮身份→群众态度 180° 反转。
- 心理级爽点锁「优势/金手指」：主角独有能力（军功/医术/手腕）让观众崇拜，且必须有约束（如不能对在乎的人用），无边界即贬值。
- 代入感底线：**无责受难**（困境外部强加，责任≈0；报告：多 1% 责任少约 10% 共情）、**穷而不脏**（领口旧但扣得整齐）。
- 男频形态「隐刚义柔」：隐=有正当动因的蛰伏（为查旧案才当保安）；刚=一招制敌不缠斗；义=恩怨分明护短；柔=专属软肋（旧部、亡妻遗物）。
- 大三角（主角+反一号+1~2 配角）≤4 人；反派必须有合理动机，不做"纯嫉妒"工具人。

### 1.2 单集结构公式
- 黄金单集公式：本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（内部标尺，不写进正文）。
- 全剧框架（报告·战神类）：受辱 1%~30% → 身份曝光打脸 31%~60% → 解决核心危机 61%~90% → 登顶 91%~100%；重生向：前世被害（第 1 集）→ 重生改写 2%~30% → 信息差逆袭 31%~70% → 复仇成功+圆满 71%~100%。
- 一卡三招：第 1 集写清性格/困境/目标/动机 + 敲定类型 + 男女主与反一号登场；2–3 集解决一个与反派相关的重大危机；第 10 集结尾强钩子卡主线。

### 1.3 情绪配比（数字）
- 爽感 50% + 期待 30% + 温暖 20%（报告·重生逆袭类；报告未单列战神类配比，同属爽感主导，沿用此值）。
- 单集 = 1 核心情绪（憋屈或爽）+ 1 辅助情绪（小冲突）+ 1 结尾钩子；核心情绪同集 ≤2 个，配角情绪不能盖过主角。
- 单集 500–800 字正文须覆盖爆点/虐点/爽点 ≥1 个；连续 3 集无爆点 = 严重问题。

### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个信息点（耳光/泼酒/辞退通知）、15 秒一个剧情变化、45 秒一个强期待（并留出主角做抉择的时空）。
- 情绪节点：前 3 秒最高情绪点；中段 30–40 秒第一次反击；结尾 10 秒拉满悬念卡断。
- 拉扯弹簧：压到谷底（压越狠反弹越猛）→ 来回晃 ≥3 次（先给"危机解除"错误预期再致命一击）；约每分钟晃一次、每 3 分钟一次完整"压-弹"。
- 付费点：第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集五个卡点；集尾永不解决问题、永不圆满收尾；前 10 集 ≈10 个可剪 30 秒爆点（每集 ≥1），付费冲动前置到前 3 集。
- 单集体量：正文 ≤1000 字、台词按 150 字/分钟；单句 ≤20 字、单角色单次 ≤50 字。

### 1.5 爽点配方（装→打脸→震惊→收获）
爽点 = 装 + 打脸 + 震惊 + 收获（报告四件套），本题材落地：
- **装**：以最低身份在场（保安/外卖员/上门女婿）被使唤、被扣钱——画面：他弯腰捡起对方扔在地上的工牌。
- **打脸**：压到最狠时亮实力，一招制敌不缠斗——画面：单手按住对方手腕，另一只手把任命文件放上桌面。
- **震惊**：不写"全场哗然"，写具体身体动作——先前叫嚣者手一抖，茶杯磕在桌沿。
- **收获**：地位/物质落地（车队敬礼、合同改签），立刻抛出更大的敌人，避免爽完就空。
- 高频模板（报告·打压-反击）：嘲讽（压抑）→ 变本加厉（愤怒）→ 亮实力（爽感）→ 狼狈道歉（解气），单集循环 1–2 轮；打脸必须有观众——付费点特征 = 场面宏大、事态紧急、围观群众多（宴会/认亲/发布会/婚礼）。
- 矛盾不能只堆吵架：欲望—阻碍抬到第 3–4 级——最好的矛盾是"两个好人因不同选择走向不同命运"（对手为救亲人而站错队）。

### 1.6 反转与钩子模板
- 全剧股价级反转 ≈3 个、骨架定死：常用预期误导（以为要认亲，反转=掏出对方罪证）与动机置换（蛰伏不是落魄，是查案）；人设颠覆只用于配角，**绝不动主角核心底色**。
- 单集钩子级反转 ≤1 个且不可连续用：道具伏笔（工牌/旧军牌）、情绪回弹（拉满预期→踩碎→极致回弹）、镜头错位（局部真画面误导 + 下集全景揭晓）。
- 集尾钩子两套并用：关系内部钩子（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）。
- 反模板纪律：金手指/桥段/反转市面 >10 次就别用；三条死路不碰（"追妻战神→外卖战神"式换汤不换药、照搬"三个巴掌"公共桥段、换皮洗稿）；开篇避三天坑（铺背景讲世界观、一群角色乱冒、慢悠悠写景）。

### 1.7 台词特征
- 短句挑衅 + 短句反杀，单句 ≤20 字，全口语化，禁半文半白与冷词。
- 要展示不要告诉：掰断名牌赛过十句"我要你好看"；反派台词精准戳软肋（骂穷不够痛，骂他儿子会继续穷才激怒）。
- 称谓按短剧规范：「家主」代家族掌权人、「执法局/执法人」代公安，禁用真实官职；财富用"亿元""百亿订单"等夸张表达；每角色 2~3 个复用口头禅作防漂移锚。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 受辱段：过肩/微俯拍 + 人群前景遮挡，把主角压到画面下 1/3；亮身份段：仰拍半身 + 定格 2 秒。
- 第一次交手用 2 秒 insert 特写独立成切（按住手腕/文件落桌）——本段节奏重音。
- 反应镜是免费的戏：重台词后切听者的脸 2–3 秒（手抖、烟按灭）。
- 运镜克制：固定是默认，推给情绪、拉给收场、跟给移动；一段内运镜 ≤2 种；竖屏优先保证主体与反应可见。

### 2.2 节奏与单镜复杂度（数字）
- 报告三层结构：段（一次生成）≤15 秒 → 段内切 2–5 秒 → 平均 3 秒一切（样例 34 切/119 秒 ≈3.5 秒/切）。本平台一镜=报告一次"段"（一次生成 ≤15 秒），单镜档位 5–12 秒（平台既有约定）——段内 3–5 切的信息量由"相邻镜景别跳档 + 反应镜"承担。
- 单镜一个动作变化：切镜必须带来信息/权力/情绪/空间/节奏变化之一；同一动作不跨镜重复；本镜终点=下一镜可信起点。
- 长台词 >20 字强制拆镜，每镜换景别、按语义停顿点切、不平均切；台词按 4 字/秒折算；含台词镜 ≥ 字数÷语速+停顿+1 秒余量；无台词镜 ≤6 秒。
- 同框 ≤3 人：打人戏拆成"单人对单人 + 反应镜"；群演只给微动作（攥/缩/退半步），不抢戏不配台词。
- 画面描述 15–50 字，只写动作/姿态/表情/状态变化；相邻镜景别错开，禁连续 3 镜同景别。

### 2.3 情绪可视化
- 不写情绪写身体：憋屈=指节压白、后槽牙咬紧；翻盘=松领口呼长气；暴怒=青筋暴起、茶杯磕桌。
- 主角的"柔"给物件：一直攥着的旧军牌、没送出的药——每次特写只给一个新信息。
- 环境替人说话：受辱在冷光地下车库/逼仄走廊，翻盘在开阔面光大厅；群演是情绪放大器（一人遮嘴、一人垂目、一人退半步），焦点锁前排，后景失焦。

### 2.4 常见钩子的镜头落法
- 集尾三选一：亮一半的证据（只给物件局部）/ 反派出现在不该出现的地方（背影入画）/ 主角做危险决定前的深呼吸（侧脸+手部动作）。
- 身份即将曝光却被叫停：门推开一半、话到嘴边被一声"住手"打断——定格在开口前一帧。
- 镜头错位反转：本集只给局部真实画面（他抬手按住对方肩膀），下集全景揭晓（其实在拦住要动手的人）；**给观众的画面必须 100% 真实，绝不造假骗人**。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表（可拍 vs 必崩 + 替代拍法）
- 可拍：按住手腕/门/扶人（静态接触+手指细节）；递文件、签字（已完成态）；摔杯（已碎结果态）；单人对单人对峙（同框、1 米内、视线不交汇）；敬礼/单膝/起身（完整定格，一镜一动作）。
- 必崩 → 替代：群架推搡 → 只拍"打完之后"（衣领歪斜、地上散落物件、站定喘气），过程交声音与反应镜；连打 3 招以上 → 拆"起手定格+对方倒地"两镜跳切；掀桌/泼水/砸车 → 撞前撞后两镜，液体只拍已泼出的静态结果；抄酒瓶砸头、见血 → 切旁观者反应+音效，落点永不给画面；飞踢/翻滚/腾空 → 改"错身而过+对方踉跄"；被围推搡 → 只拍被围的静态构图（人群前景遮挡），移动并入下一镜新位置。
- 报告原则：保留内容必须能被 AI 稳定生成、避免生成端执行不了的动作；主动规避 AI 跳脸、画面不连贯、重复场景视觉疲劳。
- 平台机制：以上类别在分镜 risks 标 motion/fluid/collision/hands/crowd，供审片核对与降级路线。

### 3.2 参考图策略
- 必带：主角与反一号定妆三视图（正面/侧面/全身，脸与半身像一致、比例协调）+ 常同框配角的服装主色差异 + 本场场景主图。
- 优先级与上限：角色 > 场景 > 道具；首帧参考图预算 8 张（报告 @Image 编号上限 9，本项目按 8 执行），超预算先裁尾部道具/场景——角色必在预算内，杜绝悬空标注串脸。
- 参考图单一职责：每张只控制身份/造型/地理/构图/风格中的明确部分，逐张声明"控制什么、不得控制什么"；打脸重场（宴会/发布会/签约台）按"同场景+同光照归一批、共用同一张环境参考图"（报告·生成批次单）。
- 关键道具（军牌/合同/工牌）出白底无手道具图——拿着道具的手是最常见污染；跨镜不变的外观写进正文，不靠模型记忆。

### 3.3 易崩点与规避
- 人物漂移：图生/文生分流由"有没有可读参考图"决定；文生镜必须写非空静态视觉锚点，**禁止只写"保持已有外观/preserve/keep"**。
- 服装/发型/长相不进画面描述（交参考图），只写动作、姿态、表情与状态变化（汗湿、泪痕、衣领被拽歪）。
- 文字画面（文件/招牌/新闻标题）高危：改为纸张边缘入画 + 手部动作，关键信息交台词与 OS，别赌模型写对字。
- 同缺陷 ≥2 次停止盲摇（重摇硬上限 2–3 次）改提示词；重拍单变量——一次只改一个子句；同一招不连续用（同一反转/打脸形态），重复镜头与重复场景的视觉疲劳会把观众划走。
