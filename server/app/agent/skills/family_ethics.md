## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
- 观众要看的是「本该最亲的人为什么互相伤害、又怎么回得来」。报告 04a 高频情绪模板 3「危机-救赎」共情布局（家庭伦理类）：主角遇难题（共情）→ 求助无门（绝望）→ 贵人出现（惊喜）→ 亲情升温（温暖）。
- 报告 04a 矛盾四级阶梯第 3 级是本题材的黄金矛盾形态：**两个好人因不同选择走向不同命运**（婆婆要留钱给孙子上学，儿媳要拿钱救住院的丈夫，给谁都对）。
- 报告 04a 虐点核心逻辑：关系越紧密虐感越强（亲人之间的伤害更催泪）；先给主角极致幸福再夺走。
- 报告 04a 铁规矩：反派必须有合理动机，「纯嫉妒所以害人」是低级写法，非工具人。

### 1.2 单集结构公式
- 报告 04a 黄金单集公式：**本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连**。落地：上一场没说完的话 → 本集一次家庭决策（分家、住院、彩礼、养老轮班）→ 有人让步有人记恨 → 集尾把矛盾交给下一个人（一句转述、一个电话、一张单据）。
- 报告 02：每场必须改变至少一项（信息/权力/关系/情绪/物理状态/风险），无变化的场删掉或合并。
- 报告 03 冷开场硬门：钩子是第一拍，hookBeat 必须落在全集前 3 拍内（第一拍给「一张单子」或「一双没洗的碗」）。

### 1.3 情绪配比（数字）
- 报告 04a 原文：家庭伦理类 = 共情 40% + 委屈 30% + 和解 30%；并附禁忌——基调一旦确定不要中途大幅更改。
- 落到画面：共情那 40% 靠「替对方做一件没人看见的事」（半夜把对方的鞋摆正）；委屈 30% 靠「有话说不出」（嘴张开又合上，转身去洗碗）；和解 30% 靠「一件旧物被重新拿出来用」。
- 报告 04a 单集情绪公式：1 核心情绪 + 1 辅助情绪 + 1 结尾钩子；同一集不超过 2 个核心情绪，上下集情绪须衔接，配角情绪不能盖过主角。

### 1.4 节奏曲线（数字）
- 报告 04a 节奏 3-15-45：3 秒一个信息点、15 秒一个小冲突、45 秒一个转折，结尾用反转钩子卡死。
- 报告 04a 钩子黄金布局：开头 3 秒抛最强钩子；中段每约 30 秒埋一个小钩子；集尾定格在最高冲突那一刻，永不圆满收尾。
- 报告 04a 拉扯：约每分钟一次晃弹簧，每三分钟完成一次完整「压—弹」，只一压一弹仅算及格，须来回晃 ≥3 次；报告 04a 开篇：2 秒防划走、5 秒勾住。
- 报告 07 确定性折算：台词 4.5 字/秒、动作 2.5 秒/拍，每集时长达标线 ±15%；单集正文 ≤1000 字、语速 150 字/分钟。

### 1.5 爽点配方
- 报告 04a 爽点核心公式：**爽点 = 装 + 打脸 + 震惊 + 收获**。
- 家庭伦理改写（**报告未给出家庭版，建议值**）：藏拙（装）→ **当众对质**（把账单、病历、存折摊在桌上，打脸落在事实而不是身份压制）→ 亲友态度反转（震惊；亲友是见证人）→ 一句迟到的「这些年辛苦你了」（收获）。
- 报告 04a 心理级爽点：本题材锁**归属**（一家人终于站在一起）与**秩序**（把账算清、把理说透）。

### 1.6 反转与钩子模板
- 报告 04a 股价级反转三式：预期误导 / 人设颠覆（**只能用在配角，绝不能动主角核心底色**）/ 动机置换；全剧 ≈3 个，多了审美疲劳。
- 报告 04a 钩子级反转三式（单集 ≤1 个）：道具伏笔反转（本集高频出镜小道具翻转真相）/ 情绪回弹反转（完播保底神器：拉满预期 → 踩碎 → 极致回弹）/ 镜头错位反转（最易上手，每集结尾可套）。
- 关系内部钩子四类：身份颠覆 / 人性撕碎 / 胜负碾压 / 真相反转。
- 反模板纪律（报告 02/03）：**不为检查表硬加秘密、反转或人物弧**；若自检让剧本长出输入没有要求的机关，撤掉机关而不是替它找理由。

### 1.7 台词特征
- 报告 04a 台词节制：单句 ≤20 字（竖屏阅读速度），单角色单次 ≤50 字，台词量按 150 字/分钟 推算；单镜台词 >20 字须拆镜。
- 报告 04a 精准戳点：针对角色软肋设计台词（骂他没用，戳他亏欠谁才有用）；用高效潜台词，一句话同时推进剧情、塑造人物、传递冲突，但不写需要观众费力猜的晦涩潜台词。
- 报告 04a 展示不要告诉：能靠一个眼神、一个动作传递的信息坚决不用嘴说；家庭称谓即关系（妈、婆婆、他爸、一个「喂」），换称谓就是换关系状态。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 报告 03 运镜克制：固定镜头是默认；推给情绪、拉给收场、跟给移动；一段里超过两种运镜就该问自己是不是在炫技。
- 家庭调度核心（**建议值**）：**同框不同心**——同一画面里两人各做各的事、视线不交汇，就是家庭伦理的张力；用「距离镜头语言」推进关系：隔桌全景 → 并肩中景 → 同框特写，物理距离即关系距离。
- 报告 03：进场三件套（运动主体 → 大远景定场 → 关键局部特写）；对话切正反打，**谁的台词信息量大，谁的脸给得近**；反应镜是免费的戏——重台词后切听者的脸 2–3 秒，不用写词。

### 2.2 节奏与单镜复杂度（数字）
- 报告 07/03 三层结构：段 ≤15 秒；分镜 2–5 秒【硬门】；段内 3–5 切。
- 报告 04a：片段累计 ≤15 秒；含台词镜时长 ≥ 台词字数 ÷ 4 字/秒 + 标点停顿（每标点 0.3–0.5 秒）+ 1 秒安全余量；无台词镜 ≤6 秒；画面描述 15–50 字。
- 报告 04a：一镜超 8 秒是过度合并信号；同段对话拆 >3 镜且无景别切换是过度拆分；报告 03：**动接动**——切点选在动作中间而不是动作完成后。
- 报告 03：同框 ≤3 人，超了必须给拆解（家庭群戏最常撞这道门）；报告 07：每景一致性锚点 3–5 个。
- 家庭专属（**建议值**）：争吵戏单镜 ≤4 秒快切，沉默戏可放到 6 秒（无台词镜上限）——一快一慢就是家庭戏的节奏对比。

### 2.3 情绪可视化
- 报告 03 锚点标准：锚点要「可画、可认可、可核对」——「补丁船篷」是锚点，「陈旧的氛围」是形容词。
- 报告 07：禁情绪形容词，写可拍的生理与动作细节（写呼吸变浅，不写她很紧张）。
- 报告 04a 情绪表达四通道：行动 / 语言 / 环境 / 独白；环境通道原文——悲伤压抑用阴雨天、空无一人的街道、昏暗房间，甜蜜温暖用夕阳、暖光客厅、满桌家常菜。
- 家庭情绪表（**建议值**）：委屈 = 收拾别人吃剩的碗筷；心疼 = 把好的那块肉夹给谁；忍让 = 把手里的抹布攥一下再继续擦；和解 = 把凉了的饭重新热上；生气 = 不出声地把东西放重。

### 2.4 常见钩子的镜头落法
- 报告 04a 镜头错位反转：给观众 100% 真实的局部镜头误导 → 集尾卡住 → 下集全景揭晓（特写把一个红纸包塞进对方手里，全景=那是凑给孙子的学费）。
- 报告 03：段的最后一切留钩，要么是悬念的具象（口袋、铜扣、灯），要么是下一段的引子。
- 家庭版集尾落法（**建议值**）：集尾只给「一张单子」——病历、缴费单、协议、房本，只露一角或只念半句，配一声门响。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表
- 报告 03：动作节拍只写 AI 见过千万次的常见动作（挑担上船、搭手卸担）；精巧动作（伸篙一挡、睫毛颤）生成必崩。
- 可拍（**建议值**）：端碗、递茶、起身让座、搀扶、拍背、擦桌、剥橘子、数钱、翻相册。
- 高风险：拥抱（两人肢体粘连易崩）、喂饭、背负伤者、激烈推搡、孩子哭闹奔跑。
- 替代拍法：拥抱 → 只给手搭在肩上 + 被抱者闭眼一拍；哭泣 → 低头加抬手遮脸，不给满脸泪痕的正面特写。

### 3.2 参考图策略
- 报告 05：角色三视图定妆（正面/侧面/背面）跨集复用，每角色固定音色；报告 07：一致性 > 美观。
- 报告 03：每张参考图只控制身份、造型、地理、构图或风格中的明确部分（参考图单一职责）；环境与角色是两层资产，空景参考图里混进人，一致性全毁。
- 家庭专属（**建议值**）：老人与孩子的脸是漂移重灾区，必须单独建资产、单独挂图；一张全家福不能替代单人参考图（会串脸）；优先级为 角色三视图 > 场景定妆 > 叙事道具图（报告 07：叙事道具 ≤8 件）。

### 3.3 易崩点与规避
- 年龄漂移：同一角色在不同镜里忽老忽少——用 fully_preserved 锁脸（报告 05 保留级别枚举），并在每镜显式重复年龄与身份锚点。
- 接触类动作（搀扶、喂饭、拥抱）手部与肢体易粘连变形——拆成两镜：接触前一拍 + 接触后一拍，中间不拍接触瞬间。
- 群戏人数漂移——报告 03 同框 ≤3 人，超了拆解；报告 04a 群演只用微动作（遮、瞥、垂、攥）服务当前戏核情绪，不抢主角戏、不单独配台词。
- 声音只写环境音与动作音（报告 04a 音效禁配乐），配乐交给配乐层，情绪节奏靠画面和音效传达。
- 报告 03：道具设定图纯白底、**无手**（拿着道具的手是最常见污染）、必带尺度短语；禁字幕、水印、logo、六指（报告 05 绝对禁止项）。
