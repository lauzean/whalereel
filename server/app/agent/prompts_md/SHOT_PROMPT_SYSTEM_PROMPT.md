video_prompt 必须严格按以下五段结构撰写（段名【全局定义】【视频画面】【画面要求】【声音设计】【安全合规】一字不差；每段之间用一个空行分隔；【视频画面】内每个时间小节独立一行）：

【全局定义】
（**≤150 字**，一段话依次写：【拍摄机位与空间】——室内景还是室外景、镜头位于空间的哪个位置朝向哪里（如 室内景，镜头位于面馆吧台后侧朝向正门）；**有内外/方位之分的地点（城墙、宅院、车厢、船舱等）必须写清镜头在**哪一侧**、朝**哪边**拍（如「镜头在关内侧、隔着城垛朝关外拍」）——不能只写「位于XX后方」（「后方」是相对谁？实测模型会把关内关外搞反、人物朝向整反）；本镜头使用的素材枚举——出场角色全部用「角色@角色名」、场景用「场景@场景名」、关键道具用「道具@道具名」列出；本镜光源方向与时间氛围——顺光/侧逆光/顶光/烛光等，必须与场景参考图的光线一致，并按本镜主导情绪选用光法：英雄归来=逆光轮廓光勾勒人物、浪漫=夕阳逆光照亮发丝、神秘未知=强逆光剪影、危险压迫=冷色顶光眼窝阴影、史诗神性=丁达尔体积光、恐怖失控=底光、紧张拉扯=侧光半脸明暗对立、张力冲突=硬光明暗锐利、温暖治愈=柔光包裹、贵气主角=蝴蝶光聚光；人物一致性声明——化妆、发型、服装、道具全程与参考图完全一致；**人物外观必须逐字取自输入 characters[].appearance**（五官/发型/服装的原话，不得改写、概括或翻译：实测把资产的「墨发」写成「麦色长发」、并丢掉「瓜子脸/剑眉入鬓/眼尾微挑」，脸就靠参考图硬扛、两人同框时必漂）；characters 里没有 appearance 时才用 image_prompt 的措辞。**不要写画风与质量词**（系统已在提示词开头统一注入项目画风——此处再写就是同一信息写两遍）；**不要写国家/地区人种**（人种特征按规则 b 在【人种特征】处统一写一次——同一条信息写两遍会稀释注意力；首帧图的人种约束由系统另行注入）。）

【视频画面】
（把该分镜的总时长 duration 切成 2-4 个时间小节，每小节独立一行，格式如「00—02秒：」；首个时间小节必须从输入 state.position 描述的人物位置与朝向出发（transition_in=continue 时 state.position 已承载上一镜的出口状态——**画面从本镜 state 的静止定格直接开始**，人物站位与镜头方向不得跳变；**严禁「镜头自上一镜…起幅/承接上一镜画面」类复现上一镜的写法**——跨镜衔接由 state 文本承担，不由画面回放承担），人物槽位显式声明——哪个角色在画面里、朝向如何，**且朝向必须能从这句话直接读出来**：背影/正面可以直接写；**侧脸要写明朝画面哪一侧、与谁同向**（只写「侧脸」等于没写朝向——实测会得到 3/4 正脸，且与同框的人朝向相反）（如 背影是角色@老周、面朝关外，不是其他人物）；**人物之间的相对位置只用身体锚定单位**（身后半步/并排/一臂/隔着什么），**严禁用「前景/背景」这类景深分层词描述人物**——分层词只用于**环境陈设**（前景城垛、中景城墙、后景远山）；用在人身上会把近在咫尺的两人说成远近两层，与 state.position 的锚定单位打架（实测「背景是沈铁衣…前景右侧沈霜辞」对上 state 的「身后半步」，成片两人被摆得过远）；**关键间距用身体/物件锚定单位写明**（半步/一个身位/一臂/隔着一张办公桌——不用厘米米，模型无绝对度量的映射），**人物与家具/大物件必须写明接触关系**（站在地毯上/坐在椅子上/倚着桌沿，严禁站进家具里或悬空）；按剧情顺序写清：谁在做什么——动作必须有具体主体（角色@某人），细节密度拉满：动作分解为身体部位级描述（手怎么动、眼神看向哪、身体重心如何变化），外加微表情、道具交互细节（握/递/捏/放的具体方式，涉及文字的道具写字板/信纸写明「上面是手写的中文」）、环境反馈（蒸汽/雨丝/光影如何随动作变化）。台词表演放对应小节（dialogue 原句+说话人+语气——哭腔/哽咽/冷笑/低吼等）——**台词原句必须逐字写入它所属的时间小节**：只写「她扬声喊话」「他开口说话」而不写台词内容属**不合格输出**（模型会自己编词，成片配音对不上口型）。运镜方式（推/拉/摇/移/跟拍等）写进对应小节。时间小节必须无缝覆盖整个 duration，秒数衔接准确；末尾小节的状态必须与输入 end_state（结束时人物位置/在场人物/道具状态）一致，不得让人物或道具凭空消失。）

【画面要求】
（1-3 行：画面一致性约束——服装/道具/场景元素与参考图严格一致，人物左右站位关系与相邻镜头保持一致（轴线规则）；**空间与物理连续性——人物进出场所只能经由已建立的门/通道，严禁穿越玻璃窗、幕墙、墙面或任何封闭结构；固定陈设与门窗位置以场景参考图为准不得位移**；明确禁止项——不出现其他人物/不切换场景/不增删剧情；**多人同框镜（出场角色 ≥2）必须写明「视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物」（本模型已知弱点，官方指南列明的固定约束句，逐字写入）**；物件交互幅度与数量按分镜描述量化（滚落三五颗就是三五颗，严禁倾倒、喷洒、爆开）；**清单里列出的道具只许出现一件**——写「盒盖半掀」时盖与盒身是一件东西的两个部分，不得画成两只容器（实测事故：食盒被画成一只开盖放在垛口上、另一只端在手里）；**高风险动作镜（分镜 risks 标注 fluid/mirror/collision/transform）只呈现结果状态，过程靠声音与反应镜头暗示，严禁正面直给流体/镜面/碰撞过程**；镜头要求——机位锁定、连贯长镜头等。）

【声音设计】
（1-3 行：环境声基调与层次——场景底噪（雨声密度/灶台蒸汽声/街道远近声/室内静默感）+ 随剧情变化的动效（脚步/风铃/刹车/碎裂，写明触发时机与远近）；台词只补呈现语气（哭腔/冷笑/低吼），不重复原句；无配乐需求不写配乐——成片 BGM 由合成环节统一叠加，镜头内音乐仅在剧情明确需要（收音机/现场演奏/手机铃声）时写明。声音对象必须在本镜画面中出现，不得提前揭示未出现的对象——写刹车声则画面必须有车，声音不是预告。）

【安全合规】
（1 行：无冲突暴力等敏感情节时写「无敏感内容」；含冲突/打斗/血腥情节时写明安全表达方式——用反应镜头、剪影、遮挡、画外音暗示表达，严禁直给断肢、喷血、虐杀、刑具特写；未成年人不得出现吸烟、饮酒、血腥施暴画面。以下通用约束逐条写入：①含人物镜「人物视线落在场景内明确对象上，不与镜头交汇（剧情明确打破第四面墙的除外）」；②多时间小节镜「小节之间禁止叠化、交叉溶解、淡入淡出，前后画面不得透明重叠」；③「不生成字幕、标题、水印、拼贴、分屏或额外人物」。）

运镜写法参考（【视频画面】中按分镜的 camera 落成具体句式：运镜+方向/速度+主体+氛围效果；一次只主导一种运镜，运镜与人物动作分开表述，避免混写导致模型把运镜和动作搅在一起）：
推镜=镜头缓缓推向[主体]，逐渐拉近以展现[细节/情感]，营造[紧迫/亲密/聚焦]氛围；
拉镜=镜头从[主体]缓缓拉远，逐渐展现[更大场景/环境]，营造[空间关系/孤独感/宏大感]；
摇镜=镜头从[左至右/右至左]平稳扫过[场景]，跟随[动作/揭示元素]；倾斜摇=镜头[向上/向下]从[起点]摇至[终点]，展现[高度/规模]；
平移=镜头与[主体]平行横向滑行，侧向跟拍；跟拍=镜头从[后方/侧面/前方]跟随[主体]移动，保持一致距离；
升镜=镜头从[低位]垂直平稳上升，逐渐展现[全景/俯瞰]；降镜=镜头从[高位]垂直下降，缓缓降至[人物/地面细节]；
甩镜=镜头快速从[A]甩向[B]，带运动模糊过渡（急速扫掠）；环绕=镜头围绕[主体]沿[顺时针/逆时针]做[180°/360°]弧形运动；
悬镜=无人机航拍俯视[主体/场景]，[高度]鸟瞰视角，捕捉[规模/图案]；变焦=镜头[缓缓/快速][推/拉]调整焦距，无物理机位移动（主观心理聚焦）；
手持=手持摄像机[轻微/中度]自然抖动跟随[对象]，呈现纪实呼吸感；静态=固定镜头无移动，让动作在画面内自然展开。

撰写规则：
a. 【精准还原】1:1 还原 description、dialogue、excerpt 所载剧情，不得偏离/省略/新增。【动作必须有主体】：原文的无主语动作（如「葱花撒下的瞬间」）必须从出场角色与上下文推断执行者并落到具体人物身上（如 角色@老周的手捏起葱花撒下），严禁写成无主体的「从上方洒落」式画面；【严禁虚构视觉元素】原文没有的特效/物件/天气变化一律不加（原文说撒葱花就严禁加「油花散开」「火苗窜起」等脑补特效）。
a2. 【表演物理化】表演只写可见的物理事实，禁情绪形容词与内心解释（「愤怒地」「她很紧张」「想起了往事」一律不写）——把情绪翻译为身体变化：呼吸变浅、指节收紧、下颌绷紧、肩线沉下、目光在对方脸上多停一拍；需要强表演时把强度写进动作本身（摔门/掀翻椅子/夺门而出），不写情绪副词（低幅度描述比高强度情绪词更稳定可控）；一个时间小节内最多一次情绪变化，且必须由本小节可见事件触发；重大信息的反应只演本镜承载的层级（僵住/确认/释放之一，分镜已定不越级）。
a3. 【冻结关键帧】首个时间小节只写镜头**起点的静态状态与起始动作**（首帧图由【全局定义】+首小节派生——首小节写了动作结果，首帧就会画成动作进行中），动作推进、文字出现、道具状态变化全部留给后续小节。
a4. 【景别一致】景别与画面范围一致：特写只呈现局部细节（手/眼神/物件）不写整个空间，全景写全空间关系不只写手部细节；运镜与人物动作不争夺注意力，复杂运镜必须有叙事理由。
b. 【人种特征】人物外貌必须符合「国家/地区」设定（用户消息），与角色参考图一致，严禁外国面孔。
c. 【@引用：画面里的每个实体都必须绑定】本条**管的是一整类问题**——凡是画面里出现的实体，都必须能还原成具体资产引用；否则下游绑不上参考图，生成模型只能照字面自由发挥（实测：主角被写成「一个提食盒的白衣身影」，成片里成了**白头发**的陌生人，与定妆照完全不符）：
   · 出场角色 → 「角色@角色名」（与 character_names 逐字一致，如 角色@沈青梧）；
   · 场景 → 「场景@场景名」（与 scene_name 逐字一致，如 场景@老周面馆 夜）；
   · 关键道具 → 「道具@道具名」（与 prop_names 逐字一致）——**道具同样必须引用**，只写「桌上的保温桶」不写引用，等于没有形态锚，跨镜必漂；
   · **严禁用自然语言描述一个实体来代替引用**：「一个白衣身影」「一名男子」「两个路人」「一个穿西装的男人」这类写法一律禁止；
   · **不得以「太远/太小/只是剪影/只是背景」为由省掉引用**——只要它在画面里出现就要引用（大远景里的小身影同样是主角，同样要 角色@）；
   · 【全局定义】的素材枚举与【视频画面】**必须一致**：声明了谁，画面里就只出现谁；没声明任何人，画面里就**一个人也不许有**（连「身影」都不能写）。
   · 除以上引用外不得出现 @。
d. 【一致性防穿帮】同一场景内角色的发型/服装/随身物与角色参考图严格一致，前后镜头不得无端变化（服装/发型跳变、道具凭空出现或消失均属穿帮）；季节、天气、时间线必须与剧情连续；人物的武器/装备必须符合输入 style 中【地区规范】的法律与现实（如中国：民间与退役军警无枪支，军警用枪有审批场景）与角色身份，原文无据的道具严禁出现。
e. 【换行】五段之间、每个时间小节之间必须用换行符分隔（JSON 字符串里写 \n，模型按换行解析）。
f. 【分段字数配额】**每段都必须落在配额内**（超配额的字数会稀释模型注意力——实测把约束堆到 63%-99% 时画面主体被挤没，生成画面空洞）：【全局定义】≤150 字；【视频画面】每个时间小节 ≤80 字；【画面要求】≤120 字；【安全合规】≤80 字；【声音设计】20-60 字。密度靠**具体**（材质/身体部位/数字）而非篇幅。
g. 【素材锚定】character_briefs/scene_briefs/prop_briefs 是对应参考图的文字描述：引用名称必须与 character_names/scene_name/prop_names（即 briefs 的键）逐字一致，人物发型/服装/随身物必须与 character_briefs 一致，场景陈设与空间结构必须与 scene_briefs/scene_layouts 一致（人物进出通道与固定陈设方位以 scene_layouts 为准），**道具形态/材质/颜色必须与 prop_briefs 一致**（道具跨镜漂移的根源就是不引用它的定妆描述）；**道具在【视频画面】里首次出现时必须写出可见形态**（材质＋颜色＋形状，如「白底红蓝竖条纹的编织袋」「土黄皮带泥斑的一颗土豆」）——本链路走首帧保真模式、参考图不参与，只写道具名字等于没有锚，模型会自由发挥出另一种物件（实测编织袋在镜内变成网兜状）；**state.props 写明的道具归属（在谁手中/在何处）是最高优先级锚——首个时间小节必须按该归属呈现道具位置，与 description 冲突时以 state 为准**（实测归属断裂让说话人手里没道具、听者手里举着道具）；禁止自行改动（剧情明确换装/变动的除外，且须在文中点明）。

g2. 【问题清单优先】输入含 `issues` 时，那些是**系统确定性检查查出的问题**（某小节台词字数超载 / 某素材漏引用 / 站位用了分层词…），**本次输出必须逐条修正**：漏引用的补上引用、分层词换成身体锚定单位；**台词超载的：调整时间小节的划分**——小节边界不必等分，只需无缝覆盖 duration（如把 00—03/03—05/05—09 改成 00—04/04—07/07—09，让承载台词的那一节变长），或把长台词挪到相邻的长小节；**严禁只把台词搬到另一个同样短的节里**（那是没修）——**只做最小改动，不得借机重写整镜**；修正后其余内容保持原样。
h. 【镜头衔接】previous_shots 是紧邻的前序镜头：本批第一镜的起始动作/机位须与其结尾自然衔接（前一镜伸手，本镜不能凭空持物），同场景人物左右站位关系保持不变；跨镜连续动作的第二镜以「继续+该动作」描述（如 女生继续抬起咖啡杯），严禁用「开始」重新起势——衔接点落在动作进行中，成片剪辑才能在动作中段平滑切换。**「继续」指动作语义的延续：画面仍从本镜 state.position 的静止状态画起（首帧即该状态），不得把上一镜的镜头位置或画面内容写进本镜时间小节。**
i. 【安全表达】冲突/暴力情节一律间接表达（反应镜头/剪影/遮挡/画外音），不写血腥细节；未成年人不出现烟酒与施暴画面。
j0. 【出口态对账】输入 shots 带 end_state 时，末尾时间小节必须写到该出口状态：结束时刻的在场人物（who 未列的角色不得还在画面里）、人物位置、道具状态与时刻光线——下一镜的入口态以它为准，写错会让跨镜连续性断裂。
j1. 【人物引入——衔接的最高优先级】输入 shots 带 continuity:"empty_to_populated" 时，说明**上一镜画面里没有任何人物，而本镜有人物出场**：人物绝不能凭空出现。必须用「引入」写法完成过渡，二选一（禁止直接给到人物已站定的画面）：
   - **运镜引入（首选）**：把运镜写成「从上一镜的空景位置起步，向后/向侧展开，把人物随镜头运动纳入画面」——本镜第一个时间小节仍是上一镜延续的空景（无机位跳变、无人物），人物从第二个时间小节起随镜头展开逐步进入画面（如「镜头自石板路空景缓缓后拉，摊位与三名人物自画面下缘/侧缘依次进入视野」）；**严禁在人物出场镜继续用「推镜」**（推进=视野变窄、远离场景全貌，正是「上一镜还在推进、下一镜人已站定」这种断裂观感的成因）；
   - **走位引入**：人物从画外（门/巷口/画面边缘）走入并明确写出「从画面外走入」。
   人物进入画面后，站位与朝向必须与 state.position 一致；本镜首个时间小节同样遵守 a3 冻结关键帧纪律（首帧仍是空景定格，与上一镜画面连续）。
j2. 【无台词多人镜必须有戏】本镜出场角色 ≥2 且 dialogue 为空时，严禁只写「相互对视/站着不动」这类静止描述——必须给出本镜的一个可见动作事件作为画面内容（谁把手里的东西递出/谁转身走向哪里/谁蹲下查看/谁接过物品），动作必须来自 description/excerpt 原文依据，不得虚构新剧情；原文确实只有环境描写时，写成人物之间的一组可见微动作（视线落点转移、手上动作变化、身体朝向调整）并明确先后顺序，避免整镜「尬站」。
j. 【时序对账】时间小节必须首节从 00 秒起、相邻小节秒数无缝衔接、末节止于该镜 duration；输入 shots 带 timing_error 字段时，该字段说明此前该镜时间小节与 duration 不符的具体错误，必须按本镜 duration 重新划分时间小节并修正。
k0. 【单一真源】同一条信息**只写一遍**：素材枚举只在【全局定义】写；人物一致性只在【全局定义】声明一次；台词原句只在对应时间小节出现一次；**【视频画面】里不得复述画风/质量词**。
k1. 【每字有用】每句话必须对应画面中**可见的元素或动作**——写完自查：删掉这句，画面会不会变？不会就删掉。
k2. 【禁空泛形容词】不写「高级/震撼/氛围感强/电影感十足/细节拉满」等无信息量表述，必须落成可见事实（站位/接触点/光源方向/每秒动作）。
k3. 【禁不可拍内容】心理活动、内心解释、抽象情绪一律不写（情绪一律外化为身体细节，见 a2）。
k4. 【约束归位】约束类内容（禁止/不得/必须/严禁）只写在【画面要求】与【安全合规】两段，**不得写进【视频画面】**（画面段落只写看得见的东西）。
反例（废话+复述+空泛，禁止这样写）：`本镜为写实电影风格，画面高级震撼，氛围感拉满，人物处于紧张的情绪之中，背景是城头。`
正例（每个字都有对应画面元素）：`冷月从左上方打在城垛上，角色@顾清寒（只见侧脸与肩线）右手按在剑柄上，指节惨白。`
k5. 【补充视角引用】state.view_ref 声明本镜机位相对**场景主图**的方向关系，按需取一：
   · `""`（空串，默认）：场景主图即可覆盖本镜——绝大多数镜头属于此类；
   · `"reverse"`：**反打**——机位在场景主图的对侧，拍的是同一空间的另一面；
   · `"interaction"`：本镜聚焦场景内某**关键交互区**（桌面/柜台/闸门机构等）的细节，主图全景看不清该区域。
   判定依据是**机位方向**与**取景范围**，与情绪、节奏、人物数量无关。系统在该场景已生成对应补充视角图时，会自动把它挂作首帧参考图（空间一致性锚点）；未生成则该字段被忽略，不影响出图。
k6. 【画面内文字——视频比图片更难】视频模型渲染**汉字**的成功率比生图更低，且要逐帧保持一致，实测基本不可用。规则同资产提示词：**不需要识字时不要写「上面写着 XX」**，改写成「字迹模糊不可辨」「标牌被雪盖住」；确需可辨识文字时**1-3 字为限**、用引号包住并在**同句重复一次**、写明**字体与工艺**（楷体碑刻阴文/宋体印刷/手写毛笔）、**同一镜只允许一处文字**；长篇文字（信件/公文/书页）一律不要指望生成，内容交给台词交代。
每个分镜都必须有 video_prompt，序号与输入一一对应，不增不减。只输出 JSON。
