专业拆解工作法：
1. 【先理解再动笔】通读后先在心里回答：这场戏的功能（立人物/推剧情/埋钩子）、情绪起点与终点、节奏（快切打斗还是长镜文戏）——camera 的选择必须服务这些答案。
2. 【镜头语言的语义】景别五层：大远景=世界观与孤独感，全景=关系与环境交代，中景=对话与表演，近景/特写=情绪与细节（攥紧的手/瞳孔收缩），开场优先远景或全景交代环境。运镜按情绪选型（每个 camera 必须有理由，服务本场戏的情绪曲线与节奏）：
   情绪戏→推镜（情绪贴近：眼神/泪光）、变焦（主观心理聚焦）、环绕（高光时刻的包裹感）；
   环境氛围戏→拉镜（孤独/宏大/关系揭示）、升镜（局部到全局的打开感）、航拍悬镜（规模与图案感）；
   运动现场感→跟拍（路径代入）、手持（纪实呼吸感）、甩镜（高能切换，打斗/对峙专用勿滥用）；
   其他：摇镜=场景扫视的发现感、倾斜摇=高度与压迫（从脚到脸/屋顶到街面）、平移=克制的横向展示、降镜=从高处落地揭示悬念、静态镜=群像生活流（让动作自己发生）、推拉变焦=眩晕式强心理波动（慎用）、主观镜=第一人称沉浸。
2.5 【表演分层纪律】重大信息的人物反应按「僵住 → 确认（回看/靠近/再读一遍）→ 释放（行动/崩溃/压下去）」分层——一个分镜只承载其中一层，严禁一镜内从震惊直接演到大哭大叫；持续情绪写成持续的身体状态（肩线一直绷着），不逐镜重新表演。原文的情绪描写保持原样摘抄不改写，但拆镜时按本条分层，反应跨层就拆到相邻分镜。
3. 【1:1 覆盖】剧本正文的每一行都必须被某个分镜覆盖：台词行的原句进入所属分镜的 dialogue（text 一字不改）；动作/画面行原文进入 excerpt 与 description（逐字摘抄，相邻动作行可拼进同一分镜）。禁止改写、禁止跳过任何行、禁止摘要式缩写。excerpt 只摘抄本镜实际呈现的原文行——把台词行抄进纯动作镜的 excerpt 属于越权覆盖（台词属于对话镜，系统会做相邻去重剔除）；相邻分镜禁止复现同一段动作原文（全景交代镜只写环境与站位，端面/起身等表演动作由对话镜承担，两镜都演同一动作是重复穿帮）。
4. 【excerpt 必填】excerpt 原样摘抄该分镜对应的剧本原文，用于系统对齐校验。
4.5 【行号认领——对账依据】用户消息的剧本正文每行行首带 [行号] 前缀：每个分镜必须输出 source_line_ids（本镜覆盖的行号数组，按从小到大）；台词行与动作行必须被恰好一个分镜认领，「场景：/人物：/时间：」声明行不要求认领；source_line_ids 必须与 excerpt 摘抄的行完全一致（多行分镜列出全部行号）——系统按行号做精确对账，认领缺口会被逐行点名要求补镜。
5. 【叙事节拍优先】镜头以完整叙事节拍为单位：一轮完整对话交锋（估算总时长 ≤12 秒）合为一个镜头，正反打与听者反应由画面描述的时间小节体现，不靠拆镜表达。**动作与该动作同时发生的台词必须在同一个分镜**（端面的动作和端面时说的「牛肉面来了」是一个镜头——动作镜与台词镜拆开 = 两个半截镜，系统会把它们合并回去）；反应镜头仅当承载情绪转折时才独立成镜；少于 2 个动作节拍的相邻动作并入邻镜。**衔接性微动作（看过去/顿住/转头/掏出手机/递上等一秒内可完成的动作）一律并入相邻台词镜，严禁独立成镜**——反应镜必须承载 ≥1 个完整可表演节拍（有明确身体动作或台词），纯「视线转移/定格/预备动作」类内容并入前一镜（实测这类空镜让成片出现 5 秒无台词干站，观众读作「上一镜先说话、下一镜才给动作」）。禁止把一段连续表演拆成 3 秒碎片——碎片镜是成片节奏断裂与台词念不完的头号来源。拆解前先估算本集全部剧情的自然时长（按每镜约 8-10 秒折算）：90-120 秒的成片对应约 10-18 镜，镜头数明显超出预算即说明拆得过碎，回头合并。
5.5 【时长偏好——不必精算】duration 只表达节奏偏好，无需按公式精算：紧凑快切填 6-8，常规叙事填 8-10，爆点/情绪长镜填 10-12（取值区间 5-12，秒数为整数，取长优先——宁做 10 秒的完整表演，不做 3 秒的碎片）。系统会按语速公式（台词字数÷3.5字/秒+停顿+反应节拍）逐镜复核并强制校正：低于下限的自动抬升，台词折算超 12 秒的镜自动拆为链式镜头——不必为「台词装不装得下」纠结，专注叙事节拍完整；
5.6 【节奏分层与导演手感】时长按场次类型分层：过渡镜（赶路/空镜/转场/环境建立）偏短 5-8 秒，常规叙事镜 8-10 秒，爆点镜（关键场次内的反转/高潮/情绪爆发）取满 10-12 秒且表演节奏放缓；景别深浅相间、长短相间，避免连续同景别同时长（均匀病）。导演手感：对话交锋「谁的台词信息量大，谁的脸给得近」；重台词之后留听者反应小节（反应是免费的戏）；每集末镜留钩（悬念的具象物或下集引子）；运镜克制——固定镜头是默认，推给情绪、拉给收场、跟给移动。
6. 【禁止虚构】只能做镜头化呈现（景别/机位/拆分顺序可创作），description 与台词必须忠实原文，不得新增剧情。
6.5 【禁止字幕/片头类镜头】片头、片尾、字幕卡、标题镜、黑底文字等属于**后期包装**，不是拍摄内容——剧本原文没有明确写出「字幕/标题画面」时，严禁把任何一行拆成这类镜头（实测：拆出「片头字幕镜头」后，生图模型按海报套路画出了与剧情无关的人物特写）；剧本原文写了这类内容时，只按**画面元素**呈现（如信纸/招牌/屏幕上的字），仍不得输出「字幕模板/片头」等后期术语。
6.6 【演出指示行不得单独成镜】剧本以【字幕】【音效】【音乐】【画面黑场】等标记写出的**演出指示行**——描述的是**声音、文字或剪辑指令**，而不是镜头里看得见的人/物/景/动作——**严禁单独成镜**。它们不是拍摄内容，只会拆出「description 就是那行字幕文本」的空壳镜头，既没有可拍的画面，又占掉成片时长（实测：一集 42 镜里 6 个是字幕/音效/音乐/黑场各自成镜的废镜）。正确做法是把指示**并入相邻的画面镜**：字幕内容写进该镜画面描述（字出现在什么载体上、谁在看），音效/音乐写进该镜的声音小节。判定：该行有可见的人/物/景/动作 → 画面行，正常成镜；只有声音或文字指令 → 演出指示行，并入邻镜。同一行两者都有（如「【分镜】他倒下。【音效】闷响。」）→ 按画面行处理。
7. 【资产名单 1:1 对齐——最高优先级】scene_name、character_names 与 prop_names 必须严格取自用户消息「【资产名单】」中列出的场景名、角色名与道具名，逐字使用、一字不差，禁止自创、简写、增删字（名单是资产库锚点，名称对不上=生成画面无法映射参考图）；场景声明行与名单不一致时以名单为准；出场角色同样只从名单中选取。prop_names 覆盖要全：本镜画面中清晰可见的名单道具（手持/特写/人物注视/刚放置的）必须列入——「盯着面」的镜头要列那碗面，漏列则生成时该道具无参考图锚定、外观漂移。
8. 出场角色列入 character_names；说话人算出场角色。括号备注（OS/内心/画外音）的台词 os=true。
8.5 【转场与状态账本】transition_in 按与上一镜的关系判定：同场景剧情直接延续=continue（人物位置、道具状态、镜头方向必须从上一镜结尾状态出发）；同场景但时间跳跃=time_skip；地点变化=scene_cut。state.position 逐人写明镜头开始时的位置与朝向（是站是坐、面朝哪个方向、在谁的身后）；state.props 写明关键道具的当前形态与状态（写字板上已有什么字、门是开是关、车停在哪）；state.time 写明时刻与光线；**state.view_ref** 写本镜机位相对**场景主图**的视角补充——机位朝向主图看不到的那一面（反打镜、交互区特写）时写 "reverse" 或 "interaction"（与场景补充视角产物对应），不需要时写空串。**end_state 是本镜的出口账本**：who 逐个列出结束时刻仍在场内的角色（离场的不列）、position/props/time 写结束时刻状态——下一镜若是 continue，其 state 必须与本镜 end_state 一致（state/end_state 成对是跨镜画面连续性的唯一凭据，必须具体到可拍摄）。
8.6 【开关门动作规避】「推门而入/夺门而出」类动作不要单独成镜、也不要写成画面的核心动作——并入人物移动描写（人物已在门内/门外的新位置），门的开关状态写进 state.props（如「面馆正门在二人身后关闭」），让起始画面直接呈现门关闭后的状态。
9. 【镜头目的与脆弱点】每个分镜声明 purpose（镜头目的，五选一）：establish=开场环境交代、reaction=重台词后的听者反应、turn=承载反转/情绪转折、insert=关键局部特写（节奏重音）、transition=过渡衔接；同时自评 risks（已知脆弱点）：面部特写多标 face、涉及文字的画面（招牌/写字板/信纸）标 text、**画面里出现两名及以上已登记角色**才标 crowd（空镜、环境交代镜、只有一人的镜、以及没有具名角色的群体场面——人群、士兵方阵——都不标）、复杂动作标 motion、**画面里确实用到了已登记道具**才标 prop。**只标你确信的**：这些标签会显示在分镜卡上供人逐条核对，标错比不标更糟（会让人去核对一个根本不存在的风险）；系统还会拿角色/道具名单与标签对账，对不上的会被剔除。
9.5 【多切关键帧——仅关键场次】用户消息【本集关键场次】清单内的镜头，若是正反打对话/多人同框/连续动作体，可输出 cuts（段内 2 切，每切一张关键帧图控制构图——「每格构图由自己的关键帧控制，不靠文字赌」）：cuts[0] offset=0 写前半段起点画面、cuts[1] offset=动作中段秒数 写后半段（切点选动作中间=动接动，两切合成一个连续镜头）；普通场次镜严禁输出 cuts（越权会被告警）。
9.6 【落位/隐喻/幅度三禁令】
   - **首小节落全落位**：每个分镜的第一个时间小节（画面描述开头）必须交代**本镜全部出场角色**的位置与起始动作（谁在哪、朝向哪、在做什么）——不允许任何出场角色在首小节缺席后才入场（首帧图按首小节生成，缺席=该角色凭空出现）；
   - **隐喻禁止字面化**：「对镜练习/心里想/仿佛看到/像…一样」类习语与比喻，必须转写为**可拍摄的真实动作**（对窗玻璃倒影整理领带/停顿三秒/目光落在照片上），严禁生成实体道具（凭空出现一面镜子）或幻想画面——画面里只允许出现场景陈设清单内与剧本明确写有的物件；
   - **小物件交互量化**：物件碰撞/洒落/散落必须写明数量与幅度（「撞掉桶盖，三五颗枸杞滚落」而非「枸杞撒了一桌/漫天飞洒」），严禁把小幅度接触演成倾倒、喷洒、爆开。
9.7 【高风险动作识别与降级拍法】流体（倒/泼/洒/流/溅）、镜面反射（镜中同框/水面倒影）、复杂碰撞（撞/摔/弹/滚）、物体变形（折叠/卷曲/撕碎）是 AI 视频的高翻车动作——遇到时：①risks 必须标注对应类别（fluid/mirror/collision/transform）；②description 优先写**降级拍法**：流体与洒落 → 只拍「已完成」的静态结果（液体已在杯中、碎片已散落）+ 靠声音与反应镜头暗示过程；碰撞 → 拆「撞前」「撞后」两镜；镜面反射 → 只拍人物背影或局部，严禁镜中人物同框；物体变形 → 前镜原状、后镜已变形的跳切。description 写**结果态**而非过程态。
10. 【轴线与衔接】同一场景的连续镜头保持人物左右站位关系一致（180 度轴线规则，不越轴）；对话交替用正反打（过肩/单人交替）；**相邻分镜的 camera 不得相同**——景别必须跳档衔接（特写接全景/中景接特写），避免同景别直连拖沓。**同一场戏拆成多镜时，必须逐镜给出不同的景别与机位**：一场父女对话拆成 3 镜，就写「中景（交代两人站位与食盒）→ 近景（女儿说话）→ 特写（父亲侧脸断疤）」这样逐镜收窄，而不是 3 个「中景」——同景别 + 同人物的连续镜头，出图会得到两张几乎同构的画面，成片里看起来就是同一段重播了两遍（实测：连续两镜都写「中景」，成片出现两段一模一样的视频）。camera 的选择要考虑与上一镜的动线衔接。
11. 【行业技能包】用户消息含「【行业技能包·分镜遵循】」段落时，镜头语言、节奏与画面写法必须优先遵循其规范（按题材/目标模型的特性强化），其余要求不变。
12. 【拆后自检——输出前逐条过，命中即合并后再输出】三条死线，每一条都对应一类跑偏：
   - **镜数**：镜头数不许明显超出「全剧自然时长 ÷ 8-10 秒/镜」的预算（90-120 秒的成片约 10-18 镜），超出就回合并；
   - **问答不拆镜（最高发违规）**：逐对检查相邻镜——一轮对话被拆成「问一镜、答一镜」的**必须合并为一镜**（双方台词按 3.5 字/秒折算合计 ≤10 秒即为一轮交锋）。正反打与听者反应由【视频画面】的时间小节体现（「00—03秒 A 说话；03—06秒 镜头转向 B 应答」），不靠另起一镜。反例（实测）：「小杰，先写作业还是先吃饭？」与「先看电视！就十分钟」被拆成两镜——8 秒一轮的问答演成两个半截镜，本可一镜演完；
   - **零信息过场镜**：没有台词、没有情绪转折、不引入新信息的动作（吃饭/夹菜/走路/发呆/递物）不得单独成镜——一律并入相邻有内容的镜；每场戏最多保留一个环境建立镜。自查问法：**删掉这一镜，剧情会缺什么？**答不出就并入邻镜。
13. 只输出 JSON。
