## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
- 观众要的不是「打脸」，是**尊严与翻身**：主角受的是「穷」和「被看轻」，回报是「当众被认可」。爽点落点是让事实当众成立，不是把人踩下去。
- 报告 04a 心理级爽点三选一：本题材锁**归属**（家族/宗族荣誉）与**秩序**（凭本事讨回公道）。
- 报告 04a 矛盾四级阶梯：爆款骨架须达 3–4 级，**两个好人因不同选择走向不同命运**最立得住（父亲要卖牛供弟读书，儿子要留牛保全家口粮）。

### 1.2 单集结构公式
- 报告 04a 黄金单集公式：**本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连**。落地：上集留下的家事农事 → 本集一个卡住的关口（交不上、卖不掉、批不下来）→ 主角用手艺或一件物件破局 → 集尾把家族脸面押上下一个关口。
- 报告 03 冷开场硬门：钩子不是标签，是第一拍，hookBeat 必须落在全集前 3 拍内。乡土戏第一拍给**物**不给景：一筐烂柿子、一张退婚帖、一张欠条。

### 1.3 情绪配比（数字）
- 报告 04a 相邻档原文：家庭伦理类 = 共情 40% + 委屈 30% + 和解 30%；并附禁忌——基调一旦确定不要中途大幅更改。
- 年代乡土配比（**报告未给出，建议值**）：尊严与隐忍 40% + 翻身小高潮 30% + 家族温情 20% + 时代阵痛 10%。
- 落到画面：隐忍那 40% 全写成「忍住的动作」——话到嘴边先咽、端起的碗放下、攥紧的衣角又松开；翻身那 30% 必须**当众**发生（开秤、过数、当众人尝第一口）。

### 1.4 节奏曲线（数字）
- 报告 04a 节奏 3-15-45：3 秒一个信息点、15 秒一个小冲突、45 秒一个转折，结尾用反转钩子卡死。
- 报告 04a 钩子黄金布局：开头 3 秒抛最强钩子；中段每约 30 秒埋一个小钩子；集尾定格在最高冲突那一刻，永不圆满收尾。
- 报告 04a 拉扯：约每分钟一次晃弹簧，每三分钟完成一次完整「压—弹」；只一压一弹仅算及格，须来回晃 ≥3 次。
- 报告 04a 开篇：2 秒防划走、5 秒勾住，前 10 秒交代主角是谁、遇到什么危机、核心冲突是什么。
- 报告 07 确定性折算：台词 4.5 字/秒、动作 2.5 秒/拍，每集时长达标线 ±15%；单集正文 ≤1000 字、语速 150 字/分钟。

### 1.5 爽点配方
- 报告 04a 爽点核心公式：**爽点 = 装 + 打脸 + 震惊 + 收获**。
- 乡土改写（**报告未给出乡土版，建议值**）：藏拙（装）→ 当众验货、当众过秤（把打脸翻成**验真**，让事实成立而不是羞辱人）→ 围观乡邻态度反转（震惊；乡邻是见证人不是嘲笑者）→ 拿到订单、工分、族中话语权（收获）。
- 可写画面：当众开秤、当众咬第一口、把欠条撕了、族谱上添一个名字。

### 1.6 反转与钩子模板
- 报告 04a 股价级反转三式：预期误导 / 人设颠覆（**只能用在配角，绝不能动主角核心底色**）/ 动机置换；全剧 ≈3 个，多了审美疲劳。
- 报告 04a 钩子级反转三式（单集 ≤1 个）：道具伏笔反转 / 情绪回弹反转 / 镜头错位反转。
- 关系内部钩子四类：身份颠覆 / 人性撕碎 / 胜负碾压 / 真相反转。
- 乡土钩子落法（**建议值**）：把「信」当钩子载体——录取通知书压在箱底、电报只念半句、退婚帖没退成、分家清单少一行。
- 反模板纪律（报告 02/03）：**不为检查表硬加秘密、反转或人物弧**；若自检让剧本长出输入没有要求的机关，撤掉机关而不是替它找理由。

### 1.7 台词特征
- 报告 04a 台词节制：单句 ≤20 字（竖屏阅读速度），单个角色单次 ≤50 字；台词量按 150 字/分钟 推算；报告 07：按 4.5 字/秒折算时长。
- 乡土质地（**建议值**）：称谓即关系（他爹、二叔、老支书、师傅）；用物计量不用数字（一担、两斗、三斤半）；狠话不说破——「你走吧」比「我恨你」重；每角色配 2–3 个全剧复用口头禅（报告 04a 说话风格）。
- 报告 02：对白必须在争取、回避、试探、逼迫或重新定义关系；报告 04a「展示不要告诉」——能靠一个动作、一个眼神传递的信息坚决不用嘴说。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 报告 03 运镜克制：固定镜头是默认；推给情绪、拉给收场、跟给移动；一段里超过两种运镜就该问自己是不是在炫技。
- 乡土分工（**建议值**）：全景给劳作（人在天地里的比例要大）、中景给议价（两人距离加手上动作）、特写给物（秤星、指节、鞋底泥、灶膛火）。
- 报告 03 进场三件套：运动主体 → 大远景定场 → 关键局部特写；对话切正反打，**谁的台词信息量大，谁的脸给得近**。
- 空镜转场用生活动势：炊烟、鸡过院、雨打瓦檐、集市人流，不硬切。

### 2.2 节奏与单镜复杂度（数字）
- 报告 07/03 三层结构：段 ≤15 秒（报告 05 嵩口实践为每集 4 段 × 15 秒）；分镜 2–5 秒【硬门】；段内 3–5 切。
- 报告 04a：片段累计 ≤15 秒；含台词镜时长 ≥ 台词字数 ÷ 4 字/秒 + 标点停顿（每标点 0.3–0.5 秒）+ 1 秒安全余量；无台词镜 ≤6 秒。
- 报告 04a：单镜台词或 VO >20 字须拆镜，每镜换视角或景别、按语义停顿点切、不平均切；画面描述 15–50 字；一镜超 8 秒是过度合并信号；同段对话拆 >3 镜且无景别切换是过度拆分。
- 报告 03：同框 ≤3 人，超了必须给拆解；报告 07：每景一致性锚点 3–5 个。
- 乡土专属（**建议值**）：劳作镜单镜 ≤3 秒（长劳作镜 AI 必崩），集市人群镜 ≤2 秒快切。

### 2.3 情绪可视化
- 报告 03 锚点标准：锚点要「可画、可认可、可核对」——「补丁船篷」是锚点，「陈旧的氛围」是形容词。
- 报告 05 物件化写法：把年代感与情绪挂到物上，不挂形容词——蓝布棉袄、竹篮、扁担、斗笠、搪瓷缸、帆布挎包、红发卡；用年代里的物，同时省掉服化道解释。
- 报告 07（waoowaoo 方法思想，表达重写）：禁情绪形容词，只写可拍的生理与动作细节。
- 乡土情绪表（**建议值**）：隐忍 = 手指在围裙上反复擦加视线落地面；委屈 = 端起的碗没送到嘴边又放下；尊严 = 把皱了的钱一张张抹平再递出去；爆发 = 手里的活计先停，然后才开口。

### 2.4 常见钩子的镜头落法
- 报告 04a 镜头错位反转：给观众 100% 真实的局部镜头误导 → 集尾卡住 → 下集全景揭晓（特写红纸包塞进口袋，全景=那是凑的学费）。
- 报告 03：段的最后一切留钩，要么是悬念的具象（口袋、铜扣、灯），要么是下一段的引子；**反应镜头是免费的戏**——重台词后切听者脸 2–3 秒，不用写词；**动接动**——切点选在动作中间而不是动作完成后。
- 集尾钩子落法（**建议值**）：信纸、电报、欠条只给半张的手持特写，配收信人的呼吸声，不给他读完。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表
- 报告 03：动作节拍只写 AI 见过千万次的常见动作（挑担上船、搭手卸担）；精巧动作（伸篙一挡、睫毛颤）生成必崩。
- 可拍（**建议值**）：挑担、推车、蹲下起身、递物、抹汗、掀帘、跨门槛、端起碗、回身点头。
- 高风险：手写字（文字崩）、剥玉米摘菜等细密手指活、多人协作搬重物、奔跑追逐。
- 替代拍法：写字 → 背影加手部停留一拍加纸面空白特写；剥菜 → 只给手部轮廓加菜叶落下。

### 3.2 参考图策略
- 报告 05：角色三视图定妆（正面/侧面/背面）跨集复用；场景实景垫图；每角色固定音色文件；报告 07：一致性 > 美观。
- 报告 05 六段式 subject_definitions 逐张声明参考图职责（Picture 1 定义环境、Picture 2 定义角色），不声明就会张冠李戴；首帧锁写「at 0.00 seconds, Picture 1 is fully referenced」。
- 报告 05 保留级别枚举：fully_preserved / partially_preserved / attribute_transfer / weak_reference，人物脸部与建筑结构用 fully_preserved。
- 优先级（**建议值**）：角色三视图 > 场景定妆 > 关键道具图；报告 03：环境与角色是两层资产，参考图里混进人，一致性全毁。

### 3.3 易崩点与规避
- **时代自洽是红线**：报告 05 的绝对禁止项含 no modern objects / no era-anachronism（禁现代物件、禁时代穿越）。服化道、支付、通讯、交通、文字必须落在剧设年代内（以下为落地写法，**建议值**）：
  - 支付：不用手机、二维码、现代面额；交易 = 现钞、票证、记账、以物易物。
  - 通讯：不出现手机与即时通讯；远距离靠书信、电报、大队广播、捎话。
  - 交通：自行车、拖拉机、班车、摆渡船。
  - 器物：秤、算盘、粮票、搪瓷缸、煤油灯、缝纫机、扁担、竹篮；禁一次性塑料与现代印刷包装。
  - 文字：招牌、对联、标语一律手写体，禁现代印刷字体。
  - **禁止跨年代混用**：同一场戏里的交易媒介与器物必须同属一个年代层（古币式铜钱与近代计量器具同框即穿越）。
  - 以上清单要写进提示词禁止项，否则终审必被「年代穿越」拦下。
- 报告 03：道具设定图纯白底、**无手**（拿着道具的手是最常见污染）、必带尺度短语（AI 常把手持道具画成家具尺寸）。
- 报告 03/05：空景无人；禁字幕、水印、logo、六指；报告 04a：群演只用微动作（遮、瞥、垂、攥）服务当前戏核情绪，不抢主角戏、不单独配台词，人头攒动则后方逐渐失焦。
