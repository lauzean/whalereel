## 一、剧作层（注入：大纲 / 创作 / 拆解）

### 1.1 题材定位与观众期待
观众要的是「现实里的委屈被看见、被补偿」：尊严受损 → 证据出现 → 当众修复。
- 情绪基调共情 40% + 委屈 30% + 和解 30%（报告类型基调表），不中途大改基调。
- 爽点锁一种：秩序（被误解→逐条还原真相）或归属（被家人/团队重新接纳）。
- 全剧留一件看得见的「委屈凭证」（被退回的报销单、被划掉的名字），反转时同一件物品再出现（当初被划掉的名字，如今被当众念出）。

### 1.2 单集结构公式
本集 = 情节承接 + 冲突升级 + 价值币环 + 下集勾连（黄金单集公式）。
- 每场必须改变至少一项：信息/权力/关系/情绪/物理状态/风险，无变化就删或并场。
- 每场至少一个动作节拍（纯对白场是广播剧，AI 没有画面可写）；单集三栏齐全：钩子 + 悬念 + 爽点认领。

### 1.3 情绪配比（数字）
- 共情 40% + 委屈 30% + 和解 30%；最高潮落在 51%–70% 集段，高潮后缓冲一段再推新高潮。
- 单集 = 1 核心情绪 + 1 辅助情绪 + 1 结尾钩子；核心情绪 ≤2 个；配角情绪不能盖过主角。
- 每集正文 500–800 字须覆盖爆点/虐点/爽点至少一个（硬性）；连续 3 集无爆点或连续 3 集同一强度＝严重。

### 1.4 节奏曲线（数字）
- 3-15-45：3 秒一个情绪冲击、15 秒一个剧情变化、45 秒一个强期待（耳光 → 被赶出办公室 → 不显示号码的电话）；强期待里必须留出主角做抉择的时空。
- 开场 3 秒抛最强钩子、2 秒防划走、5 秒勾住人；第 1 集前 10 秒交代主角是谁/什么危机/核心冲突。
- 开头 3 秒最强钩子 + 中段每约 30 秒一个小钩子 + 集尾定格最高冲突；永不解决问题、永不圆满收尾。
- 付费卡点在第 ⌈N×0.10/0.30/0.50/0.70/0.90⌉ 集（±2 集内），必须卡主线上，每卡点 ≥1 个可剪 30 秒投流点；前 3 集要有付费冲动，前 10 集凑 ≈10 个可剪爆点。
- 拉扯：约每分钟晃一次弹簧、每 3 分钟一次完整「压—弹」；只一压一弹仅算及格。

### 1.5 爽点配方（装 → 打脸 → 震惊 → 收获）
- 装：深夜加班的实习生其实是方案作者，被推上台背锅。
- 打脸：客户当众点名「这个方案只有她能讲」。
- 震惊：附和的同事集体沉默、随后改口。
- 收获：工牌从「实习」换成「负责人」。
- 拍法：①羞辱现场全景（主角站会议室最外侧抱资料）②证据特写（投影幕署名、邮件时间戳）③态度反转（同一批脸从嗤笑到僵住，逐个给 2–3 秒反应镜）。

### 1.6 反转与钩子模板
- 股价级反转全剧 ≈3 个（>4 或 0 均为问题），骨架阶段定死，预埋集必须早于揭晓集。
- 三式：预期误导 / 人设颠覆（只用在配角，绝不动主角核心底色）/ 动机置换；不藏信息、画面 100% 真实，空降硬凹＝烂尾。
- 单集钩子级反转 ≤1 个：道具伏笔（小道具颠覆用途）/ 情绪回弹（拉满→踩碎→回弹卡结尾）/ 镜头错位（真局部误导，下集全景揭晓）。
- 集末钩子两套并用、不可全是悬念：关系内部钩子（身份颠覆/人性撕碎/胜负碾压/真相反转）+ 功能型（智识/悬念/情感/世界观）。

### 1.7 台词特征
- 单句 ≤35 字（一口气上限），竖屏更严 ≤20 字、单角色单次 ≤50 字。
- 要展示不要告诉：禁自爆家门式台词；动作 > 台词（一个掰名牌的动作胜过十句「我要杀了你」）。
- 对白必须在争取/回避/试探/逼迫/重新定义关系；每句须推进剧情或塑造人物或制造钩子或激发情绪，否则删。
- 潜台词高效不晦涩（一遍就懂）；谁的话像谁——句式偏好 + 2–3 个口头禅，遮住角色名仍能判断是谁。
- 说人话禁半文半白；称谓走短剧惯例（掌权人称「家主」、警察称「执法局」），禁用「市长」「县长」。

## 二、分镜层（注入：拆解 / 补镜 / 对齐）

### 2.1 景别与运镜语言
- 双人对话正反打：说话人中近景（肩上过），反应镜给听者微表情——情绪在听者脸上；谁的台词信息量大，谁的脸给得近。
- 关系升温用「距离镜头语言」：隔桌全景 → 并肩中景 → 同框特写；关系崩坏反着走（物理距离即心理距离）。
- 情绪爆发前必有压抑镜：攥紧的手、咬紧的侧脸、转身后的闭眼——有压抑才有释放感。
- 运镜语义：手持轻晃＝不安，缓推＝告白前奏，固定长镜＝尴尬或对峙；固定是默认，推给情绪、拉给收场、跟给移动，一段超两种运镜就是炫技。
- 进场三件套：第一切必须有主体运动（静物特写开场是死画面）→ 大远景定场 → 关键局部特写；重台词后切听者脸 2–3 秒，关键动作独立成切（「她一把按住箱盖」单独一格 2 秒特写插入）。

### 2.2 节奏与单镜复杂度（数字）
- 段（一次生成）≤15 秒、不跨场次；段内分镜 2–5 秒（硬门），3 秒一切是短剧的呼吸。
- 文戏取上限 4–5 秒；争吵戏压到 2–3 秒，情绪顶点切对方沉默的特写；单镜同框 ≤3 人，超限必须拆镜。
- 台词装得下：镜头秒数 ≥ 认领台词字数 ÷ 4.5 + 2 秒余量；无台词镜 ≤6 秒。
- 一镜画面描述 15–50 字，超 8 秒或含场景切换＝过度合并；整集时长落在目标 ±15% 内。
- 每集一个心动或心碎瞬间，给足 5 秒安静镜头（环境音抽走只留呼吸）；欲言又止配视线镜：看 → 躲 → 再看。

### 2.3 情绪可视化（可拍细节）
禁情绪形容词，只写能拍到的动作与状态：
- 委屈＝咬下唇 + 鼻翼发红 + 手指把袖口攥出褶；隐忍＝喉结滚动 + 低头整理文件 + 深呼吸后把嘴角拉平。
- 心动＝呼吸变浅 + 拿杯子的手停半秒 + 视线看→躲→再看；心碎＝关门声后肩膀塌下来，维持微笑 3 秒才落泪（先给极致幸福再夺走）。
- 四通道择一或叠加：行动（撕扯、握拳、颤抖的手）/ 语言（痛斥、语塞、泣不成声）/ 环境（阴雨、空街、满桌家常菜）/ 独白（难言之隐用 OS 或 VO）；一百句「她很愤怒」不如一个掀桌子的动作。
- 光照不写光影词，走场景衍生资产（「客厅·傍晚版」）；转场用生活动势（关门、挂电话、电梯门合拢），不硬切。

### 2.4 常见钩子的镜头落法
- 解释被打断：说话人近景说到一半 → 切打断源（手机震动特写/第三人进画）→ 定格在张着嘴的脸。
- 短信只看一半：屏幕特写关键行入画即卡 → 切主角表情；电梯门合拢：门缝对视 → 门合上 → 留最后半帧眼神。
- 情绪回弹：拉满预期的全景 → 踩碎预期的特写 → 回弹动作卡住。
- 镜头错位：给 100% 真实的局部镜头 → 定格 → 下集全景揭晓；段尾留钩用具象物（口袋、工牌、灯、没关的门）。

## 三、模型适配层（注入：首帧 / 画面描述）

### 3.1 动作幅度表（可拍 vs 必崩 + 替代拍法）
可拍：走路停下、坐下、拿起/放下杯子、递文件、握手、推门、回头、看手机、拥抱、擦眼泪、转身离开、按电梯、撑伞。
必崩 → 替代：
- 精巧小动作（睫毛颤、手指微颤）→ 攥拳、手背擦脸、把杯子推远。
- 扇耳光/推搡/打斗 → 拆两镜：抬手定格 → 结果镜（脸偏过去、杯子碎地），不拍全过程。
- 连续动作串（跑上楼+推门+摔包）→ 拆三个 2–5 秒分镜；边走边说话 → 固定在门口说完再走。
- 复杂手部（递接小物件、系扣、拆信）→ 物件特写 + 手入画即止。
依据：只写 AI 见过千万次的常见动作，精巧动作生成必崩。

### 3.2 参考图策略
- 先锚后变：人物三视图（正/侧/全身）＋半身近景；三视图的脸必须与半身像一致、全身比例协调。
- 参考图单一职责；场景锚点每景 3–5 个，需「可画、可认可、可核对」（「补丁船篷」是锚点，「陈旧的氛围」是形容词）。
- 道具白底无手（拿着道具的手是最常见污染）+ 尺度短语（防画成家具尺寸）；跨集叙事道具 3–8 件。
- 优先级（报告未给出，建议值）：①主角定妆 ②对手/关键配角 ③主场景空景 ④叙事道具 ⑤光照变体；图与文冲突时模型听图的。

### 3.3 易崩点与规避
- 禁光影色调词（光/影/逆光/色温/色调/暖色/冷色），光照走场景衍生；音效只写环境音 + 动作音，禁 BGM/配乐/乐器烘托，画面动作改了声景必须一起改。
- 外观（服装/发型/长相）不进画面描述，只写动作、姿态、表情与当下状态变化（汗湿、泪痕、衣衫凌乱）。
- 在场人物不能消失：未离场角色每镜要有视觉落点（背景/局部/反应镜/虚焦剪影/前景遮挡）；群演只做微动作（遮、瞥、垂、攥），不配台词。
- 冻结关键帧只投影镜头起点，删除终点才出现的动作、姿态、道具状态；同义重复镜头删掉，同一动作不跨镜重复。
- 八病自查：舞台剧病/均匀病/秒数漂移/台词爆仓/声景漏改/换景不换段/改切不读邻切。
- 反模板条款：不为检查表硬加秘密、反转或人物弧；若自检让剧本长出输入没有要求的机关，撤掉机关而不是替它找理由；审片意见须带位置/引文/影响/修订结果，不能只说「AI 味」「不够电影感」。
